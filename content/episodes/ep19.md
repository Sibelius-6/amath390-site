## 概述

一个纯净的 A4（440 Hz），一个在微微颤抖的 A4。奇怪的是——颤抖的那个听起来更稳定、更清晰。

> *中文:* "这就是颤音，vibrato。每个歌剧歌手都在用它，但很少有人意识到，它背后的数学和雅马哈 DX7 合成器完全一样。"

颤音（vibrato）是对载波频率的周期性调制——一个正弦波嵌套在另一个正弦波内部。表面上只有一根频率在晃动，但 Jacobi-Anger 展开揭示了隐藏的频谱结构：载波两侧出现一系列等间距的边带（sidebands），每条边带的振幅由 Bessel 函数 {{< m >}}J_n(\beta){{< /m >}} 决定。调制深度 {{< m >}}\beta{{< /m >}} 从小到大，声音从颤音演变为全新的音色——1967 年 John Chowning 在斯坦福实验室的这个发现，催生了 DX7 合成器和整个八十年代的流行音乐。

本集建立从 FM 方程到频谱展开的完整数学链条，并展示颤音的边带如何反复扫过 Singer's Formant 窗口（EP15），为歌剧歌手提供穿透力优势。

## 定义

{{< definition name="频率调制信号（FM Signal）" label="Definition 19.1" >}}
设载波频率 {{< m >}}f_c > 0{{< /m >}}（Hz），调制频率 {{< m >}}f_m > 0{{< /m >}}（Hz），调制指数 {{< m >}}\beta \geq 0{{< /m >}}（无量纲），振幅 {{< m >}}A > 0{{< /m >}}。**频率调制信号**定义为

{{< dm >}}x(t) = A \sin\!\bigl(2\pi f_c\, t + \beta \sin(2\pi f_m\, t)\bigr){{< /dm >}}

三个参数的物理含义：

| 参数 | 名称 | 含义 | 典型值（歌剧颤音） |
|------|------|------|---------------------|
| {{< m >}}f_c{{< /m >}} | 载波频率（carrier） | 歌手演唱的音高 | 440 Hz（A4） |
| {{< m >}}f_m{{< /m >}} | 调制频率（modulation rate） | 颤抖的速度 | 5–7 Hz |
| {{< m >}}\beta{{< /m >}} | 调制指数（modulation index） | 频率偏移的幅度 | 2–4 |

外层正弦波是**载波**，内层正弦波是**调制波**。调制波并不直接出现在输出频谱中——它通过改变载波的**瞬时相位**来影响频谱结构。

> *中文:* "就这一个公式。载波加正弦调制。看起来简单。但把它展开，你会看到一个完全不同的频谱世界。"
{{< /definition >}}

{{< definition name="瞬时频率" label="Definition 19.2" >}}
对于相位函数 {{< m >}}\phi(t) = 2\pi f_c\, t + \beta \sin(2\pi f_m\, t){{< /m >}}，**瞬时频率**定义为

{{< dm >}}f_{\text{inst}}(t) = \frac{1}{2\pi}\frac{d\phi}{dt} = f_c + \beta f_m \cos(2\pi f_m\, t){{< /dm >}}

瞬时频率在 {{< m >}}f_c - \beta f_m{{< /m >}} 和 {{< m >}}f_c + \beta f_m{{< /m >}} 之间周期性波动。乘积 {{< m >}}\Delta f = \beta f_m{{< /m >}} 称为**频率偏移**（frequency deviation），单位是 Hz。

**数值示例**：歌剧颤音 {{< m >}}f_c = 440{{< /m >}} Hz, {{< m >}}f_m = 6{{< /m >}} Hz, {{< m >}}\beta = 2{{< /m >}}：

{{< dm >}}\Delta f = \beta f_m = 2 \times 6 = 12 \text{ Hz}{{< /dm >}}

瞬时频率在 428 Hz 到 452 Hz 之间摆动——大约 ±50 cents，即 ±半个半音。这是典型的歌剧颤音摆幅。
{{< /definition >}}

{{< definition name="第一类Bessel函数 Jₙ(β)" label="Definition 19.3" >}}
**第一类 Bessel 函数** {{< m >}}J_n(\beta){{< /m >}}（{{< m >}}n \in \mathbb{Z}{{< /m >}}, {{< m >}}\beta \geq 0{{< /m >}}）有多种等价定义。最直接的是积分表示：

{{< dm >}}J_n(\beta) = \frac{1}{2\pi} \int_{-\pi}^{\pi} e^{i(\beta \sin\theta - n\theta)}\, d\theta = \frac{1}{\pi} \int_0^{\pi} \cos(n\theta - \beta\sin\theta)\, d\theta{{< /dm >}}

等价地，{{< m >}}J_n(\beta){{< /m >}} 是 Bessel 微分方程的解：

{{< dm >}}\beta^2 J_n''(\beta) + \beta J_n'(\beta) + (\beta^2 - n^2) J_n(\beta) = 0{{< /dm >}}

**关键性质**：

1. **对称性**：{{< m >}}J_{-n}(\beta) = (-1)^n J_n(\beta){{< /m >}}
2. **归一化**：{{< m >}}\sum_{n=-\infty}^{\infty} J_n^2(\beta) = 1{{< /m >}}（Parseval 等式；总能量守恒）
3. **零点时行为**：{{< m >}}J_0(0) = 1{{< /m >}}, {{< m >}}J_n(0) = 0{{< /m >}} 对所有 {{< m >}}n \neq 0{{< /m >}}
4. **第一零点**：{{< m >}}J_0(\beta) = 0{{< /m >}} 首次出现在 {{< m >}}\beta \approx 2.4048{{< /m >}}

性质 2 的物理意义：FM 调制不产生也不消灭能量——它只是将载波能量重新分配到各个边带中。{{< m >}}\beta{{< /m >}} 越大，能量从载波（{{< m >}}J_0{{< /m >}}）向高阶边带（{{< m >}}J_1, J_2, \ldots{{< /m >}}）转移。
{{< /definition >}}

{{< definition name="边带（Sideband）" label="Definition 19.4" >}}
FM 信号的频谱由**载波**和两侧对称的**边带**组成：

{{< dm >}}f_c, \quad f_c \pm f_m, \quad f_c \pm 2f_m, \quad f_c \pm 3f_m, \quad \ldots{{< /dm >}}

第 {{< m >}}n{{< /m >}} 对边带位于 {{< m >}}f_c \pm nf_m{{< /m >}}，振幅由 {{< m >}}J_n(\beta){{< /m >}} 决定。边带间距恒为 {{< m >}}f_m{{< /m >}}。

当 {{< m >}}\beta = 0{{< /m >}} 时，只有载波——纯音。{{< m >}}\beta{{< /m >}} 增大，边带逐渐出现，载波逐渐减弱。

> *中文:* "这个公式表面上只有一根正弦波，但内部嵌套了另一根正弦波。要看清楚它对频谱做了什么，我们把它展开——就像用棱镜把白光分成彩虹。"
{{< /definition >}}

{{< definition name="Carson 带宽" label="Definition 19.5" >}}
**Carson 带宽规则**（Carson, 1922）给出 FM 信号 98% 功率所占的近似带宽：

{{< dm >}}B_{\text{Carson}} = 2(\beta + 1) f_m{{< /dm >}}

歌剧颤音（{{< m >}}\beta = 2{{< /m >}}, {{< m >}}f_m = 6{{< /m >}} Hz）的 Carson 带宽为

{{< dm >}}B = 2(2 + 1) \times 6 = 36 \text{ Hz}{{< /dm >}}

即频谱主要集中在 {{< m >}}440 \pm 18{{< /m >}} Hz 的范围内。对比 DX7 合成（{{< m >}}\beta = 10{{< /m >}}, {{< m >}}f_m = 300{{< /m >}} Hz）：{{< m >}}B = 2(10+1) \times 300 = 6600{{< /m >}} Hz——带宽扩展了 180 倍。
{{< /definition >}}

## 主要定理

{{< theorem name="Jacobi-Anger 展开" label="Theorem 19.1" >}}
对任意实数 {{< m >}}\beta{{< /m >}} 和 {{< m >}}\theta{{< /m >}}，

{{< dm >}}e^{i\beta\sin\theta} = \sum_{n=-\infty}^{\infty} J_n(\beta)\, e^{in\theta}{{< /dm >}}

等价的实数形式为

{{< dm >}}\sin(\alpha + \beta\sin\theta) = \sum_{n=-\infty}^{\infty} J_n(\beta)\, \sin(\alpha + n\theta){{< /dm >}}

将 FM 信号代入（{{< m >}}\alpha = 2\pi f_c\, t{{< /m >}}, {{< m >}}\theta = 2\pi f_m\, t{{< /m >}}），得到

{{< dm >}}x(t) = A \sum_{n=-\infty}^{\infty} J_n(\beta)\, \sin\!\bigl(2\pi(f_c + n f_m)\, t\bigr){{< /dm >}}

**物理解读**：FM 信号是无穷多个纯正弦波的叠加。第 {{< m >}}n{{< /m >}} 个分量的频率为 {{< m >}}f_c + nf_m{{< /m >}}，振幅为 {{< m >}}A \cdot J_n(\beta){{< /m >}}。
{{< /theorem >}}

{{< proof >}}
**思路**：将 {{< m >}}e^{i\beta\sin\theta}{{< /m >}} 视为 {{< m >}}\theta{{< /m >}} 的 {{< m >}}2\pi{{< /m >}}-周期函数，展开为 Fourier 级数。

**第 1 步：Fourier 系数。** 设

{{< dm >}}e^{i\beta\sin\theta} = \sum_{n=-\infty}^{\infty} c_n\, e^{in\theta}{{< /dm >}}

则 Fourier 系数为

{{< dm >}}c_n = \frac{1}{2\pi} \int_{-\pi}^{\pi} e^{i\beta\sin\theta}\, e^{-in\theta}\, d\theta = \frac{1}{2\pi} \int_{-\pi}^{\pi} e^{i(\beta\sin\theta - n\theta)}\, d\theta{{< /dm >}}

**第 2 步：识别为 Bessel 函数。** 比较 Definition 19.3 中的积分表示：

{{< dm >}}J_n(\beta) = \frac{1}{2\pi} \int_{-\pi}^{\pi} e^{i(\beta\sin\theta - n\theta)}\, d\theta{{< /dm >}}

因此 {{< m >}}c_n = J_n(\beta){{< /m >}}。

**第 3 步：代入 FM 信号。** 令 {{< m >}}\theta = 2\pi f_m\, t{{< /m >}}，则

{{< dm >}}e^{i\beta\sin(2\pi f_m t)} = \sum_{n=-\infty}^{\infty} J_n(\beta)\, e^{i \cdot 2\pi n f_m\, t}{{< /dm >}}

FM 信号可以写成

{{< dm >}}x(t) = A\, \text{Im}\!\left[e^{i2\pi f_c t} \cdot e^{i\beta\sin(2\pi f_m t)}\right] = A\, \text{Im}\!\left[\sum_{n=-\infty}^{\infty} J_n(\beta)\, e^{i2\pi(f_c + nf_m)t}\right]{{< /dm >}}

取虚部：

{{< dm >}}x(t) = A \sum_{n=-\infty}^{\infty} J_n(\beta)\, \sin\!\bigl(2\pi(f_c + nf_m)\, t\bigr) \qquad \square{{< /dm >}}

**收敛性**：对固定 {{< m >}}\beta{{< /m >}}，{{< m >}}J_n(\beta) \to 0{{< /m >}} 当 {{< m >}}|n| \to \infty{{< /m >}}（指数衰减），故级数绝对一致收敛。
{{< /proof >}}

{{< theorem name="能量守恒（Bessel–Parseval 等式）" label="Theorem 19.2" >}}
对任意实数 {{< m >}}\beta{{< /m >}}，

{{< dm >}}\sum_{n=-\infty}^{\infty} J_n^2(\beta) = 1{{< /dm >}}

等价地，{{< m >}}J_0^2(\beta) + 2\sum_{n=1}^{\infty} J_n^2(\beta) = 1{{< /m >}}（利用 {{< m >}}J_{-n} = (-1)^n J_n{{< /m >}}，故 {{< m >}}J_{-n}^2 = J_n^2{{< /m >}}）。
{{< /theorem >}}

{{< proof >}}
由 Parseval 定理，{{< m >}}2\pi{{< /m >}}-周期函数 {{< m >}}f(\theta) = e^{i\beta\sin\theta}{{< /m >}} 的 Fourier 系数 {{< m >}}c_n = J_n(\beta){{< /m >}} 满足

{{< dm >}}\sum_{n=-\infty}^{\infty} |c_n|^2 = \frac{1}{2\pi}\int_{-\pi}^{\pi} |f(\theta)|^2\, d\theta{{< /dm >}}

由于 {{< m >}}|e^{i\beta\sin\theta}| = 1{{< /m >}} 对所有 {{< m >}}\theta{{< /m >}} 成立，右侧等于

{{< dm >}}\frac{1}{2\pi}\int_{-\pi}^{\pi} 1\, d\theta = 1{{< /dm >}}

因此 {{< m >}}\sum_{n=-\infty}^{\infty} J_n^2(\beta) = 1{{< /m >}}。{{< m >}}\square{{< /m >}}

**物理意义**：FM 调制只是将总功率（{{< m >}}\propto A^2{{< /m >}}）重新分配到各个边带。无论 {{< m >}}\beta{{< /m >}} 取何值，{{< m >}}x(t){{< /m >}} 的均方功率始终为 {{< m >}}A^2/2{{< /m >}}。能量不会被调制过程创造或消灭——只会在载波和边带之间流动。
{{< /proof >}}

{{< theorem name="载波消失点" label="Theorem 19.3" >}}
载波分量（频率 {{< m >}}f_c{{< /m >}}）的振幅为 {{< m >}}A \cdot J_0(\beta){{< /m >}}。{{< m >}}J_0{{< /m >}} 的第一零点在

{{< dm >}}\beta_1^{(0)} \approx 2.4048{{< /dm >}}

当 {{< m >}}\beta = \beta_1^{(0)}{{< /m >}} 时，频谱中载波线完全消失。全部能量位于边带中。

更一般地，{{< m >}}J_0{{< /m >}} 有无穷多个正零点 {{< m >}}\beta_1^{(0)} < \beta_2^{(0)} < \beta_3^{(0)} < \cdots{{< /m >}}（大致间隔 {{< m >}}\pi{{< /m >}}），在每个零点处载波消失。
{{< /theorem >}}

{{< proof >}}
{{< m >}}J_0(\beta){{< /m >}} 的幂级数展开为

{{< dm >}}J_0(\beta) = \sum_{k=0}^{\infty} \frac{(-1)^k}{(k!)^2}\left(\frac{\beta}{2}\right)^{2k} = 1 - \frac{\beta^2}{4} + \frac{\beta^4}{64} - \cdots{{< /dm >}}

这是一个衰减振荡函数（类似 {{< m >}}\cos\beta / \sqrt{\beta}{{< /m >}} 的渐近行为）。由中值定理，{{< m >}}J_0(0) = 1 > 0{{< /m >}} 且 {{< m >}}J_0(3) < 0{{< /m >}}（代入幂级数可验证），因此 {{< m >}}J_0{{< /m >}} 在 {{< m >}}(0, 3){{< /m >}} 中至少有一个零点。数值计算给出 {{< m >}}\beta_1^{(0)} \approx 2.4048{{< /m >}}。

渐近公式（{{< m >}}\beta \gg 1{{< /m >}}）：

{{< dm >}}J_0(\beta) \sim \sqrt{\frac{2}{\pi\beta}}\cos\!\left(\beta - \frac{\pi}{4}\right){{< /dm >}}

确认零点大致以 {{< m >}}\pi{{< /m >}} 为间距分布，且包络按 {{< m >}}1/\sqrt{\beta}{{< /m >}} 衰减。{{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< proposition label="Prop 19.1" name="歌剧颤音的频谱特征" >}}
对于典型歌剧颤音参数 {{< m >}}f_c = 440{{< /m >}} Hz, {{< m >}}f_m = 6{{< /m >}} Hz, {{< m >}}\beta = 2{{< /m >}}，展开的边带振幅为

| 分量 | 频率 (Hz) | 振幅系数 {{< m >}}J_n(2){{< /m >}} | 功率占比 {{< m >}}J_n^2(2){{< /m >}} |
|------|-----------|-------------------------------|-----------------------------------|
| 载波 {{< m >}}n=0{{< /m >}} | 440 | {{< m >}}J_0(2) \approx 0.224{{< /m >}} | 5.0% |
| 第 1 对 {{< m >}}n=\pm 1{{< /m >}} | 434, 446 | {{< m >}}J_1(2) \approx 0.577{{< /m >}} | 33.3% (每侧) |
| 第 2 对 {{< m >}}n=\pm 2{{< /m >}} | 428, 452 | {{< m >}}J_2(2) \approx 0.353{{< /m >}} | 12.5% (每侧) |
| 第 3 对 {{< m >}}n=\pm 3{{< /m >}} | 422, 458 | {{< m >}}J_3(2) \approx 0.129{{< /m >}} | 1.7% (每侧) |

验证：{{< m >}}0.224^2 + 2(0.577^2 + 0.353^2 + 0.129^2 + \cdots) \approx 0.050 + 0.666 + 0.249 + 0.033 \approx 1.0{{< /m >}} {{< m >}}\checkmark{{< /m >}}

注意 {{< m >}}\beta = 2{{< /m >}} 时载波只占总功率的 5%——绝大部分能量已经转移到第一、第二对边带中。但由于边带间距仅 6 Hz（远低于人耳频率分辨阈），听觉系统将整个频谱簇感知为单一音高的"温暖抖动"。
{{< /proposition >}}

{{< proof >}}
直接代入 Theorem 19.1 的展开式，使用 {{< m >}}J_n(2){{< /m >}} 的数值表（或幂级数计算）。

{{< m >}}J_0(2) = 1 - 1 + 1/4 - 1/36 + \cdots \approx 0.2239{{< /m >}}

{{< m >}}J_1(2) = 1 - 1/2 + 1/12 - 1/144 + \cdots \approx 0.5767{{< /m >}}

{{< m >}}J_2(2) = 1/2 - 1/3 + 1/16 - \cdots \approx 0.3528{{< /m >}}

{{< m >}}J_3(2) = 1/6 - 1/12 + \cdots \approx 0.1289{{< /m >}}

功率守恒由 Theorem 19.2 保证。{{< m >}}\square{{< /m >}}
{{< /proof >}}

## 从颤音到合成：Chowning 的发现

{{< theorem name="FM 参数空间的划分" label="Theorem 19.4" >}}
FM 方程 {{< m >}}x(t) = A\sin(2\pi f_c\, t + \beta\sin(2\pi f_m\, t)){{< /m >}} 在 {{< m >}}(f_m, \beta){{< /m >}} 参数平面上产生三个知觉区域：

1. **颤音区**（{{< m >}}f_m \lesssim 7{{< /m >}} Hz, {{< m >}}\beta \lesssim 4{{< /m >}}）：听觉系统追踪瞬时频率的周期性偏移，感知为"音高在动"。Carson 带宽 {{< m >}}B = 2(\beta+1)f_m \lesssim 60{{< /m >}} Hz，远小于临界频带宽度（~100 Hz at 440 Hz），边带不可分辨。

2. **颤音–颤幅过渡区**（{{< m >}}f_m \approx 7\text{–}10{{< /m >}} Hz）：调制速率超过听觉系统的音高追踪能力。感知从"音高在动"渐变为"振幅在抖"（tremolo）。这不是一个锐利的分界线，而是一个渐变区间，取决于 {{< m >}}\beta{{< /m >}} 和个体差异。

3. **FM 合成区**（{{< m >}}f_m \gtrsim 20{{< /m >}} Hz, 特别是 {{< m >}}f_m{{< /m >}} 与 {{< m >}}f_c{{< /m >}} 可比拟）：边带间距超过临界频带宽度，各边带被分辨为独立的频率分量。{{< m >}}\beta{{< /m >}} 决定音色丰富度——不同的 {{< m >}}(f_m, \beta){{< /m >}} 组合模拟铜管、电钢琴、钟声等音色。
{{< /theorem >}}

{{< proof >}}
**颤音区的频谱约束**：当 {{< m >}}\beta = 2{{< /m >}}, {{< m >}}f_m = 6{{< /m >}} Hz 时，Carson 带宽 {{< m >}}B = 2(2+1) \times 6 = 36{{< /m >}} Hz。在 440 Hz 处，人耳的等效矩形带宽（ERB）约为

{{< dm >}}\text{ERB}(440) = 24.7(4.37 \times 0.44 + 1) = 24.7 \times 2.92 \approx 72 \text{ Hz}{{< /dm >}}

（Moore-Glasberg 公式，1983）。由于 {{< m >}}B < \text{ERB}{{< /m >}}，所有边带落在同一个临界频带内，被听觉系统融合为单一"宽化"的音高。

**FM 合成区的频谱约束**：当 {{< m >}}f_m = 300{{< /m >}} Hz, {{< m >}}\beta = 5{{< /m >}} 时，{{< m >}}B = 2(5+1) \times 300 = 3600{{< /m >}} Hz，边带间距 300 Hz 远超 ERB，各分量被独立感知——产生全新的音色。

**过渡区的机制**：当 {{< m >}}f_m{{< /m >}} 接近 ~7–10 Hz，调制周期（~100–140 ms）接近听觉系统追踪音高变化的时间常数（~130 ms, Demany & Semal 1989）。追踪失败时，听觉系统将频率调制重新解释为包络调制——即 tremolo。{{< m >}}\square{{< /m >}}
{{< /proof >}}

**历史注记**：1967 年，John Chowning 在斯坦福大学人工智能实验室调试这个方程时，将 {{< m >}}f_m{{< /m >}} 从 6 Hz 提高到几百 Hz。声音从颤抖的音符突变为铜管和钟声般的全新音色。他意识到颤音和音色合成只是同一个方程的不同参数区域。1973 年发表论文《The Synthesis of Complex Audio Spectra by Means of Frequency Modulation》，1983 年 Yamaha DX7 合成器将该方程商业化，定义了整个八十年代的流行音乐音色。

## 共振峰扫描机制

{{< theorem name="颤音的共振峰频率扫描" label="Theorem 19.5" >}}
设声音基频为 {{< m >}}f_0{{< /m >}}，谐波列为 {{< m >}}f_0, 2f_0, 3f_0, \ldots{{< /m >}} 当施加颤音（调制率 {{< m >}}f_m{{< /m >}}，调制指数 {{< m >}}\beta{{< /m >}}）时，**每一个谐波**都同步经历相同的 FM 调制。第 {{< m >}}k{{< /m >}} 次谐波的瞬时频率为

{{< dm >}}f_k(t) = k f_0 + k \beta f_m \cos(2\pi f_m\, t){{< /dm >}}

频率偏移 {{< m >}}\Delta f_k = k\beta f_m{{< /m >}} 随谐波阶数 {{< m >}}k{{< /m >}} 线性增长。

以 A4 为例（{{< m >}}f_0 = 440{{< /m >}} Hz, {{< m >}}f_m = 6{{< /m >}} Hz, {{< m >}}\beta \approx 4{{< /m >}}，对应 ±1 半音即 ±25 Hz 偏移）：

| 谐波 | 中心频率 | 偏移 {{< m >}}\Delta f_k{{< /m >}} | 扫描范围 |
|------|----------|-------------------------------|----------|
| {{< m >}}k = 1{{< /m >}} | 440 Hz | ±25 Hz | 415–465 Hz |
| {{< m >}}k = 3{{< /m >}} | 1320 Hz | ±75 Hz | 1245–1395 Hz |
| {{< m >}}k = 7{{< /m >}} | 3080 Hz | ±175 Hz | 2905–3255 Hz |
| {{< m >}}k = 8{{< /m >}} | 3520 Hz | ±200 Hz | 3320–3720 Hz |

第 7、8 次谐波的扫描范围覆盖了 Singer's Formant 窗口（2500–3500 Hz, EP15 Definition 15.3）。这些谐波如扫帚一般，以每秒 5–7 次的频率反复扫过共振峰。
{{< /theorem >}}

{{< proof >}}
若基频受 FM 调制：{{< m >}}f_0(t) = f_0 + \beta f_m \cos(2\pi f_m t){{< /m >}}，则在线性声源模型中，第 {{< m >}}k{{< /m >}} 次谐波的频率为基频的 {{< m >}}k{{< /m >}} 倍：

{{< dm >}}f_k(t) = k \cdot f_0(t) = k f_0 + k\beta f_m \cos(2\pi f_m t){{< /dm >}}

偏移量 {{< m >}}\Delta f_k = k\beta f_m{{< /m >}} 线性增长。

对于 A4（{{< m >}}f_0 = 440{{< /m >}} Hz），3 kHz 附近的谐波为 {{< m >}}k = 7{{< /m >}}（3080 Hz）和 {{< m >}}k = 8{{< /m >}}（3520 Hz）。当 {{< m >}}\beta \approx 4{{< /m >}}, {{< m >}}f_m = 6{{< /m >}} Hz：

{{< dm >}}\Delta f_7 = 7 \times 4 \times 6 = 168 \text{ Hz}, \qquad \Delta f_8 = 8 \times 4 \times 6 = 192 \text{ Hz}{{< /dm >}}

扫描范围：{{< m >}}3080 \pm 168 = [2912, 3248]{{< /m >}} Hz 和 {{< m >}}3520 \pm 192 = [3328, 3712]{{< /m >}} Hz，覆盖了 2500–3500 Hz 的 Singer's Formant 窗口。

**效果**：边带不断进进出出，把已有的谐波能量反复送过共振峰窗口。总能量守恒（Theorem 19.2）——不是产生了更多能量，而是时间平均下来，共振峰频段被反复激发，产生持续的、闪烁的明亮感。{{< m >}}\square{{< /m >}}
{{< /proof >}}

## 音乐联系

{{< musical-connection >}}
**颤音：频率扫描策略**

颤音不只是"好听的抖动"。从 Theorem 19.5 看，它是一种**频率扫描策略**：让歌手的高次谐波在 3 kHz 窗口（EP15）里持续闪烁。边带反复扫过共振峰，时间平均下持续激发 Singer's Formant 频段。穿透力不是来自更大的音量，而是来自更聪明的频率分配。

**从 EP09 到 EP19：非线性与调制**

EP09 展示了**非线性系统**如何从两个输入频率创造新频率（组合音 {{< m >}}mf_1 \pm nf_2{{< /m >}}）。EP19 的 FM 是不同的机制——不是非线性产生新频率，而是**相位调制**将能量重新分配到已有的边带结构中。但最终效果类似：原本单一的频谱线被展宽为多条线。耳蜗的非线性（EP09）和声带的频率调制（EP19）都在丰富频谱——一个在接收端，一个在发射端。

**一个方程，两个世界**

同一个公式。{{< m >}}f_m = 6{{< /m >}} Hz, {{< m >}}\beta = 2{{< /m >}}——歌剧舞台上的颤音。{{< m >}}f_m = 300{{< /m >}} Hz, {{< m >}}\beta = 10{{< /m >}}——DX7 录音棚里的电钢琴。两个参数的移动，跨越了从声乐到电子音乐的整个历史。

> *中文:* "1967年，乔宁把调制频率从六赫兹提高到几百赫兹时，声音突然变了。不再是颤抖的音符，而是一种全新的音色——铜管、电钢琴、钟声。"

## 局限性与开放问题

1. **Jacobi-Anger 展开假设纯正弦调制。** 真实的歌剧颤音波形不是完美正弦——通常包含缓慢的起振阶段和不规则的周期波动。非正弦调制的 FM 信号没有封闭的 Bessel 展开，需要用 STFT 或小波分析（EP35/EP36）。

2. **线性声源假设的局限。** Theorem 19.5 假设每个谐波的频率偏移严格等比于谐波阶数。但声门波不是理想的谐波源——声门关闭相（closed phase）的非线性导致高次谐波的调制行为偏离线性预测。

3. **感知的非线性。** 人耳对频率偏移的感知是对数的（以 cents 为单位），不是线性的。相同的 Hz 偏移在低音区和高音区对应不同的 cent 偏移。一个完整的感知模型需要结合 ERB 频率尺度（Glasberg & Moore, 1990）和调制传递函数（Viemeister, 1979）。

4. **颤音与 tremolo 的边界。** Theorem 19.4 中的过渡区（~7–10 Hz）是一个经验观察，缺乏精确的数学刻画。关键问题是：调制频率和调制深度如何联合决定感知转换点？是否存在一个临界曲线 {{< m >}}\beta_{\text{crit}}(f_m){{< /m >}} 使得 {{< m >}}(f_m, \beta){{< /m >}} 在曲线两侧分别被感知为 vibrato 和 tremolo？

{{< conjecture name="颤音–颤幅感知临界面" >}}
在 {{< m >}}(f_m, \beta){{< /m >}} 参数空间中，存在一条感知临界曲线 {{< m >}}\mathcal{C}{{< /m >}} 将"vibrato 知觉"与"tremolo 知觉"分开。初步证据表明 {{< m >}}\mathcal{C}{{< /m >}} 大致沿 {{< m >}}f_m \approx 7{{< /m >}} Hz 延伸，但在大 {{< m >}}\beta{{< /m >}} 时向更低的 {{< m >}}f_m{{< /m >}} 弯曲——更深的调制使听觉系统更早放弃追踪频率变化。

**开放问题**：{{< m >}}\mathcal{C}{{< /m >}} 的精确形状是什么？它是否依赖于载波频率 {{< m >}}f_c{{< /m >}}？
{{< /conjecture >}}
