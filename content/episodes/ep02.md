## Overview

When you pluck a guitar string, why does it produce a rich spectrum of overtones rather than a single pure tone? The answer lies in a second-order partial differential equation derived by d'Alembert in 1747 and the separation-of-variables technique that Fourier refined in the early 19th century.

This episode derives the **1D wave equation** from Newton's second law, establishes **d'Alembert's general solution** as a superposition of traveling waves, and then reframes everything as **Fourier series** — infinite sums of standing-wave modes whose frequencies form the integer harmonic series {{< m >}}f_1, 2f_1, 3f_1, \ldots{{< /m >}}

> *中文:* "从波动方程到傅里叶级数，我们看到了数学如何揭示音乐的物理本质。达朗贝尔的行波解告诉我们波如何传播，傅里叶的级数解告诉我们泛音如何叠加。"

## Definitions

{{< definition name="The Wave Equation" label="Definition 2.1" >}}
Let {{< m >}}u(x,t){{< /m >}} denote the transverse displacement of a string at position {{< m >}}x \in [0,L]{{< /m >}} and time {{< m >}}t \geq 0{{< /m >}}. The **1D wave equation** is

{{< dm >}}\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \qquad c = \sqrt{\frac{T}{\mu}}{{< /dm >}}

where {{< m >}}T > 0{{< /m >}} is the string tension (force) and {{< m >}}\mu > 0{{< /m >}} is the linear mass density (mass per unit length). The constant {{< m >}}c{{< /m >}} has units of velocity and is the propagation speed of waves on the string.
{{< /definition >}}

{{< definition name="Dirichlet Boundary Conditions" label="Definition 2.2" >}}
For a string with **fixed endpoints**, the boundary conditions are

{{< dm >}}u(0,t) = 0 \quad \text{and} \quad u(L,t) = 0 \qquad \text{for all } t \geq 0{{< /dm >}}

Combined with initial conditions {{< m >}}u(x,0) = \phi(x){{< /m >}} (initial shape) and {{< m >}}u_t(x,0) = \psi(x){{< /m >}} (initial velocity), this forms a well-posed initial-boundary value problem.
{{< /definition >}}

{{< definition name="Normal Modes" label="Definition 2.3" >}}
The **{{< m >}}n{{< /m >}}-th normal mode** (or standing wave) is the particular solution

{{< dm >}}u_n(x,t) = \sin\!\left(\frac{n\pi x}{L}\right)\!\left(A_n \cos\omega_n t + B_n \sin\omega_n t\right), \qquad n = 1, 2, 3, \ldots{{< /dm >}}

where

{{< dm >}}\omega_n = \frac{n\pi c}{L}, \qquad f_n = \frac{\omega_n}{2\pi} = \frac{nc}{2L}{{< /dm >}}

The frequency {{< m >}}f_1 = c/(2L){{< /m >}} is the **fundamental frequency** (first harmonic). The frequency {{< m >}}f_n = n f_1{{< /m >}} is the **{{< m >}}n{{< /m >}}-th harmonic** or {{< m >}}(n-1){{< /m >}}-th **overtone**.
{{< /definition >}}

{{< definition name="Fourier Series Solution" label="Definition 2.4" >}}
The general solution to the wave equation with Dirichlet boundary conditions is the **Fourier series**

{{< dm >}}u(x,t) = \sum_{n=1}^{\infty} \sin\!\left(\frac{n\pi x}{L}\right)\!\left(A_n \cos\omega_n t + B_n \sin\omega_n t\right){{< /dm >}}

The coefficients are determined by initial conditions via

{{< dm >}}A_n = \frac{2}{L}\int_0^L \phi(x)\sin\!\left(\frac{n\pi x}{L}\right) dx, \qquad B_n = \frac{2}{n\pi c}\int_0^L \psi(x)\sin\!\left(\frac{n\pi x}{L}\right) dx{{< /dm >}}
{{< /definition >}}

{{< definition name="Modal Energy" label="Definition 2.5" >}}
The **total mechanical energy** of the string is

{{< dm >}}E = \frac{1}{2}\int_0^L \left[\mu\, u_t^2 + T\, u_x^2\right] dx{{< /dm >}}

The **energy of the {{< m >}}n{{< /m >}}-th mode** is

{{< dm >}}E_n = \frac{L}{4}\left[\mu\, \omega_n^2(A_n^2 + B_n^2) + T\!\left(\frac{n\pi}{L}\right)^2(A_n^2 + B_n^2)\right] = \frac{L\mu\omega_n^2}{4}(A_n^2 + B_n^2){{< /dm >}}

(using {{< m >}}T(n\pi/L)^2 = \mu\omega_n^2{{< /m >}}).
{{< /definition >}}

## Main Theorems

{{< theorem name="Wave Equation from Newton's Second Law" label="Theorem 2.1" >}}
Under the **small-amplitude approximation** (displacements much smaller than string length), Newton's second law applied to an infinitesimal string element of length {{< m >}}dx{{< /m >}} yields the wave equation

{{< dm >}}u_{tt} = c^2\, u_{xx}, \qquad c = \sqrt{T/\mu}{{< /dm >}}
{{< /theorem >}}

{{< proof >}}
Consider the string element occupying {{< m >}}[x, x+dx]{{< /m >}} with transverse displacement {{< m >}}u(x,t){{< /m >}}. The element has mass {{< m >}}dm = \mu\, dx{{< /m >}}.

The tension acts tangentially at both ends. At the right end, the string makes angle {{< m >}}\theta(x+dx,t) \approx u_x(x+dx,t){{< /m >}} with the horizontal (small angle approximation: {{< m >}}\sin\theta \approx \tan\theta \approx \theta{{< /m >}}). At the left end, angle is {{< m >}}\theta(x,t) \approx u_x(x,t){{< /m >}}.

The net transverse force on the element is:
{{< dm >}}dF = T\sin\theta(x+dx,t) - T\sin\theta(x,t) \approx T\left[u_x(x+dx,t) - u_x(x,t)\right] = T\, u_{xx}(x,t)\, dx{{< /dm >}}

Newton's second law: {{< m >}}dF = dm \cdot u_{tt}{{< /m >}}, so

{{< dm >}}T\, u_{xx}\, dx = \mu\, dx\cdot u_{tt}{{< /dm >}}

Dividing by {{< m >}}\mu\, dx{{< /m >}}:

{{< dm >}}u_{tt} = \frac{T}{\mu}\, u_{xx} = c^2\, u_{xx} \qquad \square{{< /dm >}}
{{< /proof >}}

> *Visual:* Draw a curved string element with tangent lines at both endpoints. The net upward force from tension is proportional to the curvature {{< m >}}u_{xx}{{< /m >}} — positive curvature (concave up) creates upward restoring force, driving oscillation.

{{< theorem name="D'Alembert's General Solution" label="Theorem 2.2" >}}
Every solution of {{< m >}}u_{tt} = c^2 u_{xx}{{< /m >}} on {{< m >}}\mathbb{R} \times \mathbb{R}{{< /m >}} can be written as

{{< dm >}}u(x,t) = f(x - ct) + g(x + ct){{< /dm >}}

for arbitrary twice-differentiable functions {{< m >}}f{{< /m >}} and {{< m >}}g{{< /m >}}. The term {{< m >}}f(x-ct){{< /m >}} represents a rightward-traveling wave; {{< m >}}g(x+ct){{< /m >}} represents a leftward-traveling wave. Given initial conditions {{< m >}}u(x,0) = \phi(x){{< /m >}} and {{< m >}}u_t(x,0) = \psi(x){{< /m >}}, the unique solution is

{{< dm >}}u(x,t) = \frac{\phi(x-ct) + \phi(x+ct)}{2} + \frac{1}{2c}\int_{x-ct}^{x+ct}\psi(s)\,ds{{< /dm >}}
{{< /theorem >}}

{{< proof >}}
**Step 1 — Change of variables.** Let {{< m >}}\xi = x - ct{{< /m >}}, {{< m >}}\eta = x + ct{{< /m >}}. By the chain rule:

{{< dm >}}u_{xx} = u_{\xi\xi} + 2u_{\xi\eta} + u_{\eta\eta}, \qquad u_{tt} = c^2(u_{\xi\xi} - 2u_{\xi\eta} + u_{\eta\eta}){{< /dm >}}

The wave equation {{< m >}}u_{tt} = c^2 u_{xx}{{< /m >}} becomes

{{< dm >}}c^2(u_{\xi\xi} - 2u_{\xi\eta} + u_{\eta\eta}) = c^2(u_{\xi\xi} + 2u_{\xi\eta} + u_{\eta\eta}){{< /dm >}}

Simplifying: {{< m >}}-4c^2 u_{\xi\eta} = 0{{< /m >}}, so {{< m >}}u_{\xi\eta} = 0{{< /m >}}.

**Step 2 — Integration.** Integrate {{< m >}}u_{\xi\eta} = 0{{< /m >}} first in {{< m >}}\eta{{< /m >}}: {{< m >}}u_\xi = h(\xi){{< /m >}} for some function {{< m >}}h{{< /m >}}. Then integrate in {{< m >}}\xi{{< /m >}}: {{< m >}}u = F(\xi) + G(\eta){{< /m >}} where {{< m >}}F' = h{{< /m >}}. Setting {{< m >}}f = F{{< /m >}}, {{< m >}}g = G{{< /m >}} gives {{< m >}}u(x,t) = f(x-ct) + g(x+ct){{< /m >}}.

**Step 3 — Initial conditions.** From {{< m >}}u(x,0) = f(x) + g(x) = \phi(x){{< /m >}} and {{< m >}}u_t(x,0) = -cf'(x) + cg'(x) = \psi(x){{< /m >}}:

{{< dm >}}f'(x) - g'(x) = -\frac{\psi(x)}{c}{{< /dm >}}

Integrating: {{< m >}}f(x) - g(x) = -\frac{1}{c}\int_0^x \psi(s)\,ds + K{{< /m >}}. Solving the system of two equations for {{< m >}}f{{< /m >}} and {{< m >}}g{{< /m >}}, then substituting back yields the stated formula. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Separation of Variables: Normal Modes" label="Theorem 2.3" >}}
The only solutions of {{< m >}}u_{tt} = c^2 u_{xx}{{< /m >}} of the separable form {{< m >}}u(x,t) = X(x)T(t){{< /m >}} satisfying Dirichlet boundary conditions {{< m >}}X(0) = X(L) = 0{{< /m >}} are (up to scalar multiples) the normal modes:

{{< dm >}}X_n(x) = \sin\!\left(\frac{n\pi x}{L}\right), \quad T_n(t) = A_n\cos\omega_n t + B_n\sin\omega_n t, \quad \omega_n = \frac{n\pi c}{L}{{< /dm >}}

for {{< m >}}n = 1, 2, 3, \ldots{{< /m >}}
{{< /theorem >}}

{{< proof >}}
Substituting {{< m >}}u = X(x)T(t){{< /m >}} into {{< m >}}u_{tt} = c^2 u_{xx}{{< /m >}}:

{{< dm >}}X(x)T''(t) = c^2 X''(x)T(t){{< /dm >}}

Dividing both sides by {{< m >}}c^2 X(x)T(t){{< /m >}} (assuming both nonzero):

{{< dm >}}\frac{T''(t)}{c^2 T(t)} = \frac{X''(x)}{X(x)} = -\lambda{{< /dm >}}

where {{< m >}}-\lambda{{< /m >}} is a separation constant (it must be constant since the left side depends only on {{< m >}}t{{< /m >}} and the right only on {{< m >}}x{{< /m >}}).

**Spatial ODE:** {{< m >}}X'' = -\lambda X{{< /m >}} with {{< m >}}X(0) = X(L) = 0{{< /m >}}.

- If {{< m >}}\lambda \leq 0{{< /m >}}: the general solution is exponential or linear; neither can satisfy both boundary conditions with {{< m >}}X \not\equiv 0{{< /m >}}.
- If {{< m >}}\lambda > 0{{< /m >}}: write {{< m >}}\lambda = (n\pi/L)^2{{< /m >}}. Then {{< m >}}X(x) = A\sin(\sqrt{\lambda}\,x) + B\cos(\sqrt{\lambda}\,x){{< /m >}}. Condition {{< m >}}X(0) = 0{{< /m >}} gives {{< m >}}B = 0{{< /m >}}. Condition {{< m >}}X(L) = 0{{< /m >}} gives {{< m >}}\sin(\sqrt{\lambda}\,L) = 0{{< /m >}}, so {{< m >}}\sqrt{\lambda} = n\pi/L{{< /m >}} for {{< m >}}n = 1, 2, 3, \ldots{{< /m >}}

**Temporal ODE:** {{< m >}}T'' = -\lambda c^2 T = -\omega_n^2 T{{< /m >}} (with {{< m >}}\omega_n = n\pi c/L{{< /m >}}), which has general solution {{< m >}}T_n(t) = A_n\cos\omega_n t + B_n\sin\omega_n t{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *Visual:* The first five normal modes: mode 1 has one arch (no interior nodes), mode 2 has one interior node at {{< m >}}x=L/2{{< /m >}}, mode {{< m >}}n{{< /m >}} has {{< m >}}n-1{{< /m >}} interior nodes at {{< m >}}x = L/n, 2L/n, \ldots, (n-1)L/n{{< /m >}}. Each mode vibrates at frequency {{< m >}}f_n = n f_1{{< /m >}}.

{{< theorem name="Energy Conservation and Modal Orthogonality" label="Theorem 2.4" >}}
The total energy decomposes as a sum over modes with no cross terms:

{{< dm >}}E = \sum_{n=1}^{\infty} E_n{{< /dm >}}

where {{< m >}}E_n = \frac{L\mu\omega_n^2}{4}(A_n^2 + B_n^2){{< /m >}}, and each {{< m >}}E_n{{< /m >}} is independently conserved in time.
{{< /theorem >}}

{{< proof >}}
Compute the kinetic energy {{< m >}}K = \frac{\mu}{2}\int_0^L u_t^2\,dx{{< /m >}}.

Differentiate the Fourier series:

{{< dm >}}u_t = \sum_{n=1}^\infty \sin\!\left(\frac{n\pi x}{L}\right)\!(-A_n\omega_n\sin\omega_n t + B_n\omega_n\cos\omega_n t){{< /dm >}}

{{< dm >}}u_t^2 = \sum_{n=1}^\infty\sum_{m=1}^\infty \sin\!\left(\frac{n\pi x}{L}\right)\!\sin\!\left(\frac{m\pi x}{L}\right) \cdot (\text{time factors}){{< /dm >}}

Integrate over {{< m >}}[0,L]{{< /m >}} using the **orthogonality** of sine functions:

{{< dm >}}\int_0^L \sin\!\left(\frac{n\pi x}{L}\right)\!\sin\!\left(\frac{m\pi x}{L}\right) dx = \frac{L}{2}\,\delta_{nm}{{< /dm >}}

All cross terms ({{< m >}}n \neq m{{< /m >}}) vanish. The same orthogonality applies to the potential energy {{< m >}}\frac{T}{2}\int_0^L u_x^2\,dx{{< /m >}}. Adding kinetic and potential contributions for mode {{< m >}}n{{< /m >}} and using {{< m >}}T(n\pi/L)^2 = \mu\omega_n^2{{< /m >}}:

{{< dm >}}E_n = \frac{\mu}{2}\cdot\frac{L}{2}\,\omega_n^2(A_n^2 + B_n^2) + \frac{T}{2}\cdot\frac{L}{2}\cdot\left(\frac{n\pi}{L}\right)^2\!(A_n^2 + B_n^2) = \frac{L\mu\omega_n^2}{4}(A_n^2 + B_n^2){{< /dm >}}

Each {{< m >}}E_n{{< /m >}} is constant in time (the {{< m >}}A_n^2 + B_n^2{{< /m >}} factor does not depend on {{< m >}}t{{< /m >}}). {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< proposition label="Prop 2.1" name="Harmonic Series" >}}
The frequencies of the normal modes of a fixed string form the **harmonic series**:

{{< dm >}}f_1 : f_2 : f_3 : f_4 : \cdots = 1 : 2 : 3 : 4 : \cdots{{< /dm >}}

where {{< m >}}f_1 = c/(2L) = \frac{1}{2L}\sqrt{T/\mu}{{< /m >}} is the fundamental frequency.
{{< /proposition >}}

{{< proof >}}
By Definition 2.3, {{< m >}}f_n = \omega_n/(2\pi) = nc/(2L) = n f_1{{< /m >}}. The ratio {{< m >}}f_n / f_1 = n{{< /m >}}. {{< m >}}\square{{< /m >}}

**Physical interpretation**: Doubling the string length halves {{< m >}}f_1{{< /m >}} (one octave lower). Doubling the tension multiplies {{< m >}}f_1{{< /m >}} by {{< m >}}\sqrt{2}{{< /m >}} (a musical tritone up). Quadrupling tension doubles {{< m >}}f_1{{< /m >}} (one octave up).
{{< /proof >}}

## Worked Example: Plucked String

**Setup**: A string of length {{< m >}}L = 1{{< /m >}} is plucked at the midpoint to height {{< m >}}h{{< /m >}} and released from rest. Initial conditions:

{{< dm >}}\phi(x) = \begin{cases}2hx & 0 \leq x \leq 1/2 \\ 2h(1-x) & 1/2 \leq x \leq 1\end{cases}, \qquad \psi(x) = 0{{< /dm >}}

**Fourier coefficients**: Since {{< m >}}\psi = 0{{< /m >}}, all {{< m >}}B_n = 0{{< /m >}}. For {{< m >}}A_n{{< /m >}}:

{{< dm >}}A_n = 2\int_0^1 \phi(x)\sin(n\pi x)\,dx = \frac{8h}{n^2\pi^2}\sin\!\left(\frac{n\pi}{2}\right){{< /dm >}}

This equals {{< m >}}8h/(n^2\pi^2){{< /m >}} for {{< m >}}n \equiv 1 \pmod 4{{< /m >}}, {{< m >}}-8h/(n^2\pi^2){{< /m >}} for {{< m >}}n \equiv 3 \pmod 4{{< /m >}}, and $0$ for even {{< m >}}n{{< /m >}}.

**Conclusion**: Plucking at the midpoint **eliminates all even harmonics** ({{< m >}}A_2 = A_4 = \cdots = 0{{< /m >}}). The resulting timbre contains only odd harmonics {{< m >}}f_1, 3f_1, 5f_1, \ldots{{< /m >}} — this is the mathematical explanation for why plucking position shapes timbre.

> *中文:* "傅里叶级数的威力在于：任何初始形状，无论多复杂，都可以分解为这些正弦驻波的叠加。系数Aₙ由初始条件决定，而这些系数正是傅里叶系数。"

## Musical Connection

{{< musical-connection >}}
**The Overtone Series is the Harmonic Series**

Theorem 2.3 shows that a vibrating string produces frequencies in the exact ratio {{< m >}}1:2:3:4:5:6:\ldots{{< /m >}} This is called the **overtone series** or **harmonic series** in music. The first several intervals it generates are:

| Harmonic ratio | Interval |
|---|---|
| {{< m >}}2:1{{< /m >}} | Octave |
| {{< m >}}3:2{{< /m >}} | Perfect fifth |
| {{< m >}}4:3{{< /m >}} | Perfect fourth |
| {{< m >}}5:4{{< /m >}} | Major third |
| {{< m >}}6:5{{< /m >}} | Minor third |
| {{< m >}}7:6{{< /m >}} | "Harmonic seventh" (slightly flat of B{{< m >}}\flat{{< /m >}}) |

The ratios {{< m >}}3:2{{< /m >}} (perfect fifth) and {{< m >}}5:4{{< /m >}} (major third) that define the consonant intervals in Western music emerge directly from the integer structure of the harmonic series. This is why **Pythagorean tuning** (built from pure {{< m >}}3:2{{< /m >}} fifths) and **just intonation** (built from pure {{< m >}}5:4{{< /m >}} thirds) have mathematical foundations in the wave equation.

**Timbre as spectral envelope**: Different instruments playing the same pitch {{< m >}}f_1{{< /m >}} differ only in the amplitudes {{< m >}}A_n{{< /m >}} of each harmonic. A clarinet emphasizes odd harmonics (similar to our midpoint-pluck example, because of its cylindrical bore closed at one end). A violin's spectral envelope depends on bow speed and contact point. The piano's hammer position at roughly {{< m >}}1/8{{< /m >}} of the string length from one end suppresses harmonics {{< m >}}8, 16, 24, \ldots{{< /m >}}, avoiding the harsh high partials that would come from the exact hammer resonance.

> *中文:* "泛音的相对强度决定了音色。这就是为什么钢琴和吉他演奏同一个音符，听起来却完全不同——它们的泛音结构不同。"
{{< /musical-connection >}}

## Limits and Open Questions

1. **Small-amplitude approximation**: The derivation in Theorem 2.1 requires {{< m >}}|u_x| \ll 1{{< /m >}}. For large-amplitude vibrations (e.g., hard piano hammering), nonlinear terms enter. The nonlinear string equation introduces overtone **inharmonicity** — the higher modes deviate from exact integer multiples, which piano technicians compensate for by **stretching the octave** during tuning.

2. **Real strings have stiffness**: Physical strings are not perfectly flexible. The corrected model adds a bending stiffness term:
{{< dm >}}u_{tt} = c^2 u_{xx} - \frac{EI}{\mu}u_{xxxx}{{< /dm >}}
where {{< m >}}EI{{< /m >}} is the bending stiffness. This yields frequencies {{< m >}}f_n \approx nf_1\sqrt{1 + Bn^2}{{< /m >}} for a small constant {{< m >}}B{{< /m >}} (inharmonicity coefficient). The effect is musically significant for piano bass strings and is discussed in {{< episode-ref ep="33" >}}EP33 (physical modeling){{< /episode-ref >}}.

3. **Two and three dimensions**: Drumhead vibrations satisfy the 2D wave equation {{< m >}}u_{tt} = c^2(u_{xx} + u_{yy}){{< /m >}}. The normal modes involve Bessel functions rather than sines, and the frequency ratios are no longer integer multiples — hence drums do not produce a clear pitch the way strings do.

4. **Damping and decay**: Real strings have internal friction. Adding a damping term {{< m >}}-2\beta u_t{{< /m >}} to the right side shifts the normal mode frequencies to {{< m >}}\omega_n^{\text{damp}} = \sqrt{\omega_n^2 - \beta^2}{{< /m >}} and causes exponential amplitude decay {{< m >}}e^{-\beta t}{{< /m >}}, which gives each string note its characteristic sustain and decay envelope.

{{< conjecture name="Optimal Plucking Position" >}}
For a plucking position at {{< m >}}x = L/k{{< /m >}} (where {{< m >}}k{{< /m >}} is an integer {{< m >}}\geq 2{{< /m >}}), the Fourier coefficients satisfy {{< m >}}A_{mk} = 0{{< /m >}} for all positive integers {{< m >}}m{{< /m >}}. Therefore plucking at {{< m >}}1/k{{< /m >}} eliminates all harmonics that are multiples of {{< m >}}k{{< /m >}}. Among all plucking positions, {{< m >}}x = L/2{{< /m >}} minimizes the total power in even harmonics and {{< m >}}x = L/3{{< /m >}} minimizes power in harmonics {{< m >}}3, 6, 9, \ldots{{< /m >}} Is there a plucking position (not at a rational multiple of {{< m >}}L{{< /m >}}) that produces the smoothest (most rapidly decaying {{< m >}}A_n{{< /m >}}) spectral envelope? The answer relates to the Diophantine approximation properties of the plucking position.
{{< /conjecture >}}
