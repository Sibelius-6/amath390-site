## Overview

Bach's Fugue in C Major (BWV 846) has four independent voices: soprano, alto, tenor, bass. Delete any one of them and the remaining three still form a coherent harmonic structure. Why? The mathematical answer is **graph connectivity**: the voice-structure of polyphonic music forms a *2-connected* graph with no cut vertices, while homophonic music (melody + accompaniment) is at best 1-connected, with the melody as a potential cut vertex.

This episode develops the theory of graph connectivity — cut vertices, bridges, {{< m >}}k{{< /m >}}-connectivity — and applies it to a Bach chorale model. We also introduce Tarjan's linear-time algorithm for finding cut vertices via depth-first search, and sketch the topological extension using simplicial complexes and Betti numbers.

> *中文:* "复调音乐的'删不坏感'，并非偶然，而源于其分布式结构。"

## Definitions

{{< definition name="Graph Connectivity" label="Definition 3.1" >}}
An undirected graph {{< m >}}G = (V, E){{< /m >}} is **connected** if for every pair of vertices {{< m >}}u, v \in V{{< /m >}} there exists a path from {{< m >}}u{{< /m >}} to {{< m >}}v{{< /m >}}.

The **connected components** of {{< m >}}G{{< /m >}} are its maximal connected subgraphs.
{{< /definition >}}

{{< definition name="Cut Vertex (Articulation Point)" label="Definition 3.2" >}}
A vertex {{< m >}}v \in V{{< /m >}} is a **cut vertex** (or **articulation point**) of a connected graph {{< m >}}G{{< /m >}} if the subgraph {{< m >}}G - v{{< /m >}} (obtained by deleting {{< m >}}v{{< /m >}} and all edges incident to {{< m >}}v{{< /m >}}) is **disconnected**.

Equivalently, {{< m >}}v{{< /m >}} is a cut vertex if and only if there exist vertices {{< m >}}u, w \neq v{{< /m >}} such that every path from {{< m >}}u{{< /m >}} to {{< m >}}w{{< /m >}} passes through {{< m >}}v{{< /m >}}.
{{< /definition >}}

{{< definition name="Bridge" label="Definition 3.3" >}}
An edge {{< m >}}e = \{u,v\} \in E{{< /m >}} is a **bridge** if the graph {{< m >}}G - e{{< /m >}} (obtained by deleting only the edge {{< m >}}e{{< /m >}}) is disconnected.

Every bridge {{< m >}}e = \{u,v\}{{< /m >}} satisfies: {{< m >}}u{{< /m >}} is a cut vertex in {{< m >}}G - v{{< /m >}} and vice versa (unless one of them has degree 1, in which case {{< m >}}e{{< /m >}} is a pendant edge).
{{< /definition >}}

{{< definition name="k-Connectivity" label="Definition 3.4" >}}
For {{< m >}}k \geq 1{{< /m >}}, a graph {{< m >}}G{{< /m >}} with {{< m >}}|V| > k{{< /m >}} is **{{< m >}}k{{< /m >}}-connected** if removing any set of fewer than {{< m >}}k{{< /m >}} vertices leaves {{< m >}}G{{< /m >}} connected. Formally:

{{< dm >}}\kappa(G) = \min\{|S| : S \subseteq V,\; G - S \text{ is disconnected or has fewer than 2 vertices}\}{{< /dm >}}

is the **vertex connectivity** of {{< m >}}G{{< /m >}}. We say {{< m >}}G{{< /m >}} is {{< m >}}k{{< /m >}}-connected if {{< m >}}\kappa(G) \geq k{{< /m >}}.

Special cases:
- {{< m >}}\kappa(G) \geq 1{{< /m >}}: connected (no vertex whose removal disconnects)
- {{< m >}}\kappa(G) \geq 2{{< /m >}}: **2-connected** — no cut vertices
- {{< m >}}\kappa(G) \geq 3{{< /m >}}: **3-connected** — no pair of vertices whose removal disconnects
{{< /definition >}}

{{< definition name="DFS Discovery and Finish Times" label="Definition 3.5" >}}
In a **depth-first search** of a graph {{< m >}}G{{< /m >}} starting from vertex {{< m >}}s{{< /m >}}, each vertex {{< m >}}v{{< /m >}} receives:
- **Discovery time** {{< m >}}d[v]{{< /m >}}: the step at which {{< m >}}v{{< /m >}} is first visited
- **Finish time** {{< m >}}f[v]{{< /m >}}: the step at which all neighbors of {{< m >}}v{{< /m >}} have been explored

A **back edge** {{< m >}}\{u, v\}{{< /m >}} in an undirected DFS tree is an edge where {{< m >}}v{{< /m >}} is an ancestor of {{< m >}}u{{< /m >}} in the DFS tree (i.e., {{< m >}}d[v] < d[u]{{< /m >}} and {{< m >}}v{{< /m >}} was not processed via {{< m >}}u{{< /m >}}).
{{< /definition >}}

{{< definition name="Low Value" label="Definition 3.6" >}}
For each vertex {{< m >}}v{{< /m >}} in a DFS tree, define the **low value**:

{{< dm >}}\mathrm{low}[v] = \min\!\left(\{d[v]\} \cup \{d[w] : \{u,w\} \in E \text{ for some descendant } u \text{ of } v, \text{ and } \{u,w\} \text{ is a back edge}\}\right){{< /dm >}}

Informally, {{< m >}}\mathrm{low}[v]{{< /m >}} is the smallest discovery time reachable from the subtree rooted at {{< m >}}v{{< /m >}} using at most one back edge.
{{< /definition >}}

{{< definition name="Voice Graph of a Polyphonic Work" label="Definition 3.7" >}}
Given a {{< m >}}k{{< /m >}}-voice polyphonic composition, define the **voice graph** {{< m >}}G_{\mathrm{voice}} = (V, E){{< /m >}} where:
- {{< m >}}V = \{v_1, \ldots, v_k\}{{< /m >}}: one vertex per voice (soprano, alto, tenor, bass)
- {{< m >}}E{{< /m >}}: an edge {{< m >}}\{v_i, v_j\}{{< /m >}} is present if voices {{< m >}}i{{< /m >}} and {{< m >}}j{{< /m >}} form a consonant harmonic interval (third, fifth, sixth, octave) simultaneously at some point in the piece

In the weighted version, the weight {{< m >}}w(v_i, v_j){{< /m >}} counts the number of beats at which {{< m >}}v_i{{< /m >}} and {{< m >}}v_j{{< /m >}} are in consonance.
{{< /definition >}}

## Main Theorems

{{< theorem name="Tarjan's Cut Vertex Algorithm" label="Theorem 3.1" >}}
A non-root vertex {{< m >}}v{{< /m >}} in a DFS tree is a cut vertex of {{< m >}}G{{< /m >}} if and only if {{< m >}}v{{< /m >}} has a child {{< m >}}u{{< /m >}} in the DFS tree such that

{{< dm >}}\mathrm{low}[u] \geq d[v]{{< /dm >}}

The root of the DFS tree is a cut vertex if and only if it has at least two children in the DFS tree.

This algorithm finds all cut vertices in {{< m >}}O(|V| + |E|){{< /m >}} time.
{{< /theorem >}}

{{< proof >}}
**Correctness of the non-root condition:**

Suppose {{< m >}}v{{< /m >}} is a non-root DFS vertex and {{< m >}}u{{< /m >}} is a child of {{< m >}}v{{< /m >}} in the DFS tree. The condition {{< m >}}\mathrm{low}[u] \geq d[v]{{< /m >}} means that no vertex in the subtree rooted at {{< m >}}u{{< /m >}} has a back edge to any proper ancestor of {{< m >}}v{{< /m >}}.

**({{< m >}}\Rightarrow{{< /m >}})** If {{< m >}}\mathrm{low}[u] \geq d[v]{{< /m >}} for some child {{< m >}}u{{< /m >}}, then the subtree of {{< m >}}u{{< /m >}} cannot reach any ancestor of {{< m >}}v{{< /m >}} without going through {{< m >}}v{{< /m >}}. Hence removing {{< m >}}v{{< /m >}} disconnects the subtree of {{< m >}}u{{< /m >}} from the rest of the graph, so {{< m >}}v{{< /m >}} is a cut vertex.

**({{< m >}}\Leftarrow{{< /m >}})** Suppose {{< m >}}v{{< /m >}} is a cut vertex. Let {{< m >}}C{{< /m >}} be a connected component of {{< m >}}G - v{{< /m >}} that does not contain {{< m >}}v{{< /m >}}'s parent in the DFS tree. Pick any vertex {{< m >}}u{{< /m >}} of {{< m >}}C{{< /m >}} that was first reached from {{< m >}}v{{< /m >}} in the DFS (i.e., {{< m >}}u{{< /m >}} is in {{< m >}}v{{< /m >}}'s DFS subtree). Since {{< m >}}C{{< /m >}} has no direct path to {{< m >}}v{{< /m >}}'s parent (otherwise {{< m >}}v{{< /m >}} would not separate {{< m >}}C{{< /m >}}), all paths from the subtree of {{< m >}}u{{< /m >}} to ancestors of {{< m >}}v{{< /m >}} pass through {{< m >}}v{{< /m >}}, meaning {{< m >}}\mathrm{low}[u] \geq d[v]{{< /m >}}.

**Root case:** The root has no parent; it is a cut vertex exactly when its removal separates its subtrees, which happens iff it has {{< m >}}\geq 2{{< /m >}} children.

**Complexity:** DFS runs in {{< m >}}O(|V| + |E|){{< /m >}}. Computing {{< m >}}\mathrm{low}[v]{{< /m >}} for all vertices during the DFS adds no asymptotic overhead (one pass, bottom-up). {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *Visual:* Trace DFS on a small example: vertices {{< m >}}\{A,B,C,D,E\}{{< /m >}}, edges {{< m >}}AB, BC, CA, CD, DE{{< /m >}}. Vertex {{< m >}}C{{< /m >}} has {{< m >}}d[C] = 3{{< /m >}}; child {{< m >}}D{{< /m >}}'s subtree can only reach {{< m >}}D{{< /m >}} and {{< m >}}E{{< /m >}}, so {{< m >}}\mathrm{low}[D] = d[D] = 4 \geq d[C] = 3{{< /m >}}. Hence {{< m >}}C{{< /m >}} is a cut vertex. Removing {{< m >}}C{{< /m >}} disconnects {{< m >}}\{D,E\}{{< /m >}} from {{< m >}}\{A,B\}{{< /m >}}.

{{< theorem name="Whitney's Theorem" label="Theorem 3.2" >}}
For any graph {{< m >}}G{{< /m >}} with {{< m >}}|V| \geq 2{{< /m >}}:

{{< dm >}}\kappa(G) \leq \kappa'(G) \leq \delta(G){{< /dm >}}

where {{< m >}}\kappa(G){{< /m >}} is vertex connectivity, {{< m >}}\kappa'(G){{< /m >}} is **edge connectivity** (minimum number of edges whose removal disconnects {{< m >}}G{{< /m >}}), and {{< m >}}\delta(G) = \min_{v \in V} \deg(v){{< /m >}} is the minimum degree.
{{< /theorem >}}

{{< proof >}}
**{{< m >}}\kappa'(G) \leq \delta(G){{< /m >}}:** Let {{< m >}}v{{< /m >}} be a vertex of minimum degree {{< m >}}\delta(G){{< /m >}}. The {{< m >}}\delta(G){{< /m >}} edges incident to {{< m >}}v{{< /m >}} form a cut set (removing them isolates {{< m >}}v{{< /m >}}). Hence {{< m >}}\kappa'(G) \leq \delta(G){{< /m >}}.

**{{< m >}}\kappa(G) \leq \kappa'(G){{< /m >}}:** Given a minimum edge cut {{< m >}}F{{< /m >}} with {{< m >}}|F| = \kappa'(G){{< /m >}}, we construct a vertex cut of size at most {{< m >}}|F|{{< /m >}}. For each edge {{< m >}}\{u,v\} \in F{{< /m >}}, choose one of its endpoints (say {{< m >}}v{{< /m >}}) to include in a vertex cut {{< m >}}S{{< /m >}}. Removing {{< m >}}S{{< /m >}} separates the graph (since {{< m >}}F{{< /m >}} was a cut and each edge in {{< m >}}F{{< /m >}} has an endpoint in {{< m >}}S{{< /m >}}). This argument may select the same vertex for multiple edges, so {{< m >}}|S| \leq |F|{{< /m >}}, giving {{< m >}}\kappa(G) \leq \kappa'(G){{< /m >}}. {{< m >}}\square{{< /m >}}

**Remark:** The bounds are tight but not always equal. The complete bipartite graph {{< m >}}K_{3,3}{{< /m >}} satisfies {{< m >}}\kappa = \kappa' = \delta = 3{{< /m >}}. The graph obtained from {{< m >}}K_4{{< /m >}} by subdividing one edge has {{< m >}}\kappa = 2 < \kappa' = 3 < \delta = 3{{< /m >}}.
{{< /proof >}}

{{< theorem name="Menger's Theorem" label="Theorem 3.3" >}}
For vertices {{< m >}}s \neq t{{< /m >}} in a graph {{< m >}}G{{< /m >}}, the maximum number of internally **vertex-disjoint** {{< m >}}s{{< /m >}}-{{< m >}}t{{< /m >}} paths equals the minimum size of a vertex cut separating {{< m >}}s{{< /m >}} from {{< m >}}t{{< /m >}}.

Consequently, {{< m >}}G{{< /m >}} is {{< m >}}k{{< /m >}}-connected if and only if every pair of distinct vertices is connected by at least {{< m >}}k{{< /m >}} internally vertex-disjoint paths.
{{< /theorem >}}

{{< proof >}}
This is a special case of the max-flow min-cut theorem applied to the auxiliary network {{< m >}}N{{< /m >}} defined as follows:

- Each vertex {{< m >}}v \in V \setminus \{s,t\}{{< /m >}} is split into {{< m >}}v_{\mathrm{in}}{{< /m >}} and {{< m >}}v_{\mathrm{out}}{{< /m >}} with a directed edge {{< m >}}v_{\mathrm{in}} \to v_{\mathrm{out}}{{< /m >}} of capacity 1.
- Each undirected edge {{< m >}}\{u,v\}{{< /m >}} becomes two directed edges: {{< m >}}u_{\mathrm{out}} \to v_{\mathrm{in}}{{< /m >}} and {{< m >}}v_{\mathrm{out}} \to u_{\mathrm{in}}{{< /m >}}, each with capacity 1 (or {{< m >}}\infty{{< /m >}} if we only care about vertex cuts).
- The source is {{< m >}}s_{\mathrm{out}}{{< /m >}}, the sink is {{< m >}}t_{\mathrm{in}}{{< /m >}}.

In this network, a flow of value {{< m >}}k{{< /m >}} corresponds to {{< m >}}k{{< /m >}} internally vertex-disjoint paths, and a minimum cut of value {{< m >}}k{{< /m >}} corresponds to a minimum vertex separator of size {{< m >}}k{{< /m >}}. The max-flow min-cut theorem then gives Menger's result. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< proposition label="Prop 3.1" name="Polyphony Is 2-Connected" >}}
The voice graph of a Bach four-voice fugue is 2-connected (no cut vertices). The voice graph of a standard homophonic texture (single melody with chordal accompaniment) is at most 1-connected and typically has the melody as a cut vertex.
{{< /proposition >}}

{{< proof >}}
(Empirical argument supporting the mathematical claim.) In a four-voice fugue such as BWV 846, every pair of voices forms at least one consonant interval during the piece (verified by score analysis). Moreover, every voice is in consonance with every other voice in multiple passages. Consequently, the voice graph is {{< m >}}K_4{{< /m >}} (the complete graph on 4 vertices), which has {{< m >}}\kappa(K_4) = 3{{< /m >}}. Even after removing one voice, the remaining three form {{< m >}}K_3{{< /m >}}, which is connected.

In homophonic texture, the accompaniment voices may only be in consonance with the melody but not with each other except through the melody. This produces a **star graph** {{< m >}}K_{1,3}{{< /m >}} with the melody at the center — a graph with {{< m >}}\kappa(K_{1,3}) = 1{{< /m >}} and the center as the unique cut vertex. {{< m >}}\square{{< /m >}}

> *中文:* "复调音乐是分布式结构，每个声部都与其他声部密切连接，形成高连通的网状拓扑，没有不可或缺的中心。"
{{< /proof >}}

## Tarjan's Algorithm: Worked Example

Consider {{< m >}}G{{< /m >}} with {{< m >}}V = \{0,1,2,3,4\}{{< /m >}} and edges {{< m >}}\{0,1\}, \{1,2\}, \{2,0\}, \{1,3\}, \{3,4\}{{< /m >}}.

DFS from vertex 0 (discovery order: 0,1,2 backtracks; 1 continues to 3,4):

| Vertex | {{< m >}}d[v]{{< /m >}} | {{< m >}}f[v]{{< /m >}} | {{< m >}}\mathrm{low}[v]{{< /m >}} |
|--------|--------|--------|-------------------|
| 0 | 0 | 9 | 0 |
| 1 | 1 | 8 | 0 |
| 2 | 2 | 3 | 0 (back edge to 0) |
| 3 | 4 | 7 | 4 |
| 4 | 5 | 6 | 4 |

Check cut-vertex condition:
- Vertex 1: child 3 has {{< m >}}\mathrm{low}[3] = 4 \geq d[1] = 1{{< /m >}}. **Cut vertex.**
- Vertex 3: child 4 has {{< m >}}\mathrm{low}[4] = 4 \geq d[3] = 4{{< /m >}}. **Cut vertex.**

Removing vertex 1 disconnects {{< m >}}\{3,4\}{{< /m >}} from {{< m >}}\{0,2\}{{< /m >}}. Removing vertex 3 disconnects {{< m >}}\{4\}{{< /m >}}. These are precisely the articulation points.

## Extension: Simplicial Complexes and Betti Numbers

{{< definition name="Simplicial Complex of a Score" label="Definition 3.8" >}}
Given a {{< m >}}k{{< /m >}}-voice piece, define a simplicial complex {{< m >}}\mathcal{K}{{< /m >}} where:
- **0-simplices**: individual notes (pitch classes at time {{< m >}}t{{< /m >}})
- **1-simplices**: dyads (pairs of simultaneously sounding notes)
- **2-simplices**: trichords (three simultaneously sounding notes)
- **{{< m >}}(k-1){{< /m >}}-simplices**: {{< m >}}k{{< /m >}}-note chords

The **{{< m >}}n{{< /m >}}-th Betti number** {{< m >}}\beta_n{{< /m >}} counts {{< m >}}n{{< /m >}}-dimensional "holes" in {{< m >}}\mathcal{K}{{< /m >}}. {{< m >}}\beta_0{{< /m >}} counts connected components, {{< m >}}\beta_1{{< /m >}} counts independent cycles.
{{< /definition >}}

> *中文:* "传统的图只能捕捉两个音符之间的关系，但和弦是三个或更多音符的同时交互，这种高阶关系需要更高级的数学工具：单纯复形。"

The 2025 paper cited below used this approach to distinguish fugues from dances in Bach's WTC. Fugues exhibit high {{< m >}}\beta_1{{< /m >}} (many harmonic cycles) while dances show simpler topology.

## Musical Connection

{{< musical-connection >}}
**Cut Vertices and Harmonic Syntax**

In a chord-progression graph (vertices = chords, weighted directed edges = transition frequency), the **dominant seventh chord** V7 functions as a near-cut-vertex in common-practice tonality. Almost all progressions to the tonic I pass through V7, making it the bottleneck of harmonic syntax.

In Bach's chorales, Rameau's principle of **fundamental bass** predicts that V → I is the strongest directed edge. A chord-graph analysis of a Bach chorale corpus (e.g., the 371 harmonized chorales) reveals:
- V7 (G7 in C major) has the highest **betweenness centrality** of any chord — it lies on the most shortest paths between other chords
- The I–IV–V–I "loop" has no interior cut vertex (it is the backbone 3-cycle of the graph)
- Chromatic chords (viio7, augmented sixths) appear as **bridges**: edges whose removal would disconnect remote key areas from the tonic region

This is why Wagner could exploit chromatic bridges so dramatically: by avoiding the V7 → I resolution (the strongest edge), he kept the harmonic graph in a perpetually "almost-disconnected" state, creating sustained tension.

> *中文:* "从图论的连通性，到复调音乐的声部结构，数学再一次揭示了音乐的深层逻辑。"
{{< /musical-connection >}}

## Limits and Open Questions

1. **Directed vs. undirected graphs**: The voice graph model (Definition 3.7) is undirected, but chord-progression graphs are naturally directed. Directed connectivity (strong vs. weak connectivity) is a stronger notion: a directed graph is **strongly connected** if for every ordered pair {{< m >}}(u,v){{< /m >}} there is a directed path from {{< m >}}u{{< /m >}} to {{< m >}}v{{< /m >}}. The harmonic syntax graph of a key is strongly connected within the diatonic scale but not across all chromatic chords.

2. **Temporal dynamics**: Graph connectivity is a static measure. A sliding-window analysis that recomputes {{< m >}}\kappa(G_t){{< /m >}} at each time window {{< m >}}t{{< /m >}} reveals how connectivity evolves during a piece — tension arches correspond to drops in {{< m >}}\kappa{{< /m >}}.

3. **Edge weights and weighted connectivity**: Weighted {{< m >}}k{{< /m >}}-connectivity (where edge weights represent transition probabilities) uses flow-based generalizations of Menger's theorem. The maximum weighted flow through the network gives a more musically meaningful notion of "structural importance."

4. **Simplicial homology and music**: Computing Betti numbers for a Bach fugue requires building the full simplicial complex (Definition 3.8) and then computing the ranks of homology groups {{< m >}}H_n(\mathcal{K}, \mathbb{Z}){{< /m >}}. For large choral works, this is computationally feasible but the musical interpretation of {{< m >}}\beta_2{{< /m >}} (3-dimensional holes) remains open.

{{< conjecture name="Polyphony Degree and Connectivity" >}}
For a {{< m >}}k{{< /m >}}-voice polyphonic work where every pair of voices forms at least one consonant interval, the voice graph contains {{< m >}}K_k{{< /m >}} as a subgraph, so {{< m >}}\kappa(G_{\mathrm{voice}}) \geq k-1{{< /m >}}. Conversely, the minimum connectivity of any {{< m >}}k{{< /m >}}-voice homophonic texture is at most 1. This suggests a sharp connectivity threshold distinguishing polyphonic from homophonic texture, independent of the specific harmony used.
{{< /conjecture >}}
