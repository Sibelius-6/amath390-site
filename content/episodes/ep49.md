## Overview / 概述

A tree grows one rule at a time — yet from just two substitution rules, an infinite self-similar structure emerges. This is the central insight of **Lindenmayer systems** (L-systems): simple parallel string-rewriting rules, iterated repeatedly, produce fractal geometry and — with an appropriate interpretation scheme — fractal musical structure.

> *中文:* "一棵树的生长规则，竟然能'长出'一首赋格？"

L-systems were invented in 1968 by the Hungarian biologist Aristid Lindenmayer to model the development of filamentous plants. The key innovation is **parallel rewriting**: at each step, every symbol in the string is simultaneously replaced by its expansion. This is in sharp contrast to context-free grammars (EP16), which expand one nonterminal at a time in a sequential derivation. The result of parallel rewriting is that each local piece of the string is a miniature copy of the whole — the hallmark of **self-similarity**.

The same mathematical machinery that generates the Koch snowflake, the Sierpiński triangle, and the branching patterns of ferns can be mapped, via a **turtle interpretation**, onto pitch sequences, rhythmic structures, and harmonic branching. This episode develops the formal theory of L-systems, computes their fractal dimension using the Hausdorff-Besicovitch formula, and connects the Fibonacci sequence and the golden angle to natural and musical proportion.

## Definitions

{{< definition name="Lindenmayer System (L-System)" label="Definition 49.1" >}}
A **deterministic context-free L-system** (D0L-system) is a triple

{{< dm >}}\mathcal{L} = (V,\, \omega,\, P){{< /dm >}}

where:

- {{< m >}}V{{< /m >}} is a finite **alphabet** of symbols.
- {{< m >}}\omega \in V^+{{< /m >}} is the **axiom** (initial string), a non-empty word over {{< m >}}V{{< /m >}}.
- {{< m >}}P : V \to V^*{{< /m >}} is the **production function**, assigning to each symbol {{< m >}}a \in V{{< /m >}} a replacement string {{< m >}}P(a) \in V^*{{< /m >}}.

The system evolves by **parallel rewriting**: given current string {{< m >}}w = a_1 a_2 \cdots a_n{{< /m >}}, the next string is

{{< dm >}}w' = P(a_1)\, P(a_2)\, \cdots\, P(a_n){{< /dm >}}

where juxtaposition denotes string concatenation. The string at step {{< m >}}n{{< /m >}} is denoted {{< m >}}w^{(n)}{{< /m >}}, with {{< m >}}w^{(0)} = \omega{{< /m >}}.
{{< /definition >}}

**Worked example — the Fibonacci L-system.** Let {{< m >}}V = \{A, B\}{{< /m >}}, {{< m >}}\omega = A{{< /m >}}, and production rules {{< m >}}P(A) = AB{{< /m >}}, {{< m >}}P(B) = A{{< /m >}}. The first five generations are:

| Step | String | Length |
|------|--------|--------|
| {{< m >}}n = 0{{< /m >}} | A | 1 |
| {{< m >}}n = 1{{< /m >}} | AB | 2 |
| {{< m >}}n = 2{{< /m >}} | ABA | 3 |
| {{< m >}}n = 3{{< /m >}} | ABAAB | 5 |
| {{< m >}}n = 4{{< /m >}} | ABAABABA | 8 |

The lengths 1, 2, 3, 5, 8, … are consecutive Fibonacci numbers. This is not coincidental — it follows directly from the structure of the rewriting rules.

> *中文:* "你认出来了吗？这是斐波那契数列——每一步的长度是前两步之和。"

{{< definition name="Turtle Interpretation" label="Definition 49.2" >}}
A **turtle interpretation** maps an L-system string over an extended alphabet {{< m >}}V \supseteq \{F, +, -, [, ]\}{{< /m >}} to a geometric path (or a musical sequence) via the following state machine. The turtle carries a state {{< m >}}(\mathbf{p}, \theta){{< /m >}}: position {{< m >}}\mathbf{p} \in \mathbb{R}^2{{< /m >}} and heading angle {{< m >}}\theta \in [0, 2\pi){{< /m >}}.

| Symbol | Geometric action | Musical action |
|--------|-----------------|----------------|
| {{< m >}}F{{< /m >}} | Move forward by step {{< m >}}\delta{{< /m >}}, drawing a segment | Play one note at current pitch |
| {{< m >}}+{{< /m >}} | Turn left by angle {{< m >}}\alpha{{< /m >}} | Raise pitch by interval {{< m >}}\alpha{{< /m >}} |
| {{< m >}}-{{< /m >}} | Turn right by angle {{< m >}}\alpha{{< /m >}} | Lower pitch by interval {{< m >}}\alpha{{< /m >}} |
| {{< m >}}[{{< /m >}} | Push {{< m >}}(\mathbf{p}, \theta){{< /m >}} onto stack | Begin a chord branch (push state) |
| {{< m >}}]{{< /m >}} | Pop {{< m >}}(\mathbf{p}, \theta){{< /m >}} from stack | End chord branch (pop state) |

The stack mechanism (bracket pair {{< m >}}[ \cdots ]{{< /m >}}) enables **branching structure** — the defining feature that allows L-systems to model trees (and polyphonic music) rather than just linear curves.
{{< /definition >}}

**Worked example — Koch curve.** Let {{< m >}}V = \{F, +, -\}{{< /m >}}, axiom {{< m >}}\omega = F{{< /m >}}, rule {{< m >}}P(F) = F{+}F{-}F{-}F{+}F{{< /m >}}, turning angle {{< m >}}\alpha = 90°{{< /m >}}. After three iterations the turtle traces the boundary of the Koch snowflake, a fractal with Hausdorff dimension {{< m >}}\log 4 / \log 3 \approx 1.26{{< /m >}}.

> *中文:* "Koch 曲线的规则：F 替换为 F 加 F 减 F 减 F 加 F。迭代三次，得到分形雪花边界。"

{{< definition name="Hausdorff-Besicovitch (Fractal) Dimension" label="Definition 49.3" >}}
For a self-similar set generated by {{< m >}}N{{< /m >}} copies of itself, each scaled by factor {{< m >}}r < 1{{< /m >}} (the **self-similarity ratio**), the **similarity dimension** (which coincides with the Hausdorff dimension for geometrically regular L-system outputs) is

{{< dm >}}d_H = \frac{\log N}{\log(1/r)}{{< /dm >}}

For a line segment: {{< m >}}N = 1{{< /m >}}, {{< m >}}r = 1{{< /m >}}, giving {{< m >}}d_H = 1{{< /m >}}.
For a filled square: {{< m >}}N = 4{{< /m >}}, {{< m >}}r = 1/2{{< /m >}}, giving {{< m >}}d_H = 2{{< /m >}}.
For the Koch curve: {{< m >}}N = 4{{< /m >}}, {{< m >}}r = 1/3{{< /m >}}, giving {{< m >}}d_H = \log 4 / \log 3 \approx 1.2619{{< /m >}}.
{{< /definition >}}

{{< definition name="Golden Angle" label="Definition 49.4" >}}
The **golden ratio** is {{< m >}}\varphi = (1 + \sqrt{5})/2 \approx 1.618{{< /m >}}. The **golden angle** is

{{< dm >}}\alpha_g = 360° \cdot \frac{1}{\varphi^2} = 360° \cdot (2 - \varphi) \approx 137.508°{{< /dm >}}

Equivalently, {{< m >}}\alpha_g = 360° / \varphi^2{{< /m >}}. In **phyllotaxis** (the arrangement of leaves, seeds, or scales on a plant), each successive element is placed at angular offset {{< m >}}\alpha_g{{< /m >}} from the previous one. The resulting spiral pattern exhibits Fibonacci numbers of arms in adjacent directions.
{{< /definition >}}

> *中文:* "这个角度是三百六十度除以黄金比的平方，等价于三百六十度乘以二减黄金比，约等于一百三十七点五度——因为黄金比是'最难被有理数逼近的无理数'，按黄金角排列能在所有尺度上避免聚集。"

## Main Theorems / 主要定理

{{< theorem name="Fibonacci Growth from Parallel Rewriting" label="Theorem 49.1" >}}
Let {{< m >}}\mathcal{L} = (\{A,B\},\, A,\, P){{< /m >}} with {{< m >}}P(A) = AB{{< /m >}}, {{< m >}}P(B) = A{{< /m >}}. Denote by {{< m >}}a_n{{< /m >}} and {{< m >}}b_n{{< /m >}} the number of {{< m >}}A{{< /m >}}'s and {{< m >}}B{{< /m >}}'s in {{< m >}}w^{(n)}{{< /m >}}, and let {{< m >}}F_n = a_n + b_n{{< /m >}} be the total length. Then:

{{< dm >}}F_n = F_{n-1} + F_{n-2}, \qquad F_0 = 1,\quad F_1 = 2{{< /dm >}}

so {{< m >}}F_n{{< /m >}} is the {{< m >}}(n+2){{< /m >}}-th Fibonacci number. Moreover, {{< m >}}\lim_{n \to \infty} F_{n+1}/F_n = \varphi{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
The key is to track {{< m >}}a_n{{< /m >}} and {{< m >}}b_n{{< /m >}} separately. Under one parallel rewriting step, each {{< m >}}A{{< /m >}} produces one {{< m >}}A{{< /m >}} and one {{< m >}}B{{< /m >}}, while each {{< m >}}B{{< /m >}} produces one {{< m >}}A{{< /m >}}. Therefore:

{{< dm >}}a_{n+1} = a_n + b_n, \qquad b_{n+1} = a_n{{< /dm >}}

It follows that {{< m >}}F_{n+1} = a_{n+1} + b_{n+1} = (a_n + b_n) + a_n = F_n + a_n = F_n + b_{n+1}{{< /m >}}. Since {{< m >}}b_{n+1} = a_n = F_{n-1} - b_{n-1} + b_{n-1} \cdots{{< /m >}}, a simpler path: {{< m >}}a_n = F_{n-1}{{< /m >}} and {{< m >}}b_n = F_{n-2}{{< /m >}} (verifiable by induction), so {{< m >}}F_n = F_{n-1} + F_{n-2}{{< /m >}}. The ratio {{< m >}}F_{n+1}/F_n \to \varphi{{< /m >}} is a classical result from the characteristic equation {{< m >}}x^2 = x + 1{{< /m >}}, whose positive root is {{< m >}}\varphi{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Parallel vs Sequential Rewriting" label="Theorem 49.2" >}}
Let {{< m >}}\mathcal{G} = (V_N, V_T, S, \mathcal{R}){{< /m >}} be a context-free grammar and {{< m >}}\mathcal{L} = (V, \omega, P){{< /m >}} be a D0L-system over the same alphabet and rules. Starting from the same axiom with a single nonterminal, the set of strings derivable in {{< m >}}\mathcal{G}{{< /m >}} in exactly {{< m >}}k{{< /m >}} sequential steps is **strictly larger** than the single string {{< m >}}w^{(k)}{{< /m >}} produced by {{< m >}}\mathcal{L}{{< /m >}} in {{< m >}}k{{< /m >}} parallel steps, unless all production rules are of the form {{< m >}}A \to a{{< /m >}} (terminal productions).
{{< /theorem >}}

{{< proof >}}
In a CFG, at each derivation step one nonterminal is chosen and expanded; the choice of *which* nonterminal to expand may differ, yielding multiple possible derived strings. In an L-system, the parallel map {{< m >}}w \mapsto P(w_1)P(w_2)\cdots P(w_n){{< /m >}} is a **function** — it admits no choice. Hence from a given string, one application of {{< m >}}P{{< /m >}} produces exactly one successor. The CFG's derivation relation is a binary relation (many-to-many), whereas the L-system's rewriting relation is a function (one-to-one). When rules are non-trivial ({{< m >}}P(A){{< /m >}} contains more than one symbol), multiple nonterminals in the CFG string can each be chosen first, producing different intermediate strings — none of which match the L-system's single deterministic output. {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *中文:* "L 系统是并行重写：每一步同时替换所有字符。并行重写产生了自相似结构——每个局部都是整体的缩小版。这是植物生长的基本机制。"

{{< theorem name="Hausdorff Dimension of the Koch Curve" label="Theorem 49.3" >}}
The Koch curve, generated by the L-system with rule {{< m >}}F \to F{+}F{-}F{-}F{+}F{{< /m >}} and angle {{< m >}}\alpha = 90°{{< /m >}}, has Hausdorff dimension

{{< dm >}}d_H(\text{Koch}) = \frac{\log 4}{\log 3} \approx 1.2619{{< /dm >}}

In particular, {{< m >}}d_H{{< /m >}} is strictly between 1 (line) and 2 (plane).
{{< /theorem >}}

{{< proof >}}
After one application of the rule, each segment of length {{< m >}}\ell{{< /m >}} is replaced by {{< m >}}N = 4{{< /m >}} segments each of length {{< m >}}\ell/3{{< /m >}} (the scaling ratio is {{< m >}}r = 1/3{{< /m >}} because the original segment is divided into thirds, with the middle third replaced by two sides of an equilateral triangle). By the Moran equation for self-similar sets with a single scaling ratio, the similarity dimension satisfies

{{< dm >}}N \cdot r^{d_H} = 1 \quad \Longrightarrow \quad 4 \cdot (1/3)^{d_H} = 1 \quad \Longrightarrow \quad d_H = \frac{\log 4}{\log 3}{{< /dm >}}

Under the open set condition (which holds for the Koch curve by geometric inspection), the similarity dimension equals the Hausdorff dimension. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Golden Angle Optimality" label="Theorem 49.4" >}}
Among all angular offsets {{< m >}}\alpha \in (0°, 360°){{< /m >}}, the golden angle {{< m >}}\alpha_g = 360° / \varphi^2 \approx 137.5°{{< /m >}} uniquely minimizes clustering: for any number {{< m >}}n{{< /m >}} of elements placed at successive offsets {{< m >}}\alpha_g{{< /m >}}, no two elements occupy the same angular position (mod {{< m >}}360°{{< /m >}}), and the gaps between elements are as uniform as possible at every scale. This follows because {{< m >}}\varphi{{< /m >}} has the slowest-converging continued fraction expansion among all positive reals.
{{< /theorem >}}

{{< proof >}}
The continued fraction expansion of {{< m >}}\varphi{{< /m >}} is {{< m >}}[1; 1, 1, 1, \ldots]{{< /m >}} — all partial quotients equal 1, which are the smallest possible. By the theory of continued fractions (Hurwitz's theorem), a number with all partial quotients equal to 1 is the hardest to approximate by rationals: for any rational {{< m >}}p/q{{< /m >}}, {{< m >}}|\varphi - p/q| > 1/(\sqrt{5}\, q^2){{< /m >}}, and this bound is tight. An offset of {{< m >}}\alpha_g = 2\pi(1 - 1/\varphi) = 2\pi/\varphi^2{{< /m >}} radians corresponds to the irrational rotation by {{< m >}}1/\varphi^2{{< /m >}} of the circle. Since {{< m >}}1/\varphi^2{{< /m >}} is never well-approximated by a rational {{< m >}}p/q{{< /m >}}, no {{< m >}}n{{< /m >}} consecutive placements cluster near any arc. The **three-distance theorem** (Steinhaus 1950) then guarantees that {{< m >}}n{{< /m >}} points placed at offsets {{< m >}}\{k/\varphi^2 \bmod 1\}_{k=0}^{n-1}{{< /m >}} create gaps of at most three distinct lengths — the most uniform possible for an irrational rotation. {{< m >}}\square{{< /m >}}
{{< /proof >}}

**Fibonacci L-system string length:**

For the rules {{< m >}}A \to AB{{< /m >}}, {{< m >}}B \to A{{< /m >}}, the string length at step {{< m >}}n{{< /m >}} is {{< m >}}F_{n+2}{{< /m >}} (the {{< m >}}(n+2){{< /m >}}-th Fibonacci number):

{{< dm >}}|w^{(0)}| = 1, \quad |w^{(1)}| = 2, \quad |w^{(2)}| = 3, \quad |w^{(3)}| = 5, \quad |w^{(4)}| = 8, \quad |w^{(10)}| = 144{{< /dm >}}

The ratio {{< m >}}|w^{(n+1)}| / |w^{(n)}|{{< /m >}} converges to {{< m >}}\varphi \approx 1.618{{< /m >}} exponentially fast: by step {{< m >}}n = 10{{< /m >}}, the ratio {{< m >}}144/89 = 1.6180\ldots{{< /m >}} agrees with {{< m >}}\varphi{{< /m >}} to four decimal places.

**Golden angle phyllotaxis:** In a sunflower with 89 clockwise spirals and 55 counterclockwise spirals, the ratio {{< m >}}89/55 \approx 1.618{{< /m >}}. With 144 seeds placed at successive golden-angle offsets, covering a disk of radius {{< m >}}R{{< /m >}}, the packing density approaches {{< m >}}\pi/(2\sqrt{3}) \approx 90.7\%{{< /m >}} — close to optimal hexagonal packing, achieved without any global coordination.

## Musical Connection / 音乐联系

{{< musical-connection >}}
**The same rules, grown into sound**

The turtle interpretation maps the same L-system alphabet to music: {{< m >}}F{{< /m >}} becomes a note event, {{< m >}}+{{< /m >}} and {{< m >}}-{{< /m >}} become ascending and descending pitch steps (by a chosen interval {{< m >}}\alpha{{< /m >}}), and bracket pairs {{< m >}}[\cdots]{{< /m >}} produce simultaneous harmonic branches (chords or ornaments).

With the Fibonacci rules {{< m >}}A \to AB{{< /m >}}, {{< m >}}B \to A{{< /m >}} and the musical assignment {{< m >}}A \mapsto{{< /m >}} quarter note, {{< m >}}B \mapsto{{< /m >}} eighth note, the resulting rhythm at each generation is a longer version of the pattern at the previous generation — **rhythmic self-similarity**. The ratio of quarter to eighth notes at step {{< m >}}n{{< /m >}} is {{< m >}}a_n / b_n = F_{n-1}/F_{n-2} \to \varphi{{< /m >}}: the golden ratio emerges in the rhythmic proportion.

> *中文:* "音乐版本：F 是一个音符，加号是升调，减号是降调，方括号是和弦分支。同一规则，生成旋律结构。"

**Fractal dimension as musical complexity:** The Hausdorff dimension {{< m >}}d_H{{< /m >}} of an L-system's geometric output provides a heuristic measure of structural complexity for its musical counterpart. A melody generated by a Koch-like rule ({{< m >}}d_H \approx 1.26{{< /m >}}) has more local variation than a simple ascending scale ({{< m >}}d_H = 1{{< /m >}}), but less global filling than a random walk ({{< m >}}d_H \to 2{{< /m >}}). This analogy is heuristic: the direct relationship between {{< m >}}d_H{{< /m >}} and perceived musical complexity has not been established in the music cognition literature.

> *中文:* "L 系统生成的旋律，其自相似程度可以用分形维度来类比量化——维度越高，结构越复杂（这是一种启发性类比，分形维度与感知复杂度的直接关系尚未在音乐认知文献中建立）。"

**Golden ratio in musical proportion:** The golden ratio appears as a structural proportion in several celebrated compositions. Bartók's *Music for Strings, Percussion and Celesta* (1936) has been analyzed (Lendvai 1971) as placing the climactic entry of the fugue subject at the golden section of the movement. Whether Bartók deliberately applied {{< m >}}\varphi{{< /m >}} or the effect arises from Fibonacci-structured phrase lengths is debated; the mathematical structure is present regardless of compositional intent.

Dividing a phrase or a form by the golden ratio produces sections of length {{< m >}}\varphi : 1{{< /m >}}, so that the shorter section is to the longer as the longer is to the whole — the defining property of {{< m >}}\varphi{{< /m >}}:

{{< dm >}}\frac{a}{b} = \frac{a+b}{a} = \varphi, \qquad a = \varphi\, b{{< /dm >}}

**Connection to EP16 (CFGs):** The parallel/sequential distinction (Theorem 49.2) connects directly to {{< episode-ref ep="16" >}}EP16's context-free grammars{{< /episode-ref >}}. CFGs model hierarchical musical syntax — phrase structure, cadential patterns — through sequential derivation trees. L-systems extend this to **growth processes** where all sub-structures develop simultaneously, producing the emergent self-similarity absent in CFG derivations.

> *中文:* "自相似性不是复杂算法的结果，而是简单规则多次迭代的涌现属性。"
{{< /musical-connection >}}

## Limits and Open Questions / 局限性与开放问题

1. **Stochastic and context-sensitive L-systems.** The D0L-systems in this episode are deterministic and context-free. Real biological growth involves randomness (stochastic L-systems, SL-systems) and neighbor-dependent rules (context-sensitive L-systems, 2L-systems). The musical analogues — probabilistic melody generation and context-aware harmonization — remain largely unexplored as a unified formal framework.

2. **Fractal dimension and music perception.** The Hausdorff dimension {{< m >}}d_H{{< /m >}} is a geometric invariant of the L-system's output curve. Claiming that {{< m >}}d_H{{< /m >}} directly measures perceived musical complexity requires a psychoacoustic bridge that does not yet exist in the literature. Controlled listening experiments comparing melodies of equal length but differing {{< m >}}d_H{{< /m >}} have not been systematically conducted.

3. **Turtle interpretation is non-canonical.** The mapping from L-system alphabet to musical parameters (which symbol = note, which = pitch shift, what interval {{< m >}}\alpha{{< /m >}}, what time unit) is chosen by the composer, not determined by mathematics. Different interpretations of the same L-system produce entirely different musical surfaces. There is no principled theory of which interpretations preserve musically meaningful structure.

4. **Inversibility.** Given a musical passage, no general algorithm recovers the L-system that generated it, because many L-systems produce the same string at a given iteration and the turtle interpretation is lossy. The inverse problem — L-system inference from a musical surface — is computationally hard (NP-hard in general for string compression problems).

{{< conjecture name="Perceptual Equivalence at Matching Dimension" >}}
Two melodies generated by different L-systems but with the same Hausdorff dimension {{< m >}}d_H{{< /m >}} are rated as equally "complex" or "ornate" by naive listeners in a forced-choice experiment, controlling for tempo, range, and mode.

**Falsification criterion:** A controlled listening study presenting pairs of L-system melodies matched on {{< m >}}d_H{{< /m >}} but differing in production rules finds a statistically significant preference for one over the other, or a significant difference in perceived complexity ratings (e.g., {{< m >}}p < 0.05{{< /m >}} on a paired {{< m >}}t{{< /m >}}-test). Such a result would demonstrate that {{< m >}}d_H{{< /m >}} is not the relevant perceptual invariant, motivating a search for a dimensionless musical complexity measure beyond fractal geometry.
{{< /conjecture >}}

5. **Golden ratio in composition: design or coincidence?** The appearances of {{< m >}}\varphi{{< /m >}} in analyses of Bartók, Debussy, and others (Lendvai 1971; Howat 1983) remain contested. Without access to compositional sketches or explicit composer statements, it is impossible to distinguish deliberate golden-section planning from the analyst's selection bias (finding {{< m >}}\varphi{{< /m >}} where Fibonacci-approximated phrase lengths happen to appear).
