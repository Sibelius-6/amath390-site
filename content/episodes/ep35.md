## Overview

A single recorded note in a sampler like Kontakt can produce 88 different pitches — not by storing 88 separate recordings, but by mathematically stretching or compressing one recording. The tool that makes this possible is the **phase vocoder**, a signal processing algorithm that separates a sound into magnitude and phase components via the Short-Time Fourier Transform, then manipulates those components to achieve pitch shifting and time stretching independently.

The central mathematical challenge is phase continuity. Naive pitch shifting — simply resampling a signal at a different rate — changes duration alongside pitch. The phase vocoder solves this by working frame-by-frame in the frequency domain: it estimates the **true instantaneous frequency** in each spectral bin from the phase difference between adjacent frames, scales those frequencies by a desired ratio, and then reconstructs a phase-continuous output signal. The reconstruction is only valid if the analysis and synthesis windows satisfy the **Constant Overlap-Add (COLA)** condition, which constrains the joint choice of window function and hop size.

This episode builds the full mathematical picture: STFT definition and phase advance, phase unwrapping and instantaneous frequency estimation, pitch-shift by frequency scaling, time-stretch by separating analysis and synthesis hop sizes, and the COLA condition for perfect reconstruction.

## Definitions

{{< definition name="Short-Time Fourier Transform (STFT)" label="Definition 35.1" >}}
Let {{< m >}}x[n]{{< /m >}} be a discrete-time signal and {{< m >}}w[n]{{< /m >}} a window function of length {{< m >}}L{{< /m >}}. The **Short-Time Fourier Transform** of {{< m >}}x{{< /m >}} at frame {{< m >}}m{{< /m >}} and frequency bin {{< m >}}k{{< /m >}} is

{{< dm >}}X[k,m] = \sum_{n=0}^{L-1} x[n + m \cdot H_a]\, w[n]\, e^{-i\, 2\pi k n / L},{{< /dm >}}

where {{< m >}}H_a{{< /m >}} is the **analysis hop size** (the number of samples the window advances between consecutive frames), and {{< m >}}k = 0, 1, \ldots, L-1{{< /m >}}. The STFT output is a complex-valued time-frequency matrix with magnitude {{< m >}}|X[k,m]|{{< /m >}} and phase {{< m >}}\phi[k,m] = \arg(X[k,m]){{< /m >}}.
{{< /definition >}}

{{< definition name="Spectrogram" label="Definition 35.2" >}}
The **spectrogram** of a signal is the magnitude-squared STFT,
{{< dm >}}\mathcal{S}[k,m] = |X[k,m]|^2.{{< /dm >}}
It represents the distribution of signal energy across time (frame index {{< m >}}m{{< /m >}}) and frequency (bin {{< m >}}k{{< /m >}}). The STFT yields strictly more information than the spectrogram: the phase {{< m >}}\phi[k,m]{{< /m >}} is discarded when forming {{< m >}}\mathcal{S}{{< /m >}}, and is irretrievably lost.
{{< /definition >}}

{{< definition name="Expected Phase Advance" label="Definition 35.3" >}}
The **center angular frequency** of bin {{< m >}}k{{< /m >}} is {{< m >}}\omega_k = 2\pi k / L{{< /m >}}. If a pure sinusoid at exactly {{< m >}}\omega_k{{< /m >}} is analyzed, the phase advances by a fixed amount between consecutive frames. The **expected phase advance** for bin {{< m >}}k{{< /m >}} over one analysis hop {{< m >}}H_a{{< /m >}} is
{{< dm >}}\Delta\phi_{\text{expected}}[k] = \omega_k \cdot H_a = \frac{2\pi k H_a}{L}.{{< /dm >}}
{{< /definition >}}

{{< definition name="Phase Deviation and Instantaneous Frequency" label="Definition 35.4" >}}
Let {{< m >}}\Delta\phi_{\text{actual}}[k,m] = \phi[k,m] - \phi[k,m-1]{{< /m >}} be the observed phase difference between frame {{< m >}}m{{< /m >}} and frame {{< m >}}m-1{{< /m >}}, after **phase unwrapping** (see Proposition 35.1 below). The **phase deviation** is
{{< dm >}}\delta\phi[k,m] = \mathcal{W}\bigl(\Delta\phi_{\text{actual}}[k,m] - \Delta\phi_{\text{expected}}[k]\bigr),{{< /dm >}}
where {{< m >}}\mathcal{W}(\cdot){{< /m >}} denotes wrapping to {{< m >}}(-\pi, \pi]{{< /m >}}. The **instantaneous angular frequency** at bin {{< m >}}k{{< /m >}} in frame {{< m >}}m{{< /m >}} is
{{< dm >}}\omega_{\text{true}}[k,m] = \omega_k + \frac{\delta\phi[k,m]}{H_a}.{{< /dm >}}
{{< /definition >}}

{{< definition name="COLA Condition" label="Definition 35.5" >}}
A window function {{< m >}}w[n]{{< /m >}} and hop size {{< m >}}H{{< /m >}} satisfy the **Constant Overlap-Add (COLA)** condition if
{{< dm >}}\sum_{m=-\infty}^{\infty} w[n - m \cdot H] = C \quad \forall\, n,{{< /dm >}}
for some nonzero constant {{< m >}}C{{< /m >}}. In the WOLA (Weighted Overlap-Add) variant used in many phase vocoder implementations, the condition is imposed on the squared window:
{{< dm >}}\sum_{m=-\infty}^{\infty} w^2[n - m \cdot H] = C \quad \forall\, n.{{< /dm >}}
The WOLA form is needed when both the analysis and synthesis paths apply the window, so that the product of the two windows sums to a constant.
{{< /definition >}}

{{< definition name="Analysis and Synthesis Hop Sizes" label="Definition 35.6" >}}
In a phase vocoder configured for **time stretching** by factor {{< m >}}\alpha > 0{{< /m >}}, the analysis hop size {{< m >}}H_a{{< /m >}} and synthesis hop size {{< m >}}H_s{{< /m >}} are related by
{{< dm >}}H_s = \alpha \cdot H_a.{{< /dm >}}
When {{< m >}}\alpha > 1{{< /m >}} the output is longer than the input (time expansion); when {{< m >}}\alpha < 1{{< /m >}} it is shorter (time compression). Pitch is unchanged when only the hop ratio is altered and phase is correctly propagated.
{{< /definition >}}

## Main Theorems / 主要定理

{{< theorem name="STFT Phase Advance Formula" label="Theorem 35.1" >}}
If {{< m >}}x[n] = A e^{i\omega_0 n}{{< /m >}} is a complex exponential at angular frequency {{< m >}}\omega_0{{< /m >}}, the STFT phase at bin {{< m >}}k{{< /m >}} satisfies
{{< dm >}}\phi[k, m] = \phi[k, 0] + m \cdot \omega_0 \cdot H_a + \psi_k,{{< /dm >}}
where {{< m >}}\psi_k{{< /m >}} is a constant depending only on {{< m >}}k{{< /m >}} and the window {{< m >}}w{{< /m >}}. In particular, the phase increments between consecutive frames at fixed bin {{< m >}}k{{< /m >}} are constant and equal to {{< m >}}\omega_0 H_a{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
Substituting {{< m >}}x[n + mH_a] = A e^{i\omega_0(n + mH_a)}{{< /m >}} into Definition 35.1:
{{< dm >}}X[k,m] = \sum_{n=0}^{L-1} A e^{i\omega_0(n+mH_a)}\, w[n]\, e^{-i2\pi kn/L}.{{< /dm >}}
Factor out the term that depends on {{< m >}}m{{< /m >}}:
{{< dm >}}X[k,m] = A e^{i\omega_0 m H_a} \sum_{n=0}^{L-1} w[n]\, e^{i(\omega_0 - \omega_k)n}.{{< /dm >}}
The sum is a constant {{< m >}}G_k \in \mathbb{C}{{< /m >}} (the window's frequency response evaluated at {{< m >}}\omega_0 - \omega_k{{< /m >}}), independent of {{< m >}}m{{< /m >}}. Write {{< m >}}G_k = |G_k| e^{i\psi_k}{{< /m >}}. Then
{{< dm >}}\phi[k,m] = \arg(X[k,m]) = \omega_0 m H_a + \arg(A) + \psi_k,{{< /dm >}}
which establishes the linear growth with slope {{< m >}}\omega_0 H_a{{< /m >}} and confirms that the frame-to-frame phase increment equals {{< m >}}\omega_0 H_a{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< proposition label="Prop 35.1" name="Phase Unwrapping" >}}
Measured phases {{< m >}}\phi[k,m]{{< /m >}} are confined to {{< m >}}(-\pi, \pi]{{< /m >}} by the {{< m >}}\arg{{< /m >}} operation. When the true phase increment {{< m >}}\omega_0 H_a{{< /m >}} exceeds {{< m >}}\pi{{< /m >}} in magnitude, the observed difference {{< m >}}\phi[k,m] - \phi[k,m-1]{{< /m >}} undergoes a discontinuous "wrap." Phase unwrapping corrects for these wraps by adding the unique integer multiple of {{< m >}}2\pi{{< /m >}} that brings the difference into {{< m >}}(-\pi, \pi]{{< /m >}}:
{{< dm >}}\Delta\phi_{\text{unwrapped}}[k,m] = \Delta\phi_{\text{raw}}[k,m] + 2\pi \cdot \operatorname{round}\!\left(\frac{-\Delta\phi_{\text{raw}}[k,m]}{2\pi}\right).{{< /dm >}}
After unwrapping, {{< m >}}\Delta\phi_{\text{unwrapped}}{{< /m >}} recovers the true phase increment and the instantaneous frequency formula (Definition 35.4) is valid.
{{< /proposition >}}

{{< theorem name="Instantaneous Frequency Estimation" label="Theorem 35.2" >}}
Under the local stationarity assumption that the signal in frame {{< m >}}m{{< /m >}} is well approximated by a single sinusoid at frequency {{< m >}}\omega_{\text{true}}[k,m]{{< /m >}}, the instantaneous frequency in bin {{< m >}}k{{< /m >}} is unambiguously estimated as
{{< dm >}}\omega_{\text{true}}[k,m] = \omega_k + \frac{\mathcal{W}\!\left(\phi[k,m] - \phi[k,m-1] - \omega_k H_a\right)}{H_a},{{< /dm >}}
provided the true frequency deviation {{< m >}}|\omega_{\text{true}} - \omega_k|{{< /m >}} satisfies {{< m >}}|\omega_{\text{true}} - \omega_k| < \pi / H_a{{< /m >}} (i.e., it stays within half a bin width in terms of the wrapped phase range).
{{< /theorem >}}

{{< proof >}}
By Theorem 35.1, a pure tone at {{< m >}}\omega_{\text{true}}{{< /m >}} contributes a phase increment {{< m >}}\omega_{\text{true}} H_a{{< /m >}} in bin {{< m >}}k{{< /m >}}. The observed raw difference is
{{< dm >}}\Delta\phi_{\text{raw}} = \omega_{\text{true}} H_a + 2\pi p{{< /dm >}}
for some integer {{< m >}}p{{< /m >}} introduced by the {{< m >}}\arg{{< /m >}} wrapping. Subtracting the expected advance:
{{< dm >}}\Delta\phi_{\text{raw}} - \omega_k H_a = (\omega_{\text{true}} - \omega_k) H_a + 2\pi p.{{< /dm >}}
Wrapping this residual into {{< m >}}(-\pi, \pi]{{< /m >}} recovers {{< m >}}(\omega_{\text{true}} - \omega_k) H_a{{< /m >}} uniquely as long as its magnitude is less than {{< m >}}\pi{{< /m >}}, i.e., {{< m >}}|\omega_{\text{true}} - \omega_k| < \pi/H_a{{< /m >}}. Dividing by {{< m >}}H_a{{< /m >}} and adding {{< m >}}\omega_k{{< /m >}} yields the formula. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="COLA Condition for Perfect Reconstruction" label="Theorem 35.3" >}}
Let the synthesis signal be formed by the overlap-add of windowed inverse-STFT frames,
{{< dm >}}y[n] = \frac{1}{C}\sum_{m} \left(\sum_{k=0}^{L-1} X[k,m]\, e^{i2\pi kn/L}\right) w_s[n - mH],{{< /dm >}}
where {{< m >}}w_s{{< /m >}} is the synthesis window. If the analysis and synthesis windows satisfy the COLA condition {{< m >}}\sum_m w_a[n-mH]\, w_s[n-mH] = C{{< /m >}} for all {{< m >}}n{{< /m >}}, then {{< m >}}y = x{{< /m >}} (perfect reconstruction when no frequency modifications are applied).
{{< /theorem >}}

{{< proof >}}
Substituting the STFT definition into the overlap-add formula and exchanging summation order:
{{< dm >}}y[n] = \frac{1}{C}\sum_{m} w_s[n-mH] \sum_{j} x[j]\, w_a[j-mH] \underbrace{\frac{1}{L}\sum_k e^{i2\pi k(n-j)/L}}_{\delta[n-j]}.{{< /dm >}}
The inner DFT sum equals the Kronecker delta {{< m >}}\delta[n-j]{{< /m >}}, so the {{< m >}}j{{< /m >}} sum collapses to {{< m >}}x[n]\, w_a[n-mH]{{< /m >}}:
{{< dm >}}y[n] = \frac{x[n]}{C} \sum_{m} w_a[n-mH]\, w_s[n-mH].{{< /dm >}}
Applying the COLA condition, the sum equals {{< m >}}C{{< /m >}} for all {{< m >}}n{{< /m >}}, giving {{< m >}}y[n] = x[n]{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Hann Window Satisfies COLA at 50% Overlap" label="Theorem 35.4" >}}
The Hann window {{< m >}}w[n] = \tfrac{1}{2}\!\left(1 - \cos\!\tfrac{2\pi n}{L}\right){{< /m >}} for {{< m >}}n = 0, \ldots, L-1{{< /m >}} satisfies the WOLA condition {{< m >}}\sum_m w^2[n - mH] = \text{const}{{< /m >}} when the hop size is {{< m >}}H = L/2{{< /m >}} (50% overlap), with constant value {{< m >}}3/4{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
At 50% overlap, {{< m >}}H = L/2{{< /m >}}, so at each sample position {{< m >}}n{{< /m >}} exactly two windows overlap: the one centered at {{< m >}}mH{{< /m >}} and the one at {{< m >}}(m+1)H{{< /m >}}. Within the support of two successive windows with offset {{< m >}}H{{< /m >}}, define {{< m >}}u = 2\pi n/L \in [0, \pi){{< /m >}} for the first window and {{< m >}}u - \pi{{< /m >}} for the second. Then:
{{< dm >}}w^2(u) + w^2(u+\pi) = \frac{1}{4}(1-\cos u)^2 + \frac{1}{4}(1-\cos(u+\pi))^2.{{< /dm >}}
Since {{< m >}}\cos(u+\pi) = -\cos u{{< /m >}}:
{{< dm >}}= \frac{1}{4}(1-\cos u)^2 + \frac{1}{4}(1+\cos u)^2 = \frac{1}{4}\bigl(2 + 2\cos^2 u\bigr) = \frac{1}{2}(1 + \cos^2 u).{{< /dm >}}
Using {{< m >}}\cos^2 u = (1+\cos 2u)/2{{< /m >}}:
{{< dm >}}= \frac{1}{2}\!\left(1 + \frac{1+\cos 2u}{2}\right) = \frac{3}{4} + \frac{\cos 2u}{4}.{{< /dm >}}
This is not identically {{< m >}}3/4{{< /m >}}; the Hann window at exactly 50% overlap does not satisfy the squared-sum COLA exactly. However, at **75% overlap** ({{< m >}}H = L/4{{< /m >}}), four windows contribute at each point and the squared sum is identically constant. For the **standard (unsquared) COLA** at 50% overlap, the Hann window sum {{< m >}}\sum_m w[n-mH]{{< /m >}} does equal {{< m >}}1{{< /m >}} identically: with two overlapping windows,
{{< dm >}}w(u) + w(u+\pi) = \tfrac{1}{2}(1-\cos u) + \tfrac{1}{2}(1+\cos u) = 1.{{< /dm >}}
Thus the Hann window at 50% overlap satisfies the standard OLA-COLA condition with constant {{< m >}}C = 1{{< /m >}}, guaranteeing energy-flat overlap-add reconstruction in the OLA framework. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Phase Vocoder Pitch-Shift Theorem" label="Theorem 35.5" >}}
To shift all spectral components of {{< m >}}x[n]{{< /m >}} upward by frequency ratio {{< m >}}r > 0{{< /m >}}:

1. Compute the STFT to obtain {{< m >}}X[k,m]{{< /m >}}.
2. Estimate {{< m >}}\omega_{\text{true}}[k,m]{{< /m >}} via Theorem 35.2.
3. Replace each true frequency by {{< m >}}\omega_{\text{shifted}}[k,m] = r \cdot \omega_{\text{true}}[k,m]{{< /m >}}.
4. Propagate a phase-continuous output phase:
{{< dm >}}\phi_{\text{out}}[k,m] = \phi_{\text{out}}[k,m-1] + r \cdot \omega_{\text{true}}[k,m] \cdot H_a.{{< /dm >}}
5. Reconstruct using {{< m >}}Y[k,m] = |X[k,m]|\, e^{i\phi_{\text{out}}[k,m]}{{< /m >}} followed by overlap-add synthesis.

The output {{< m >}}y[n]{{< /m >}} contains the same spectral magnitudes as {{< m >}}x[n]{{< /m >}} but all instantaneous frequencies scaled by {{< m >}}r{{< /m >}}, with no change in duration.
{{< /theorem >}}

{{< proof >}}
The proof has two parts: correctness of frequency scaling, and phase continuity.

**Frequency scaling.** The synthesis frame is constructed with magnitude {{< m >}}|X[k,m]|{{< /m >}} (unchanged) and a new phase whose increment per frame is {{< m >}}r \cdot \omega_{\text{true}}[k,m] \cdot H_a{{< /m >}}. By the inverse of Theorem 35.1, a STFT frame with that phase increment, when inverse-transformed, yields a local sinusoid at instantaneous frequency {{< m >}}r \cdot \omega_{\text{true}}[k,m]{{< /m >}}. Therefore every spectral component is scaled by {{< m >}}r{{< /m >}}.

**Phase continuity.** The output phase is defined by the recurrence {{< m >}}\phi_{\text{out}}[k,m] = \phi_{\text{out}}[k,m-1] + r \cdot \omega_{\text{true}}[k,m] \cdot H_a{{< /m >}}. By construction this is a cumulative sum — there are no discontinuities between frames. If the synthesis used the raw (wrapped) analysis phase instead, adjacent frames would have inconsistent phase relationships, producing comb-filter artifacts (metallic distortion) when overlap-added. The recurrence guarantees a smooth phase trajectory.

**Duration unchanged.** Both analysis and synthesis use the same hop size {{< m >}}H_a{{< /m >}}, so the same number of frames covers the same total duration. The output signal has the same number of samples as the input. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Phase Correction for Time Stretching" label="Theorem 35.6" >}}
To stretch the duration of {{< m >}}x[n]{{< /m >}} by factor {{< m >}}\alpha{{< /m >}} without changing pitch, set the synthesis hop {{< m >}}H_s = \alpha H_a{{< /m >}} and propagate output phases as:
{{< dm >}}\phi_{\text{out}}[k,m] = \phi_{\text{out}}[k,m-1] + \omega_{\text{true}}[k,m] \cdot H_s.{{< /dm >}}
The resulting signal {{< m >}}y[n]{{< /m >}} has duration {{< m >}}\alpha{{< /m >}} times that of {{< m >}}x[n]{{< /m >}} and retains the original pitch.
{{< /theorem >}}

{{< proof >}}
**Duration scaling.** The analysis processes {{< m >}}M{{< /m >}} frames from {{< m >}}x{{< /m >}}, covering a total of {{< m >}}M \cdot H_a{{< /m >}} input samples. Synthesis places those {{< m >}}M{{< /m >}} frames with spacing {{< m >}}H_s = \alpha H_a{{< /m >}}, covering {{< m >}}M \cdot H_s = \alpha M H_a{{< /m >}} output samples. The duration ratio is {{< m >}}\alpha{{< /m >}}.

**Pitch preservation.** The pitch of the output is determined by the instantaneous frequencies of the synthesis frames. The phase increment per synthesis frame at bin {{< m >}}k{{< /m >}} is {{< m >}}\omega_{\text{true}}[k,m] \cdot H_s{{< /m >}}. The corresponding angular frequency of the synthesized sinusoid is the increment divided by the synthesis hop:
{{< dm >}}\frac{\phi_{\text{out}}[k,m] - \phi_{\text{out}}[k,m-1]}{H_s} = \frac{\omega_{\text{true}}[k,m] \cdot H_s}{H_s} = \omega_{\text{true}}[k,m].{{< /dm >}}
The instantaneous frequency is {{< m >}}\omega_{\text{true}}[k,m]{{< /m >}}, identical to the analysis frequency. Since no frequency scaling is applied, the pitch is preserved.

**Why naive repositioning fails.** If the raw analysis phases {{< m >}}\phi[k,m]{{< /m >}} were used directly in the repositioned synthesis frames without recurrence, consecutive frames would carry phase values appropriate for positions {{< m >}}m H_a{{< /m >}} but placed at positions {{< m >}}m H_s{{< /m >}}. The mismatch {{< m >}}\phi[k,m] - \phi[k,m-1] \neq \omega_{\text{true}} H_s{{< /m >}} produces phase discontinuities at frame boundaries, causing comb-filter (metallic) distortion in the overlap-add sum. The recurrence eliminates this. {{< m >}}\square{{< /m >}}
{{< /proof >}}

## Numerical Examples

### Example 1: Phase advance for a pure tone

Let {{< m >}}L = 1024{{< /m >}}, {{< m >}}H_a = 256{{< /m >}}, sample rate {{< m >}}f_s = 44100{{< /m >}} Hz. Consider a pure tone at {{< m >}}f_0 = 440{{< /m >}} Hz (A4).

The angular frequency is {{< m >}}\omega_0 = 2\pi \cdot 440 / 44100 \approx 0.06267{{< /m >}} rad/sample. The nearest bin is
{{< dm >}}k_0 = \operatorname{round}\!\left(\frac{440 \cdot 1024}{44100}\right) = \operatorname{round}(10.22) = 10.{{< /dm >}}
The center frequency of bin 10 is {{< m >}}\omega_{10} = 2\pi \cdot 10 / 1024 \approx 0.06136{{< /m >}} rad/sample.

Expected phase advance per hop: {{< m >}}\Delta\phi_{\text{expected}} = \omega_{10} \cdot 256 \approx 15.71{{< /m >}} rad.

True phase advance per hop: {{< m >}}\Delta\phi_{\text{true}} = \omega_0 \cdot 256 \approx 16.04{{< /m >}} rad.

Phase deviation: {{< m >}}\delta\phi = 16.04 - 15.71 = 0.33{{< /m >}} rad (no unwrapping needed since {{< m >}}|\delta\phi| \ll \pi{{< /m >}}).

Instantaneous frequency: {{< m >}}\omega_{\text{true}} = \omega_{10} + 0.33/256 = 0.06136 + 0.00129 = 0.06265{{< /m >}} rad/sample, recovering {{< m >}}f_0 = 0.06265 \cdot 44100 / (2\pi) \approx 440{{< /m >}} Hz. The estimate is accurate to within measurement resolution.

### Example 2: Pitch shifting by a perfect fifth

A perfect fifth corresponds to frequency ratio {{< m >}}r = 3/2 = 1.5{{< /m >}}.

For the 440 Hz tone above, shifted frequency: {{< m >}}\omega_{\text{shifted}} = 1.5 \times 0.06265 = 0.09397{{< /m >}} rad/sample, corresponding to {{< m >}}f = 0.09397 \times 44100/(2\pi) \approx 660{{< /m >}} Hz (E5).

Output phase after frame {{< m >}}m{{< /m >}} (starting from {{< m >}}\phi_{\text{out}}[k,0] = 0{{< /m >}}):
{{< dm >}}\phi_{\text{out}}[k,m] = m \cdot 1.5 \cdot \omega_{\text{true}} \cdot H_a \approx m \cdot 1.5 \times 16.04 = m \cdot 24.06 \text{ rad}.{{< /dm >}}
Each frame receives a consistent phase increment of 24.06 rad, ensuring a smooth sinusoid at 660 Hz in the output.

### Example 3: Time stretching by 1.5x

With {{< m >}}\alpha = 1.5{{< /m >}}, {{< m >}}H_a = 256{{< /m >}}, the synthesis hop is {{< m >}}H_s = 384{{< /m >}} samples.

Phase recurrence for the 440 Hz bin:
{{< dm >}}\phi_{\text{out}}[k,m] = \phi_{\text{out}}[k,m-1] + 0.06265 \times 384 \approx \phi_{\text{out}}[k,m-1] + 24.06 \text{ rad}.{{< /dm >}}
The output instantaneous frequency is {{< m >}}24.06 / 384 = 0.06265{{< /m >}} rad/sample — unchanged at 440 Hz. A 5-second input (220,500 samples at 44.1 kHz) produces a 7.5-second output (330,750 samples), stretched by exactly {{< m >}}\alpha = 1.5{{< /m >}}.

### Example 4: COLA check — Hann at 50% overlap

With {{< m >}}L = 8{{< /m >}} and {{< m >}}H = 4{{< /m >}}, consecutive Hann windows centered at {{< m >}}n = 0{{< /m >}} and {{< m >}}n = 4{{< /m >}} are:
{{< dm >}}w[n] = \tfrac{1}{2}\!\left(1 - \cos\frac{2\pi n}{8}\right), \quad w[n-4] = \tfrac{1}{2}\!\left(1 - \cos\frac{2\pi(n-4)}{8}\right).{{< /dm >}}
At {{< m >}}n=2{{< /m >}}: {{< m >}}w[2] = \tfrac{1}{2}(1-\cos(\pi/2)) = 1/2{{< /m >}} and {{< m >}}w[2-4] = w[-2]{{< /m >}} wraps to {{< m >}}w[6] = \tfrac{1}{2}(1-\cos(3\pi/2)) = 1/2{{< /m >}}. Sum: {{< m >}}1/2 + 1/2 = 1{{< /m >}}. This confirms the OLA-COLA condition at 50% overlap (Theorem 35.4).

## Musical Connection / 音乐联系

{{< musical-connection >}}
The phase vocoder is the mathematical engine behind some of the most familiar sounds in modern music production.

**Sampler instruments.** A sampler records a note at one pitch (the "root note") and uses the phase vocoder — or its lightweight cousin, wavetable synthesis — to render every other pitch on the keyboard from that single recording. Kontakt, Omnisphere, and similar instruments rely on this: one carefully recorded cello note becomes an entire playable cello section.

**The "chipmunk effect" and autotune.** Setting {{< m >}}r \gg 1{{< /m >}} in pitch shifting pushes all frequencies upward, compressing the spectral content into a high-frequency range. The voice sounds thin and cartoon-like because harmonic spacing and formant positions all shift together. Professional pitch correction (Melodyne, Auto-Tune) avoids this by **formant preservation**: the spectral envelope (formant curve) is extracted, separated from the fine harmonic structure, and shifted independently so that only the fundamental pitch moves while the vocal timbre (vowel quality) remains natural.

**Time-stretching in DAWs.** Every digital audio workstation — Logic, Ableton, Reaper — uses a variant of the phase vocoder time-stretch algorithm when the user warps audio to a different tempo. The analysis/synthesis hop ratio {{< m >}}\alpha = H_s/H_a{{< /m >}} directly maps to the tempo change factor. Phase vocoder artifacts (the "phasiness" or metallic quality on transients) motivate further refinements such as transient detection, which switches to a waveform-copy method around percussive events.

**Wavetable synthesis.** The lighter-weight alternative described in this episode stores a single waveform period and varies playback speed to control pitch. The interpolation kernel used between samples is mathematically identical to the sinc reconstruction studied in {{< episode-ref ep="30" >}}EP30: The Sampling Theorem{{< /episode-ref >}}: linear interpolation is a piecewise-linear approximation to sinc, while windowed-sinc interpolation achieves ideal reconstruction within the Nyquist bandwidth.

**Looking ahead.** The Short-Time Fourier Transform has a deeper foundation: in EP36, we will see that the time-frequency resolution of the STFT is constrained by the Gabor uncertainty principle, established in 1946 — a musical analogue of the Heisenberg uncertainty principle that fundamentally limits how precisely a sound can be localized in both time and frequency simultaneously. EP42 will revisit these ideas in the context of wavelet analysis, which adapts the window width to frequency and can overcome some of STFT's resolution tradeoffs.

## Limits and Open Questions / 局限性与开放问题

**Transient smearing.** The phase vocoder assumes local stationarity — each frame is well modeled by a superposition of sinusoids. Percussive transients (drum hits, plucked strings) violate this assumption severely. Time-stretching a snare drum with a standard phase vocoder produces a characteristic "pre-echo" or "flamming" artifact as the transient energy is spread across adjacent frames. State-of-the-art solutions (transient detection, phase locking, object-based coding) partially address this, but perfect transient preservation under time-stretching remains an active research area.

**Polyphony and phase locking.** When multiple harmonic partials of the same note are present, the relative phases between bins at harmonically related frequencies encode important perceptual cues (the "shape" of the attack and the coherence of the instrument body). Naively scaling all phases independently can destroy this coherence. Phase locking algorithms propagate phase corrections from the analysis bin at the fundamental frequency up through its harmonics, preserving perceptually important phase relationships. The optimal phase locking strategy for complex polyphonic signals is still an open problem.

**Pitch shifting limits.** Very large pitch ratios (e.g., {{< m >}}r = 4{{< /m >}}, two octaves up) produce audible artifacts even with phase-continuous processing, because the assumed one-sinusoid-per-bin model breaks down as the scaled frequencies of different bins overlap. This motivates resampling-based approaches for large pitch changes, or source-separation preprocessing.

**The uncertainty principle.** The STFT window length {{< m >}}L{{< /m >}} controls a fundamental tradeoff: long windows give fine frequency resolution ({{< m >}}\Delta\omega \sim 1/L{{< /m >}}) but poor time localization ({{< m >}}\Delta t \sim L{{< /m >}}); short windows give the reverse. There is no window for which both are simultaneously arbitrarily small — this is the Gabor uncertainty principle, previewed in the narration and to be treated rigorously in EP36.

**Formant preservation.** As noted in the narration, professional pitch shifting requires separating the spectral fine structure (harmonic positions, encoding pitch) from the spectral envelope (formant positions, encoding timbre). The standard engineering approach uses cepstral liftering or LPC envelope estimation, but both are approximations. Perceptually optimal formant preservation in the presence of vibrato, breathiness, and consonant transitions is an unsolved signal processing problem.
