## Overview / 概述

Two melodies stand before you. How far apart are they? Not the number of notes that differ, not a key-signature gap — but the minimum cost of *transporting* one distribution of pitches into the other. That cost is the **Wasserstein distance**, also called the Earth Mover's Distance (EMD).

Optimal transport (OT) reframes melody comparison as a logistics problem: notes are piles of earth at different pitch locations, and we want to move every grain of source-earth onto the matching target location with the smallest total effort. The decisive insight is that this minimisation problem has a dual formulation — the Kantorovich duality — that connects geometry to functional analysis and turns melody distance into a computable quantity.

This episode introduces the transport-plan matrix, the Kantorovich primal–dual theorem, the Sinkhorn algorithm for fast approximation, and three musical applications: style similarity, plagiarism detection, and tonal distance along the circle of fifths.

## Definitions

{{< definition name="Melody as a Probability Measure" label="Definition 52.1" >}}
Let {{< m >}}\mathcal{X} = \{0, 1, \ldots, 11\}{{< /m >}} denote the set of pitch classes (mod 12), or more generally let {{< m >}}\mathcal{X} \subset \mathbb{R}{{< /m >}} be a finite set of MIDI note numbers.

A **melody** of length {{< m >}}n{{< /m >}} with notes {{< m >}}x_1, x_2, \ldots, x_n \in \mathcal{X}{{< /m >}} and non-negative amplitude weights {{< m >}}a_1, \ldots, a_n \geq 0{{< /m >}} with {{< m >}}\sum_i a_i = 1{{< /m >}} defines a **discrete probability measure**:

{{< dm >}}\mu = \sum_{i=1}^{n} a_i \, \delta_{x_i}{{< /dm >}}

where {{< m >}}\delta_{x}{{< /m >}} is the Dirac mass at pitch {{< m >}}x{{< /m >}}. The weight {{< m >}}a_i{{< /m >}} encodes the relative importance (duration, velocity, or uniform {{< m >}}1/n{{< /m >}}) of note {{< m >}}x_i{{< /m >}}.

**Worked example.** A three-note motif C–E–G with equal weights: {{< m >}}\mu = \tfrac{1}{3}\delta_0 + \tfrac{1}{3}\delta_4 + \tfrac{1}{3}\delta_7{{< /m >}} (using MIDI pitch classes C=0, E=4, G=7).
{{< /definition >}}

{{< definition name="Ground Cost and Cost Matrix" label="Definition 52.2" >}}
A **ground cost** is a function {{< m >}}c : \mathcal{X} \times \mathcal{X} \to [0, \infty){{< /m >}} measuring the cost of transporting one unit of "earth" from pitch {{< m >}}x{{< /m >}} to pitch {{< m >}}y{{< /m >}}.

For melody comparison the standard choice is the {{< m >}}L^1{{< /m >}} pitch distance:
{{< dm >}}c(x, y) = |x - y|{{< /dm >}}

(in semitones). Given source notes {{< m >}}x_1, \ldots, x_m{{< /m >}} and target notes {{< m >}}y_1, \ldots, y_n{{< /m >}}, the **cost matrix** is:
{{< dm >}}C_{ij} = c(x_i, y_j) = |x_i - y_j|, \quad 1 \leq i \leq m, \; 1 \leq j \leq n{{< /dm >}}

**Example.** Moving pitch C (0) to G (7) costs 7; moving C to D (2) costs 2.
{{< /definition >}}

{{< definition name="Transport Plan" label="Definition 52.3" >}}
Given source measure {{< m >}}\mu = \sum_i a_i \delta_{x_i}{{< /m >}} and target measure {{< m >}}\nu = \sum_j b_j \delta_{y_j}{{< /m >}}, a **transport plan** is a matrix {{< m >}}\gamma \in \mathbb{R}^{m \times n}_{\geq 0}{{< /m >}} satisfying the **marginal constraints**:

{{< dm >}}\sum_{j=1}^{n} \gamma_{ij} = a_i \quad \forall i, \qquad \sum_{i=1}^{m} \gamma_{ij} = b_j \quad \forall j{{< /dm >}}

The entry {{< m >}}\gamma_{ij}{{< /m >}} specifies how much mass is moved from source note {{< m >}}x_i{{< /m >}} to target note {{< m >}}y_j{{< /m >}}.

The set of all transport plans is denoted {{< m >}}\Pi(\mu, \nu){{< /m >}} and is a convex polytope.

**Musical reading.** Row sums equal source note weights; column sums equal target note weights. Each row describes how one source note is "spread" across target notes; each column describes which sources contribute to one target note.
{{< /definition >}}

{{< definition name="Wasserstein-1 Distance (Earth Mover's Distance)" label="Definition 52.4" >}}
The **Wasserstein-1 distance** (or {{< m >}}W_1{{< /m >}} distance, Earth Mover's Distance) between measures {{< m >}}\mu{{< /m >}} and {{< m >}}\nu{{< /m >}} over a metric space {{< m >}}(\mathcal{X}, c){{< /m >}} is:

{{< dm >}}W_1(\mu, \nu) = \min_{\gamma \in \Pi(\mu, \nu)} \sum_{i,j} \gamma_{ij} \, C_{ij} = \min_{\gamma \in \Pi(\mu, \nu)} \langle \gamma, C \rangle{{< /dm >}}

where {{< m >}}\langle \gamma, C \rangle = \sum_{i,j} \gamma_{ij} C_{ij}{{< /m >}} is the Frobenius inner product (total transport cost).

**Intuition.** Each unit of mass must be moved; the cost is distance times mass. The minimisation finds the most efficient re-assignment, avoiding unnecessary long-range transport.
{{< /definition >}}

{{< definition name="Kantorovich Dual Potentials" label="Definition 52.5" >}}
The **Kantorovich dual problem** to {{< m >}}W_1{{< /m >}} seeks a pair of functions {{< m >}}(f, g){{< /m >}} with {{< m >}}f : \mathcal{X} \to \mathbb{R}{{< /m >}} and {{< m >}}g : \mathcal{Y} \to \mathbb{R}{{< /m >}} (called **dual potentials**) subject to the constraint:

{{< dm >}}f(x_i) + g(y_j) \leq C_{ij} \quad \forall i, j{{< /dm >}}

The dual objective is:

{{< dm >}}\max_{f, g} \sum_i a_i f(x_i) + \sum_j b_j g(y_j){{< /dm >}}

The functions {{< m >}}f{{< /m >}} and {{< m >}}g{{< /m >}} can be interpreted as "prices" at each source and target location in a resource-allocation economy. At optimality, {{< m >}}f{{< /m >}} and {{< m >}}g{{< /m >}} are {{< m >}}c{{< /m >}}-conjugates of each other.
{{< /definition >}}

## Main Theorems / 主要定理

{{< theorem name="Wasserstein Is a Metric" label="Theorem 52.1" >}}
Let {{< m >}}(\mathcal{X}, c){{< /m >}} be a metric space. Then {{< m >}}W_1{{< /m >}} defines a metric on the space of probability measures {{< m >}}\mathcal{P}(\mathcal{X}){{< /m >}}:

1. **Non-negativity**: {{< m >}}W_1(\mu, \nu) \geq 0{{< /m >}}, with equality if and only if {{< m >}}\mu = \nu{{< /m >}}.
2. **Symmetry**: {{< m >}}W_1(\mu, \nu) = W_1(\nu, \mu){{< /m >}}.
3. **Triangle inequality**: {{< m >}}W_1(\mu, \rho) \leq W_1(\mu, \nu) + W_1(\nu, \rho){{< /m >}} for any third measure {{< m >}}\rho{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
Non-negativity and symmetry follow directly from the definition: {{< m >}}C_{ij} \geq 0{{< /m >}} and any plan {{< m >}}\gamma{{< /m >}} for {{< m >}}(\mu, \nu){{< /m >}} can be transposed to give a plan for {{< m >}}(\nu, \mu){{< /m >}} with the same cost.

For the **triangle inequality**, given optimal plans {{< m >}}\gamma^* \in \Pi(\mu, \nu){{< /m >}} and {{< m >}}\eta^* \in \Pi(\nu, \rho){{< /m >}}, one constructs a **gluing** {{< m >}}\zeta \in \Pi(\mu, \rho){{< /m >}} via the disintegration theorem: define {{< m >}}\zeta(x, z) = \int_\mathcal{Y} \frac{d\gamma^*(x,y)}{d\nu(y)} \cdot d\eta^*(y,z) \, d\nu(y){{< /m >}}. Then:
{{< dm >}}\langle \zeta, c \rangle \leq \langle \gamma^*, c \rangle + \langle \eta^*, c \rangle = W_1(\mu,\nu) + W_1(\nu,\rho){{< /dm >}}
by the triangle inequality on {{< m >}}c{{< /m >}}: {{< m >}}c(x,z) \leq c(x,y) + c(y,z){{< /m >}}. Since {{< m >}}\zeta{{< /m >}} is a valid coupling for {{< m >}}(\mu,\rho){{< /m >}}, the infimum {{< m >}}W_1(\mu,\rho) \leq \langle \zeta, c\rangle{{< /m >}} gives the result. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Kantorovich Duality" label="Theorem 52.2" >}}
For discrete measures {{< m >}}\mu = \sum_i a_i \delta_{x_i}{{< /m >}} and {{< m >}}\nu = \sum_j b_j \delta_{y_j}{{< /m >}} with finite support and ground cost {{< m >}}c{{< /m >}}, the primal and dual values are equal:

{{< dm >}}W_1(\mu, \nu) = \min_{\gamma \in \Pi(\mu,\nu)} \langle \gamma, C \rangle = \max_{\substack{f, g \\ f(x_i)+g(y_j) \leq C_{ij}}} \left[ \sum_i a_i f(x_i) + \sum_j b_j g(y_j) \right]{{< /dm >}}

Moreover, for the {{< m >}}L^1{{< /m >}} ground cost {{< m >}}c(x,y)=|x-y|{{< /m >}}, the dual admits the Lipschitz reformulation:

{{< dm >}}W_1(\mu, \nu) = \sup_{\|h\|_{\mathrm{Lip}} \leq 1} \left[ \int h \, d\mu - \int h \, d\nu \right]{{< /dm >}}

where the supremum is over all 1-Lipschitz functions {{< m >}}h : \mathcal{X} \to \mathbb{R}{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
The primal problem is a **linear programme** in {{< m >}}\gamma{{< /m >}} (minimise a linear objective over a convex polytope). Strong LP duality applies whenever the primal is feasible and bounded — both hold since {{< m >}}\Pi(\mu,\nu){{< /m >}} is non-empty (e.g., the independent coupling {{< m >}}\gamma_{ij}=a_i b_j{{< /m >}}) and costs are non-negative. Strong duality yields {{< m >}}\min \langle \gamma, C \rangle = \max \sum_i a_i f_i + \sum_j b_j g_j{{< /m >}} over dual-feasible {{< m >}}(f,g){{< /m >}}.

The Lipschitz reformulation follows from complementary slackness: at optimality {{< m >}}f(x_i) - f(y_j) \leq C_{ij} = |x_i - y_j|{{< /m >}}, so the optimal {{< m >}}f{{< /m >}} (setting {{< m >}}g = -f{{< /m >}} for the symmetric {{< m >}}L^1{{< /m >}} case) must be 1-Lipschitz. The supremum over 1-Lipschitz {{< m >}}h{{< /m >}} equals the dual optimum. {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *中文:* "康托洛维奇对偶是最优传输理论的核心定理：最小化搬运代价，等于最大化一对函数的积分差。对偶性把几何距离和函数分析联系起来，是最优传输成为强大工具的数学原因。"

{{< theorem name="Transposition Is Near, Inversion Is Far" label="Theorem 52.3" >}}
Let {{< m >}}\mu = \sum_{i=1}^n \tfrac{1}{n} \delta_{x_i}{{< /m >}} be a melody with uniform weights. Define:

- **Transposition by {{< m >}}k{{< /m >}} semitones**: {{< m >}}\mu^{+k} = \sum_{i=1}^n \tfrac{1}{n} \delta_{x_i + k}{{< /m >}}.
- **Inversion about axis {{< m >}}a{{< /m >}}**: {{< m >}}\mu^{\text{inv}} = \sum_{i=1}^n \tfrac{1}{n} \delta_{2a - x_i}{{< /m >}}.

Then:
{{< dm >}}W_1(\mu, \mu^{+k}) = |k|{{< /dm >}}
{{< dm >}}W_1(\mu, \mu^{\text{inv}}) = \frac{2}{n} \sum_{i=1}^n |x_i - a|{{< /dm >}}
{{< /theorem >}}

{{< proof >}}
**Transposition.** The identity coupling {{< m >}}\gamma_{ii} = \tfrac{1}{n}{{< /m >}} (ship note {{< m >}}x_i{{< /m >}} to {{< m >}}x_i + k{{< /m >}}) is feasible and has cost {{< m >}}\sum_i \tfrac{1}{n} |k| = |k|{{< /m >}}. No coupling can do better, because every unit of mass must move at least {{< m >}}|k|{{< /m >}} (a lower bound from the dual: the 1-Lipschitz function {{< m >}}h(x) = x{{< /m >}} satisfies {{< m >}}\int h \, d\mu^{+k} - \int h \, d\mu = k{{< /m >}}).

**Inversion.** The identity coupling ships {{< m >}}x_i{{< /m >}} to {{< m >}}2a - x_i{{< /m >}} at cost {{< m >}}|x_i - (2a-x_i)| = 2|x_i - a|{{< /m >}}. Summing with weight {{< m >}}\tfrac{1}{n}{{< /m >}} gives the stated formula. Optimality of this coupling follows from the Monge solution for 1D transport (Theorem 52.4 below). {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *中文:* "转位：把旋律整体移高五度，代价很小——每个音符搬运相同距离。听起来也'近'。倒影：把每个音符关于轴翻转，搬运代价大——音符散布开来。听起来'远'了。这和直觉完全吻合。"

{{< theorem name="Monge Solution in One Dimension" label="Theorem 52.4" >}}
When {{< m >}}\mathcal{X} = \mathbb{R}{{< /m >}} and {{< m >}}c(x,y) = |x-y|{{< /m >}}, the optimal transport plan between discrete measures is achieved by the **sorted matching**: sort source pitches {{< m >}}x_1 \leq x_2 \leq \cdots \leq x_m{{< /m >}} and target pitches {{< m >}}y_1 \leq y_2 \leq \cdots \leq y_n{{< /m >}} (with repetition according to weights), then match them in order.

For equal-weight melodies of the same length {{< m >}}n = m{{< /m >}}:
{{< dm >}}W_1(\mu, \nu) = \frac{1}{n} \sum_{i=1}^n |x_{\sigma(i)} - y_i|{{< /dm >}}
where {{< m >}}\sigma{{< /m >}} is the rank-permutation sorting {{< m >}}\mu{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
For the {{< m >}}L^1{{< /m >}} cost on {{< m >}}\mathbb{R}{{< /m >}}, any **crossing** in a transport plan is suboptimal: if {{< m >}}\gamma_{ij} > 0{{< /m >}} and {{< m >}}\gamma_{kl} > 0{{< /m >}} with {{< m >}}x_i < x_k{{< /m >}} and {{< m >}}y_j > y_l{{< /m >}}, then uncrossing — sending {{< m >}}x_i \to y_l{{< /m >}} and {{< m >}}x_k \to y_j{{< /m >}} — costs the same or less, by the {{< m >}}L^1{{< /m >}} identity {{< m >}}|a-d| + |b-c| \leq |a-c| + |b-d|{{< /m >}} when {{< m >}}a \leq b{{< /m >}}, {{< m >}}c \leq d{{< /m >}}. Removing all crossings yields the sorted matching, which is optimal. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< proposition label="Prop 52.1" name="LP Complexity and Sinkhorn Approximation" >}}
The exact transport plan solves a linear programme with {{< m >}}mn{{< /m >}} variables and {{< m >}}m + n{{< /m >}} equality constraints. The interior-point complexity is {{< m >}}O((mn)^{3/2}){{< /m >}} (roughly {{< m >}}O(n^3){{< /m >}} for square problems). The **Sinkhorn algorithm** (Cuturi 2013) adds an entropic regularisation term {{< m >}}\varepsilon H(\gamma){{< /m >}} to the objective (where {{< m >}}H(\gamma) = -\sum_{ij} \gamma_{ij} \log \gamma_{ij}{{< /m >}}), yielding an approximate plan in {{< m >}}O(n^2 / \varepsilon^2){{< /m >}} iterations, each of cost {{< m >}}O(n^2){{< /m >}}.
{{< /proposition >}}

{{< proof >}}
The regularised problem has a unique solution (strict convexity of entropy) given by a **doubly stochastic scaling** of the kernel matrix {{< m >}}K_{ij} = e^{-C_{ij}/\varepsilon}{{< /m >}}: {{< m >}}\gamma^\varepsilon = \mathrm{diag}(u) \, K \, \mathrm{diag}(v){{< /m >}} for scaling vectors {{< m >}}u, v{{< /m >}}. The Sinkhorn iteration alternately normalises rows and columns of {{< m >}}K{{< /m >}}, converging geometrically. As {{< m >}}\varepsilon \to 0{{< /m >}}, {{< m >}}\gamma^\varepsilon \to \gamma^*{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

## Numerical Examples

**Example 1: Transposition by a fifth.**

Source: C–E–G–B–D (uniform weights {{< m >}}1/5{{< /m >}} each), pitches {{< m >}}\{0, 4, 7, 11, 14\}{{< /m >}}.
Target: G–B–D–F♯–A (shifted up 7 semitones), pitches {{< m >}}\{7, 11, 14, 18, 21\}{{< /m >}}.

By Theorem 52.3:
{{< dm >}}W_1(\mu, \mu^{+7}) = 7{{< /dm >}}

The sorted matching ships each note exactly 7 semitones. Total cost {{< m >}}= 5 \times \tfrac{1}{5} \times 7 = 7{{< /m >}}.

**Example 2: Inversion about axis C (pitch 0).**

Source: same pentatonic {{< m >}}\{0, 2, 4, 7, 9\}{{< /m >}} (C–D–E–G–A), inversion about C maps to {{< m >}}\{0, -2, -4, -7, -9\}{{< /m >}}.

{{< dm >}}W_1(\mu, \mu^{\text{inv}}) = \frac{2}{5}(|0| + |2| + |4| + |7| + |9|) = \frac{2}{5} \times 22 = 8.8{{< /dm >}}

Inversion costs 8.8 semitone-units vs. 7 for transposition — confirming that inversion "moves the melody further."

**Example 3: Transport plan matrix (4×4).**

Consider source notes C, E, G, B with weights {{< m >}}(a_1, a_2, a_3, a_4){{< /m >}} and target notes D, F, A, C with weights {{< m >}}(b_1, b_2, b_3, b_4){{< /m >}}. A feasible plan:

| | D | F | A | C |
|---|---|---|---|---|
| **C** | 0.8 | 0.2 | 0.0 | 0.0 |
| **E** | 0.0 | 0.7 | 0.3 | 0.0 |
| **G** | 0.0 | 0.0 | 0.8 | 0.2 |
| **B** | 0.1 | 0.0 | 0.0 | 0.9 |

Each row sums to the source note weight; each column sums to the target note weight. The total cost is {{< m >}}\sum_{ij} \gamma_{ij} |x_i - y_j|{{< /m >}}, minimised over all such feasible matrices.

> *中文:* "最优传输计划是一个矩阵：行是源旋律的音符，列是目标旋律的音符，每个格子表示从这个源音符搬运多少到那个目标音符。目标：最小化总搬运代价，即矩阵与代价矩阵的点积。这是一个线性规划问题。"

**Example 4: Tonal distance from C major to F major.**

Represent C major scale as uniform distribution on {{< m >}}\{0, 2, 4, 5, 7, 9, 11\}{{< /m >}} and F major on {{< m >}}\{0, 2, 4, 5, 7, 9, 10\}{{< /m >}}. The only differing note is B (11) vs. B♭ (10). The sorted matching sends all notes to themselves except B → B♭ at cost 1, giving:

{{< dm >}}W_1(\mu_{C}, \mu_{F}) = \frac{1}{7} \times 1 = 0.143{{< /dm >}}

Moving two steps on the circle of fifths (C → F, a distance of 1 fifth) costs this amount, matching the geometric intuition that adjacent keys are close.

## Musical Connection / 音乐联系

{{< musical-connection >}}
**Why Wasserstein beats edit distance for melody**

Classical edit distance (Levenshtein) on melody sequences counts insertions, deletions, and substitutions — but assigns cost 1 to every substitution regardless of pitch distance. Under edit distance, changing C to C♯ (1 semitone) is just as costly as changing C to B (11 semitones). Musicians know this is wrong: a chromatic neighbour feels similar; a tritone substitution sounds remote.

Wasserstein distance corrects this by embedding pitch into its natural metric space. The ground cost {{< m >}}c(x,y) = |x - y|{{< /m >}} (or a circular variant {{< m >}}\min(|x-y|, 12-|x-y|){{< /m >}} on {{< m >}}\mathbb{Z}_{12}{{< /m >}}) means nearby pitches are cheap to transport. The Wasserstein metric *inherits* the geometry of pitch space.

**Three applications in music analysis**

1. **Style similarity.** Represent a composer's melodic output as a weighted average of melody measures. {{< m >}}W_1{{< /m >}} between two composers' aggregated pitch distributions gives a principled distance; clustering by {{< m >}}W_1{{< /m >}} recovers stylistic families more reliably than histogram overlap.

2. **Plagiarism detection.** When {{< m >}}W_1(\mu_A, \mu_B) < \theta{{< /m >}} for a calibrated threshold {{< m >}}\theta{{< /m >}}, the two melodies are flagged for review. Unlike fingerprinting (exact match), OT-based detection tolerates transposition, rhythmic variation, and ornamental embellishment — precisely the transformations composers use to disguise borrowing.

3. **Tonal distance and the circle of fifths.** Represent each key as its scale distribution. The Wasserstein distance between scale distributions matches the circle-of-fifths distance: C → G costs less than C → F♯, because the scales differ by one note vs. six notes. This gives a data-driven derivation of the circle of fifths from first principles.

**Transposition and inversion through the OT lens**

Transposition by {{< m >}}k{{< /m >}} semitones moves every pitch the same distance, so the transport plan is diagonal and the cost is exactly {{< m >}}|k|{{< /m >}} — a small, controlled motion. Melodic inversion scatters pitches relative to an axis; unless the melody is highly symmetric, inversion produces a large, non-diagonal transport plan and a correspondingly large Wasserstein distance. This quantifies the intuition that transpositions are "the same melody in a new key" while inversions are genuinely different melodic shapes.

## Limits and Open Questions / 局限性与开放问题

1. **Pitch-only transport ignores rhythm.** The current formulation represents a melody as a distribution over pitches, discarding all temporal information. Two melodies with identical pitch-class distributions but entirely different rhythms receive {{< m >}}W_1 = 0{{< /m >}}. Extending OT to joint pitch–time distributions (measures on {{< m >}}\mathbb{R}^2{{< /m >}}) requires a 2D ground cost and dramatically increases the size of the LP.

2. **Circular pitch space.** The linear cost {{< m >}}c(x,y) = |x-y|{{< /m >}} does not respect octave equivalence. On {{< m >}}\mathbb{Z}_{12}{{< /m >}} the natural metric is {{< m >}}\min(|x-y|, 12-|x-y|){{< /m >}}, making the ground space a circle rather than a line. The 1D Monge sorting theorem no longer applies directly, increasing computational complexity.

3. **Choice of ground cost is a modelling decision.** The {{< m >}}L^1{{< /m >}} semitone distance treats all semitone steps as equal. A psychoacoustically motivated cost (e.g., weighted by consonance intervals, or derived from MDS of listener similarity ratings) could yield musically more meaningful distances, but is harder to justify axiomatically.

4. **Computational cost at scale.** Exact LP computation is {{< m >}}O(n^3){{< /m >}}; Sinkhorn at precision {{< m >}}\varepsilon{{< /m >}} is {{< m >}}O(n^2/\varepsilon^2){{< /m >}}. For large corpora (millions of melody pairs), even Sinkhorn becomes expensive. Sliced Wasserstein distance — averaging 1D projections — runs in {{< m >}}O(n \log n){{< /m >}} per projection but loses metric information.

5. **Wasserstein vs. Gromov–Wasserstein for structural comparison.** {{< m >}}W_1{{< /m >}} compares pitch distributions embedded in a fixed ambient space. When comparing melodies across different modal systems (e.g., Western vs. Indian ragas with different scale structures), the ambient spaces differ. **Gromov–Wasserstein distance** (Mémoli 2011) compares metric-measure spaces intrinsically, without requiring a common embedding — but is {{< m >}}O(n^3){{< /m >}} even approximately.

{{< conjecture name="Wasserstein Threshold for Melodic Similarity Perception" >}}
There exists a perceptual threshold {{< m >}}\theta^* > 0{{< /m >}} such that for any two melodies {{< m >}}\mu, \nu{{< /m >}} with {{< m >}}W_1(\mu, \nu) < \theta^*{{< /m >}}, trained listeners judge them as "similar" with probability exceeding 0.75. Conversely, for {{< m >}}W_1(\mu, \nu) > 2\theta^*{{< /m >}}, the similarity judgment probability falls below 0.25.

**Falsification criterion.** A valid counterexample is a pair of melodies with {{< m >}}W_1 < \theta^*{{< /m >}} that listeners consistently rate as dissimilar (e.g., due to rhythmic or timbral contrast not captured by pitch distribution), or a pair with {{< m >}}W_1 > 2\theta^*{{< /m >}} that listeners rate as similar (e.g., due to motivic imitation or shared contour). Such examples would demonstrate that {{< m >}}W_1{{< /m >}} on pitch distributions is insufficient for perceptual melody similarity, and that a richer ground space (pitch × time × timbre) is necessary.
