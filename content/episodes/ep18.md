## Overview

Four operas. Four game-theoretic frameworks. This episode treats operatic duets as strategic interactions and asks: can the mathematical machinery of game theory --- payoff matrices, equilibrium concepts, information structures --- explain why characters make the choices they do?

We begin with Bizet's *Carmen* (1875), where the final confrontation between Carmen and Don Jose is modeled as a two-player non-cooperative game solved by backward induction. Mozart's *Don Giovanni* (1787) introduces incomplete information: Giovanni persuades Zerlina through repeated signaling, and her decision follows Bayesian updating. Xenakis's *Duel* (1959) is the most literal case --- a zero-sum matrix game written directly into the score, governed by the von Neumann minimax theorem. Finally, Zorn's *Cobra* (1984) embodies the folk theorem: cooperation emerging from repeated interaction and reputation.

> *中文:* "卡门看着唐何塞。戒指扔在地上。她只要低头，就能活。但她没有。为什么？一个理性的人，为什么会走向死亡？这不是冲动。像是一种计算。她到底算到了什么？"

## Definitions

{{< definition name="Normal-Form Game" label="Definition 18.1" >}}
A **normal-form (strategic-form) game** is a tuple {{< m >}}\Gamma = (N, (S_i)_{i \in N}, (u_i)_{i \in N}){{< /m >}} where:

- {{< m >}}N = \{1, 2, \ldots, n\}{{< /m >}} is a finite set of **players**,
- {{< m >}}S_i{{< /m >}} is the finite set of **strategies** (pure actions) available to player {{< m >}}i{{< /m >}},
- {{< m >}}u_i : S_1 \times S_2 \times \cdots \times S_n \to \mathbb{R}{{< /m >}} is the **payoff (utility) function** of player {{< m >}}i{{< /m >}}.

A **strategy profile** is a tuple {{< m >}}s = (s_1, \ldots, s_n) \in \prod_i S_i{{< /m >}}. We write {{< m >}}s_{-i}{{< /m >}} for the profile of all players except {{< m >}}i{{< /m >}}.
{{< /definition >}}

{{< definition name="Nash Equilibrium" label="Definition 18.2" >}}
A strategy profile {{< m >}}s^* = (s_1^*, \ldots, s_n^*){{< /m >}} is a **Nash equilibrium** if no player can unilaterally improve their payoff:
{{< dm >}}\forall\, i \in N,\; \forall\, s_i \in S_i: \quad u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*){{< /dm >}}
Equivalently, each {{< m >}}s_i^*{{< /m >}} is a **best response** to {{< m >}}s_{-i}^*{{< /m >}}.
{{< /definition >}}

> *中文:* "什么是纳什均衡？如果每个玩家在对方策略不变的前提下，都没有动机改变自己的策略，这个组合就是纳什均衡。"

{{< definition name="Sequential Game and Backward Induction" label="Definition 18.3" >}}
A **sequential (extensive-form) game** specifies a game tree where players move in sequence, each observing prior moves. **Backward induction** solves such games by starting at terminal nodes and reasoning backwards: at each decision node, the player selects the action maximizing their payoff given the optimal continuation.
{{< /definition >}}

{{< definition name="Bayesian Game" label="Definition 18.4" >}}
A **Bayesian game** extends the normal form with incomplete information. Each player {{< m >}}i{{< /m >}} has a **type** {{< m >}}\theta_i \in \Theta_i{{< /m >}} drawn from a prior distribution {{< m >}}p(\theta){{< /m >}}. Player {{< m >}}i{{< /m >}} knows their own type but not others'. After observing a signal {{< m >}}x{{< /m >}}, a player updates their belief about the opponent's type via **Bayes' theorem**:
{{< dm >}}P(\theta \mid x) = \frac{P(x \mid \theta)\, P(\theta)}{P(x)}{{< /dm >}}
{{< /definition >}}

{{< definition name="Mixed Strategy" label="Definition 18.5" >}}
A **mixed strategy** for player {{< m >}}i{{< /m >}} is a probability distribution {{< m >}}\sigma_i \in \Delta(S_i){{< /m >}} over their pure strategies. The **expected payoff** under mixed strategies {{< m >}}(\sigma_1, \ldots, \sigma_n){{< /m >}} is:
{{< dm >}}U_i(\sigma_1, \ldots, \sigma_n) = \sum_{s \in \prod_j S_j} \left(\prod_{j=1}^n \sigma_j(s_j)\right) u_i(s){{< /dm >}}
{{< /definition >}}

{{< definition name="Zero-Sum Game" label="Definition 18.6" >}}
A two-player game is **zero-sum** if {{< m >}}u_1(s) + u_2(s) = 0{{< /m >}} for every strategy profile {{< m >}}s{{< /m >}}. One player's gain is exactly the other's loss. The payoff matrix {{< m >}}A{{< /m >}} records player 1's payoffs; player 2's payoffs are {{< m >}}-A{{< /m >}}.
{{< /definition >}}

{{< definition name="Repeated Game and Discount Factor" label="Definition 18.7" >}}
A **repeated game** consists of the same stage game {{< m >}}\Gamma{{< /m >}} played over rounds {{< m >}}t = 1, 2, \ldots{{< /m >}} Players observe the full history of past play. With **discount factor** {{< m >}}\delta \in (0,1){{< /m >}}, player {{< m >}}i{{< /m >}}'s total payoff is:
{{< dm >}}\sum_{t=0}^{\infty} \delta^t\, u_i(s^{(t)}){{< /dm >}}
When {{< m >}}\delta{{< /m >}} is close to 1, players care significantly about the future, enabling cooperation.
{{< /definition >}}

## Main Theorems

### Nash Existence Theorem

{{< theorem name="Nash Existence Theorem" label="Theorem 18.1" >}}
Every finite game (finitely many players, each with finitely many strategies) has at least one Nash equilibrium in mixed strategies.
{{< /theorem >}}

{{< proof >}}
Define the **best-response correspondence** {{< m >}}BR_i(\sigma_{-i}) = \arg\max_{\sigma_i \in \Delta(S_i)} U_i(\sigma_i, \sigma_{-i}){{< /m >}} for each player {{< m >}}i{{< /m >}}. The joint best-response map {{< m >}}BR: \prod_i \Delta(S_i) \to \prod_i \Delta(S_i){{< /m >}} sends {{< m >}}\sigma \mapsto \prod_i BR_i(\sigma_{-i}){{< /m >}}.

The domain {{< m >}}\prod_i \Delta(S_i){{< /m >}} is compact and convex (a product of simplices). Each {{< m >}}U_i{{< /m >}} is linear (hence continuous) in {{< m >}}\sigma_i{{< /m >}}, and continuous in {{< m >}}\sigma_{-i}{{< /m >}}. By the maximum theorem, {{< m >}}BR_i{{< /m >}} is upper hemicontinuous with non-empty convex values (since the argmax of a linear function over a simplex is a convex set).

By **Kakutani's fixed-point theorem**, any upper hemicontinuous correspondence from a compact convex set to itself with non-empty convex values has a fixed point {{< m >}}\sigma^*{{< /m >}}. A fixed point {{< m >}}\sigma^* \in BR(\sigma^*){{< /m >}} means each player's strategy is a best response to the others --- precisely the definition of a Nash equilibrium. {{< m >}}\square{{< /m >}}
{{< /proof >}}

### Von Neumann Minimax Theorem

{{< theorem name="Von Neumann Minimax Theorem" label="Theorem 18.2" >}}
In a finite two-player zero-sum game with payoff matrix {{< m >}}A \in \mathbb{R}^{m \times n}{{< /m >}}, there exists a unique **game value** {{< m >}}V{{< /m >}} and mixed strategies {{< m >}}p^* \in \Delta_m{{< /m >}}, {{< m >}}q^* \in \Delta_n{{< /m >}} such that:
{{< dm >}}\max_{p \in \Delta_m} \min_{q \in \Delta_n} p^T A q = V = \min_{q \in \Delta_n} \max_{p \in \Delta_m} p^T A q{{< /dm >}}
{{< /theorem >}}

> *中文:* "在零和博弈中，存在一个博弈值 V。玩家一的最优策略是找到一个概率分布 p，使得最坏情况下的期望收益最大化。"

{{< proof >}}
For any {{< m >}}p, q{{< /m >}}, the function {{< m >}}f(p, q) = p^T A q{{< /m >}} is bilinear: linear (hence convex) in {{< m >}}q{{< /m >}} for fixed {{< m >}}p{{< /m >}}, and linear (hence concave) in {{< m >}}p{{< /m >}} for fixed {{< m >}}q{{< /m >}}. The strategy sets {{< m >}}\Delta_m{{< /m >}} and {{< m >}}\Delta_n{{< /m >}} are compact and convex.

By **Sion's minimax theorem** (a generalization of von Neumann's original result): if {{< m >}}X, Y{{< /m >}} are compact convex sets and {{< m >}}f: X \times Y \to \mathbb{R}{{< /m >}} is convex-concave and continuous, then
{{< dm >}}\min_{y \in Y} \max_{x \in X} f(x,y) = \max_{x \in X} \min_{y \in Y} f(x,y){{< /dm >}}

Applying this with {{< m >}}X = \Delta_m{{< /m >}}, {{< m >}}Y = \Delta_n{{< /m >}}, {{< m >}}f(p,q) = p^T A q{{< /m >}} yields the minimax equality. The common value {{< m >}}V{{< /m >}} is the game value. Optimal strategies {{< m >}}p^*, q^*{{< /m >}} exist by compactness. {{< m >}}\square{{< /m >}}
{{< /proof >}}

### Folk Theorem

{{< theorem name="Folk Theorem (Nash, Aumann-Shapley)" label="Theorem 18.3" >}}
Consider an infinitely repeated game with discount factor {{< m >}}\delta{{< /m >}} and stage game {{< m >}}\Gamma{{< /m >}}. Let {{< m >}}v_i^{\min}{{< /m >}} denote the **minimax payoff** for player {{< m >}}i{{< /m >}} --- the lowest payoff that other players can force on {{< m >}}i{{< /m >}} regardless of {{< m >}}i{{< /m >}}'s strategy:
{{< dm >}}v_i^{\min} = \min_{s_{-i}} \max_{s_i} u_i(s_i, s_{-i}){{< /dm >}}
Let {{< m >}}F{{< /m >}} be the set of **feasible payoff vectors** (convex hull of stage-game payoff profiles) and {{< m >}}F^* = \{v \in F : v_i > v_i^{\min} \;\forall i\}{{< /m >}} the **individually rational** feasible set. Then for any {{< m >}}v \in F^*{{< /m >}}, there exists {{< m >}}\bar\delta < 1{{< /m >}} such that for all {{< m >}}\delta > \bar\delta{{< /m >}}, {{< m >}}v{{< /m >}} is the payoff vector of some Nash equilibrium of the repeated game.
{{< /theorem >}}

{{< proof >}}
Fix a target payoff {{< m >}}v \in F^*{{< /m >}}. Since {{< m >}}v{{< /m >}} is feasible, there exist stage-game strategy profiles and a mixing distribution (possibly a correlated sequence of pure profiles) yielding average payoff {{< m >}}v{{< /m >}}. Define the following **grim trigger** strategy for each player {{< m >}}i{{< /m >}}:

- **Cooperation phase**: Play the prescribed action producing payoff vector {{< m >}}v{{< /m >}}.
- **Punishment phase**: If any player deviates, all other players switch permanently to the minimax punishment against the deviator.

The deviator gains at most a one-round deviation payoff {{< m >}}u_i^{\text{dev}}{{< /m >}}, then faces the minimax payoff {{< m >}}v_i^{\min}{{< /m >}} forever. The deviation is unprofitable when:
{{< dm >}}(1-\delta) u_i^{\text{dev}} + \delta\, v_i^{\min} \leq v_i{{< /dm >}}
{{< dm >}}\iff \delta \geq \frac{u_i^{\text{dev}} - v_i}{u_i^{\text{dev}} - v_i^{\min}}{{< /dm >}}

Since {{< m >}}v_i > v_i^{\min}{{< /m >}} by individual rationality, the right-hand side is strictly less than 1. Setting {{< m >}}\bar\delta = \max_i \frac{u_i^{\text{dev}} - v_i}{u_i^{\text{dev}} - v_i^{\min}}{{< /m >}} gives the threshold. For {{< m >}}\delta > \bar\delta{{< /m >}}, no player has incentive to deviate, so the strategy profile is a Nash equilibrium with payoff {{< m >}}v{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *中文:* "在博弈论中，当玩家足够在意未来，合作可以从重复互动中自发维持——这就是所谓的民间定理。"

## Musical Example 1: Carmen --- Tragedy as Nash Equilibrium

> *中文:* "1875年，比才的卡门。第四幕，斗牛场外。卡门和唐何塞的最终对峙。"

Model the final confrontation of Bizet's *Carmen* (1875), Act IV, as a two-player non-cooperative game {{< m >}}\Gamma_{\text{Carmen}}{{< /m >}}.

**Players**: Carmen (row) and Jose (column). **Strategies**: Carmen chooses from {{< m >}}\{\text{Submit}, \text{Defy}\}{{< /m >}}; Jose chooses from {{< m >}}\{\text{Release}, \text{Kill}\}{{< /m >}}.

**Payoff matrix** (Carmen, Jose):

|  | Release | Kill |
|---|---|---|
| **Submit** | {{< m >}}(-2, -2){{< /m >}} | {{< m >}}(-3, -4){{< /m >}} |
| **Defy** | {{< m >}}(+1, -5){{< /m >}} | {{< m >}}(-\infty, -3){{< /m >}} |

> *中文:* "注意：这不是零和博弈——两个人可以同时输。我们把它建模为二人非合作博弈。"

{{< proposition label="Prop 18.1" name="Carmen's Nash Equilibrium" >}}
Under the payoff matrix above, the unique Nash equilibrium in pure strategies is {{< m >}}(\text{Defy}, \text{Kill}){{< /m >}}.
{{< /proposition >}}

{{< proof >}}
Check best responses. Given Carmen plays **Submit**: Jose compares {{< m >}}u_J(\text{Submit}, \text{Release}) = -2{{< /m >}} vs. {{< m >}}u_J(\text{Submit}, \text{Kill}) = -4{{< /m >}}. Best response: Release. Given Carmen plays **Defy**: Jose compares {{< m >}}u_J(\text{Defy}, \text{Release}) = -5{{< /m >}} vs. {{< m >}}u_J(\text{Defy}, \text{Kill}) = -3{{< /m >}}. Best response: Kill.

Given Jose plays **Release**: Carmen compares {{< m >}}u_C(\text{Submit}, \text{Release}) = -2{{< /m >}} vs. {{< m >}}u_C(\text{Defy}, \text{Release}) = +1{{< /m >}}. Best response: Defy. Given Jose plays **Kill**: Carmen compares {{< m >}}u_C(\text{Submit}, \text{Kill}) = -3{{< /m >}} vs. {{< m >}}u_C(\text{Defy}, \text{Kill}) = -\infty{{< /m >}}. Best response: Submit.

The only profile where both play best responses simultaneously is {{< m >}}(\text{Defy}, \text{Kill}){{< /m >}}: Carmen's best response to Kill is Submit (not Defy), so we must re-examine. In fact, we need the sequential structure.

As a **sequential game** (Carmen moves first, Jose observes), backward induction applies. Jose's best responses: if Carmen submits, Jose releases ({{< m >}}-2 > -4{{< /m >}}); if Carmen defies, Jose kills ({{< m >}}-3 > -5{{< /m >}}). Carmen, anticipating Jose's responses, compares: Submit then Release gives {{< m >}}-2{{< /m >}}; Defy then Kill gives {{< m >}}-\infty{{< /m >}}. Under standard utility, Carmen should submit.

But the narration's key insight: Carmen's utility function assigns submission a cost equivalent to spiritual death. If we replace {{< m >}}u_C(\text{Submit}, \cdot) = -\infty{{< /m >}}, then Defy dominates regardless of Jose's response. Given Defy, Jose kills ({{< m >}}-3 > -5{{< /m >}}). The subgame-perfect equilibrium is {{< m >}}(\text{Defy}, \text{Kill}){{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *中文:* "关键洞察：纳什均衡不一定是最优结果。两个人都理性选择，但最终结果可能比合作更差。这就是囚徒困境的教训。而歌剧里的悲剧，常常就是纳什均衡的必然结果。"

{{< musical-connection >}}
The tragedy of Carmen is not irrational --- it is the rational consequence of two incompatible utility functions. The mathematical structure is identical to the Prisoner's Dilemma: both players would prefer (Submit, Release) at {{< m >}}(-2, -2){{< /m >}} over the equilibrium outcome, but neither can unilaterally deviate without worsening their position. Bizet's dramatic genius is to construct characters whose utility functions make tragedy the unique equilibrium.

> *中文:* "这是一个序贯博弈。卡门先选择反抗，何塞再回应。用逆向归纳法从最后一步往回推。"
{{< /musical-connection >}}

## Musical Example 2: Don Giovanni --- Bayesian Persuasion

> *中文:* "1787年，莫扎特的唐乔凡尼。把你的手给我。我们可以把这首二重唱读作一场不完全信息下的说服。"

The duet "La ci darem la mano" from Mozart's *Don Giovanni* (1787) models persuasion under incomplete information.

**Setup**: Giovanni (sender) knows his true type {{< m >}}\theta \in \{\text{Sincere}, \text{Deceiver}\}{{< /m >}}. Zerlina (receiver) holds a prior belief {{< m >}}P(\theta = \text{Sincere}) = p_0{{< /m >}}. Giovanni sends musical signals --- each phrase of the duet is a signal {{< m >}}x{{< /m >}}.

After each signal, Zerlina updates via Bayes' theorem (Definition 18.4):
{{< dm >}}P(\text{Sincere} \mid x) = \frac{P(x \mid \text{Sincere})\, p_0}{P(x \mid \text{Sincere})\, p_0 + P(x \mid \text{Deceiver})\,(1 - p_0)}{{< /dm >}}

> *中文:* "采琳娜无法直接观察他的意图，只能根据他的行为更新判断。她有一个先验信念——在听到任何音乐之前，凭直觉估计他真心的概率是 p。"

{{< proposition label="Prop 18.2" name="Posterior Threshold Crossing" >}}
Let {{< m >}}p_t{{< /m >}} denote Zerlina's posterior belief after {{< m >}}t{{< /m >}} rounds of signaling. If Giovanni sends signals with likelihood ratio {{< m >}}\ell = P(x \mid \text{Sincere}) / P(x \mid \text{Deceiver}) > 1{{< /m >}} consistently, then:
{{< dm >}}\frac{p_t}{1 - p_t} = \frac{p_0}{1 - p_0} \cdot \ell^t{{< /dm >}}
so {{< m >}}p_t \to 1{{< /m >}} as {{< m >}}t \to \infty{{< /m >}}. There exists a threshold {{< m >}}\tau{{< /m >}} and a finite round {{< m >}}T{{< /m >}} such that {{< m >}}p_T > \tau{{< /m >}} and Zerlina accepts.
{{< /proposition >}}

{{< proof >}}
The posterior odds after one signal with likelihood ratio {{< m >}}\ell{{< /m >}} are:
{{< dm >}}\frac{p_1}{1 - p_1} = \frac{P(\text{Sincere} \mid x)}{P(\text{Deceiver} \mid x)} = \frac{P(x \mid \text{Sincere})}{P(x \mid \text{Deceiver})} \cdot \frac{p_0}{1-p_0} = \ell \cdot \frac{p_0}{1-p_0}{{< /dm >}}
After {{< m >}}t{{< /m >}} independent signals each with ratio {{< m >}}\ell{{< /m >}}, the posterior odds become {{< m >}}\ell^t \cdot p_0/(1-p_0){{< /m >}}. Since {{< m >}}\ell > 1{{< /m >}} and {{< m >}}p_0 > 0{{< /m >}}, the odds grow without bound, so {{< m >}}p_t \to 1{{< /m >}}. For any threshold {{< m >}}\tau < 1{{< /m >}}, there exists {{< m >}}T = \lceil \log\!\bigl(\frac{\tau}{1-\tau} \cdot \frac{1-p_0}{p_0}\bigr) / \log \ell \,\rceil{{< /m >}} such that {{< m >}}p_T > \tau{{< /m >}}. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< musical-connection >}}
Mozart's duet enacts Bayesian updating in real time. Zerlina's repeated "Vorrei e non vorrei" (I want to and I don't want to) is the musical representation of a posterior hovering near the decision threshold. Each time Giovanni repeats the melody, he provides another observation with {{< m >}}\ell > 1{{< /m >}}. The final moment --- when she gives him her hand --- is the threshold crossing.

> *中文:* "音乐完美呈现了这个过程。开始时采琳娜犹豫，重复唱道我想又不想。乔凡尼每重复一次旋律，就多提供一次观察样本。到最后，她的信念越过了阈值——她把手递了出去。"
{{< /musical-connection >}}

## Musical Example 3: Xenakis's Duel --- Zero-Sum Matrix Game

> *中文:* "1959年，希腊作曲家 Xenakis 做了一件当时极为罕见的事。他把博弈论直接写成了乐谱。"

Xenakis's *Duel* (1959) is a genuine musical game. Two conductors, each leading an orchestra, choose simultaneously from six **sound tactics**:

| Index | Tactic |
|-------|--------|
| I | String granular textures |
| II | Sustained strings |
| III | Glissando networks |
| IV | Stochastic percussion |
| V | Stochastic winds |
| VI | Silence |

A referee scores each round using a {{< m >}}6 \times 6{{< /m >}} payoff matrix {{< m >}}A{{< /m >}}. The game is zero-sum: conductor 1 receives {{< m >}}a_{ij}{{< /m >}}, conductor 2 receives {{< m >}}-a_{ij}{{< /m >}}.

By the Minimax Theorem (Theorem 18.2), there exist optimal mixed strategies {{< m >}}p^* \in \Delta_6{{< /m >}} and {{< m >}}q^* \in \Delta_6{{< /m >}} and a game value {{< m >}}V{{< /m >}} such that:
{{< dm >}}\min_q (p^*)^T A q = V = \max_p p^T A q^*{{< /dm >}}

> *中文:* "数学基础是冯诺依曼的极小极大定理。不管对手怎么选，我的混合策略都能保证至少拿到博弈值 V。"

{{< musical-connection >}}
Xenakis is the most literal case: game theory is not an interpretive lens imposed after the fact but is written directly into the score as a payoff matrix and performance rules. The 1962 sequel *Strategie* expands to 19 tactics per conductor (6 basic + 13 combinations), yielding a {{< m >}}19 \times 19{{< /m >}} matrix --- larger, longer, and more complex, but governed by the same minimax principle.

> *中文:* "Xenakis 是最早将博弈论直接写入乐谱的作曲家之一。不是隐喻，不是类比——是真正的收益矩阵和混合策略。"
{{< /musical-connection >}}

## Musical Example 4: Zorn's Cobra --- The Folk Theorem in Action

> *中文:* "1984年，约翰佐恩的 Cobra。这不是传统乐谱，而是一套博弈规则。"

John Zorn's *Cobra* (1984) is an improvisation game. A **prompter** holds cue cards (change style, imitate someone, create chaos, sudden silence). Musicians may raise hands to request cues or ignore them. The same ensemble plays repeatedly across performances.

This is the structure of a repeated game. The stage game involves choices to cooperate (follow cues, listen to ensemble) or defect (free-ride, ignore others). The folk theorem (Theorem 18.3) guarantees that if players value future interactions sufficiently (high {{< m >}}\delta{{< /m >}}), cooperation is sustainable as an equilibrium.

{{< proposition label="Prop 18.3" name="Reputation Sustains Cooperation in Cobra" >}}
In an infinitely repeated Cobra performance with discount factor {{< m >}}\delta{{< /m >}} sufficiently close to 1, the cooperative outcome (musicians follow cues and respond to each other) can be sustained as a Nash equilibrium via grim-trigger strategies.
{{< /proposition >}}

{{< proof >}}
This is a direct application of Theorem 18.3. Let {{< m >}}v_{\text{coop}}{{< /m >}} denote the cooperative payoff per round and {{< m >}}v_{\text{defect}}{{< /m >}} the one-shot deviation gain. The minimax payoff {{< m >}}v^{\min}{{< /m >}} corresponds to being ignored by the ensemble (the punishment). Cooperation is sustained when:
{{< dm >}}\delta > \frac{v_{\text{defect}} - v_{\text{coop}}}{v_{\text{defect}} - v^{\min}}{{< /dm >}}
In practice, Cobra musicians who regularly perform together develop strong reputational incentives (high effective {{< m >}}\delta{{< /m >}}), making the cooperative equilibrium self-enforcing. {{< m >}}\square{{< /m >}}
{{< /proof >}}

> *中文:* "Cobra 的魔力在于，经过多轮互动，乐手之间建立了声誉机制。谁经常合作，谁习惯捣乱，所有人都记得。合作不是来自乐谱上的指令，而是从反复互动和声誉积累中自发涌现。"

## Limits and Open Questions

1. **Utility function arbitrariness**. The Carmen model depends critically on the numerical payoffs. As the narration observes: "you can explain any choice with a payoff matrix, as long as you adjust the numbers." This is a fundamental limitation of revealed-preference game theory --- the model is unfalsifiable unless utilities are independently measured.

> *中文:* "你可以用收益矩阵解释任何选择，只要你修改数字。歌剧的力量，在于它让我们感受那个数字背后的重量。"

2. **Bounded rationality**. Real operatic characters (and real musicians in Cobra) do not compute equilibria. Behavioral game theory (Camerer 2003) models bounded rationality via quantal response equilibrium and level-k reasoning. How do these departures from Nash equilibrium map onto dramatic choices?

3. **Incomplete-information limits**. The Bayesian model of Don Giovanni assumes Zerlina has a well-defined prior and updates rationally. In practice, persuasion exploits cognitive biases (framing effects, anchoring) that Bayesian models do not capture.

4. **Computational complexity of large games**. Xenakis's *Strategie* has a {{< m >}}19 \times 19{{< /m >}} matrix --- still tractable. But real-time improvisation (Cobra) involves continuous strategy spaces and partial observability, for which computing equilibria is PPAD-complete in general.

{{< conjecture name="Equilibrium Deviation as Dramatic Peak" >}}
In operatic scenes that can be modeled as strategic interactions, the moment of maximum dramatic intensity corresponds to a character's **deviation from the Nash equilibrium** of the stage game. Formally: if {{< m >}}s^*{{< /m >}} is the Nash equilibrium and {{< m >}}s(t){{< /m >}} is the character's action at dramatic time {{< m >}}t{{< /m >}}, the dramatic intensity {{< m >}}I(t){{< /m >}} is maximized when {{< m >}}\|u(s(t), s_{-i}^*) - u(s^*, s_{-i}^*)\|{{< /m >}} is maximized.

This would connect game-theoretic structure to measurable audience response (galvanic skin response, fMRI activation), and could be tested against the prediction-error framework of {{< episode-ref ep="25" >}}EP25{{< /episode-ref >}}.
{{< /conjecture >}}

5. **Mixed-strategy interpretation in performance**. When Xenakis prescribes mixed strategies, conductors must randomize. But human randomization is notoriously biased (Rapoport & Budescu 1997). Does the aesthetic quality of a *Duel* performance correlate with how closely conductors approximate the minimax distribution?
