## Overview

Beethoven's Fifth Symphony, fourth movement, deploys over twenty orchestral staves. Collapse all octave doublings, and the climax still demands more than ten distinct pitch heights simultaneously — more than two human hands can play. How do you reduce a full orchestra to a piano score without destroying the harmonic structure? And what is the *minimum* number of voices absolutely required?

This episode answers both questions with graph coloring. Model each note as a vertex; connect two vertices when their sounding intervals overlap in time. The resulting **interval graph** encodes all simultaneity conflicts. The **chromatic number** {{< m >}}\chi(G){{< /m >}} of this graph is the minimum number of voices (colors) needed so that no two simultaneously-sounding notes share a voice. The **Perfect Graph Theorem** (Lovász, 1972) guarantees that for interval graphs {{< m >}}\chi = \omega{{< /m >}} — the chromatic number equals the clique number, i.e., the maximum number of notes sounding at once. A single greedy pass along the time axis achieves this bound in linear time.

When {{< m >}}\omega{{< /m >}} exceeds the number of available performers, the theorem gives the precise cost of every forced deletion — turning an artistic choice into a quantifiable trade-off.

## Definitions

{{< definition name="Proper Graph Coloring" label="Def 6.1" >}}
A **proper {{< m >}}k{{< /m >}}-coloring** of a graph {{< m >}}G = (V,E){{< /m >}} is a function {{< m >}}c : V \to \{1,2,\ldots,k\}{{< /m >}} such that {{< m >}}c(u) \ne c(v){{< /m >}} whenever {{< m >}}\{u,v\} \in E{{< /m >}}.

The **chromatic number** {{< m >}}\chi(G){{< /m >}} is the smallest {{< m >}}k{{< /m >}} for which a proper {{< m >}}k{{< /m >}}-coloring exists.
{{< /definition >}}

{{< definition name="Clique Number" label="Def 6.2" >}}
A **clique** in {{< m >}}G{{< /m >}} is a set of vertices that are pairwise adjacent. The **clique number** {{< m >}}\omega(G){{< /m >}} is the size of the largest clique.

Since any clique requires all its vertices to have distinct colors, {{< m >}}\chi(G) \ge \omega(G){{< /m >}} always.
{{< /definition >}}

{{< definition name="Interval Graph" label="Def 6.3" >}}
An **interval graph** {{< m >}}G = (V,E){{< /m >}} is constructed from a finite set of closed intervals {{< m >}}\{[a_i, b_i]\}_{i=1}^n{{< /m >}} on the real line by:
- setting {{< m >}}V = \{1, 2, \ldots, n\}{{< /m >}} (one vertex per interval),
- connecting {{< m >}}i{{< /m >}} and {{< m >}}j{{< /m >}} with an edge iff {{< m >}}[a_i, b_i] \cap [a_j, b_j] \ne \emptyset{{< /m >}} (intervals overlap).

In the musical application, each interval {{< m >}}[a_i, b_i]{{< /m >}} represents the sounding duration of note {{< m >}}i{{< /m >}}: onset {{< m >}}a_i{{< /m >}}, release {{< m >}}b_i{{< /m >}}.
{{< /definition >}}

{{< definition name="Perfect Graph" label="Def 6.4" >}}
A graph {{< m >}}G{{< /m >}} is **perfect** if for every induced subgraph {{< m >}}H \subseteq G{{< /m >}}:
{{< dm >}}\chi(H) = \omega(H).{{< /dm >}}

Equivalently, {{< m >}}G{{< /m >}} is perfect iff neither {{< m >}}G{{< /m >}} nor its complement {{< m >}}\bar{G}{{< /m >}} contains an odd cycle of length {{< m >}}\ge 5{{< /m >}} as an induced subgraph (this is the content of the **Strong Perfect Graph Theorem**, Chudnovsky et al. 2006).
{{< /definition >}}

{{< definition name="Chromatic Polynomial" label="Def 6.5" >}}
The **chromatic polynomial** {{< m >}}P(G, k){{< /m >}} counts the number of proper {{< m >}}k{{< /m >}}-colorings of {{< m >}}G{{< /m >}}. It is a polynomial in {{< m >}}k{{< /m >}} of degree {{< m >}}|V|{{< /m >}}.

Examples:
- {{< m >}}P(K_n, k) = k(k-1)(k-2)\cdots(k-n+1){{< /m >}} — must assign {{< m >}}n{{< /m >}} distinct colors.
- {{< m >}}P(T_n, k) = k(k-1)^{n-1}{{< /m >}} — tree on {{< m >}}n{{< /m >}} vertices; each new vertex has one neighbor constraint.
- {{< m >}}P(C_5, k) = (k-1)^5 + (k-1){{< /m >}} — the 5-cycle (odd cycle), which violates perfection: {{< m >}}P(C_5, 2) = 0{{< /m >}} but {{< m >}}\omega(C_5) = 2{{< /m >}}, confirming {{< m >}}\chi(C_5) = 3 > 2 = \omega(C_5){{< /m >}}.
{{< /definition >}}

## Main Theorems

{{< theorem name="Interval Graphs are Perfect" label="Theorem 6.1" >}}
Every interval graph is a perfect graph: {{< m >}}\chi(G) = \omega(G){{< /m >}} for any interval graph {{< m >}}G{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
We show that the greedy algorithm achieves {{< m >}}\omega(G){{< /m >}} colors, establishing {{< m >}}\chi(G) \le \omega(G){{< /m >}}. Since {{< m >}}\chi \ge \omega{{< /m >}} always, equality follows.

**Algorithm:** Sort the {{< m >}}n{{< /m >}} intervals by left endpoint: {{< m >}}a_{\sigma(1)} \le a_{\sigma(2)} \le \cdots \le a_{\sigma(n)}{{< /m >}}. Process vertices in this order. When processing vertex {{< m >}}v{{< /m >}} with interval {{< m >}}[a_v, b_v]{{< /m >}}, assign the smallest color {{< m >}}c \notin \{c(u) : u \text{ is a neighbor of } v \text{ already processed}\}{{< /m >}}.

**Claim:** The algorithm uses at most {{< m >}}\omega(G){{< /m >}} colors.

At the moment vertex {{< m >}}v{{< /m >}} is processed, the set of already-processed neighbors of {{< m >}}v{{< /m >}} is exactly {{< m >}}N_<(v) = \{u : a_u \le a_v \text{ and } b_u \ge a_v\}{{< /m >}} — the intervals that started before {{< m >}}v{{< /m >}} and are still sounding when {{< m >}}v{{< /m >}} begins. Together with {{< m >}}v{{< /m >}} itself, the set {{< m >}}N_<(v) \cup \{v\}{{< /m >}} is a clique (all pairwise overlapping, since they all contain {{< m >}}a_v{{< /m >}} in their interiors). Therefore {{< m >}}|N_<(v) \cup \{v\}| \le \omega(G){{< /m >}}.

Since {{< m >}}v{{< /m >}} needs a color different from at most {{< m >}}|N_<(v)| = \omega(G) - 1{{< /m >}} colors, there is always a color in {{< m >}}\{1,\ldots,\omega(G)\}{{< /m >}} available. The algorithm never needs a {{< m >}}(\omega(G)+1){{< /m >}}-th color. {{< m >}}\square{{< /m >}}

**Why general graphs fail:** The odd 5-cycle {{< m >}}C_5{{< /m >}} has {{< m >}}\omega = 2{{< /m >}} but {{< m >}}\chi = 3{{< /m >}}. The greedy ordering can be bad (e.g., alternating vertices of {{< m >}}C_5{{< /m >}}) and need a third color. But {{< m >}}C_5{{< /m >}} cannot be an interval graph, because any five intervals containing a cyclic overlap pattern must contain a "triangle" (three mutually overlapping intervals) by the Helly property for intervals on the line: if pairwise intersections are nonempty, the total intersection is nonempty.
{{< /proof >}}

{{< theorem name="Perfect Graph Theorem (Lovász, 1972)" label="Theorem 6.2" >}}
A graph {{< m >}}G{{< /m >}} is perfect if and only if its complement {{< m >}}\bar{G}{{< /m >}} is perfect.

Equivalently (the **Weak Perfect Graph Theorem**): {{< m >}}G{{< /m >}} is perfect iff it contains no odd cycle of length {{< m >}}\ge 5{{< /m >}} as an induced subgraph, and neither does {{< m >}}\bar{G}{{< /m >}}.
{{< /theorem >}}

{{< proof >}}
The full proof is deep (Lovász's original 1972 proof uses a topological argument; the full Strong Perfect Graph Theorem by Chudnovsky, Robertson, Seymour, Thomas (2006) is a 150-page paper). We give the key idea for the weak version.

**Necessity ({{< m >}}\Rightarrow{{< /m >}}):** An odd cycle {{< m >}}C_{2k+1}{{< /m >}} with {{< m >}}k \ge 2{{< /m >}} has {{< m >}}\omega = 2{{< /m >}} (no triangle since it is an odd cycle) but {{< m >}}\chi = 3{{< /m >}} (it takes 3 colors to properly color any odd cycle). So it is not perfect.

**Sufficiency ({{< m >}}\Leftarrow{{< /m >}}) sketch (Lovász's approach):** The key lemma is that any minimal non-perfect graph {{< m >}}G{{< /m >}} must satisfy {{< m >}}|V||E(\bar{G})| \ge \binom{|V|}{2} + \alpha(G)\omega(G){{< /m >}} where {{< m >}}\alpha{{< /m >}} is the independence number. Lovász showed this forces the existence of an odd hole or odd antihole. The details require the theory of perfect graph structure theorems. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="Brooks' Theorem" label="Theorem 6.3" >}}
For any connected graph {{< m >}}G{{< /m >}} that is neither a complete graph {{< m >}}K_n{{< /m >}} nor an odd cycle {{< m >}}C_{2k+1}{{< /m >}}:
{{< dm >}}\chi(G) \le \Delta(G){{< /dm >}}
where {{< m >}}\Delta(G){{< /m >}} is the maximum degree.

(The bound {{< m >}}\chi(G) \le \Delta(G) + 1{{< /m >}} always holds by greedy coloring; Brooks' theorem improves this by 1 in all non-exceptional cases.)
{{< /theorem >}}

{{< proof >}}
**Greedy bound {{< m >}}\chi \le \Delta + 1{{< /m >}}:** When the greedy algorithm processes a vertex {{< m >}}v{{< /m >}}, it has at most {{< m >}}\deg(v) \le \Delta{{< /m >}} neighbors already colored. At most {{< m >}}\Delta{{< /m >}} colors are forbidden, so one of {{< m >}}\{1, \ldots, \Delta+1\}{{< /m >}} is always available.

**Improvement to {{< m >}}\Delta{{< /m >}} (sketch):** The key step is to find a vertex ordering in which every vertex except the last has a neighbor later in the ordering. For a {{< m >}}\Delta{{< /m >}}-regular connected non-complete graph, one shows (using a spanning tree rooted at a non-cut vertex) an ordering where each vertex has at most {{< m >}}\Delta - 1{{< /m >}} earlier-colored neighbors, allowing greedy to use only {{< m >}}\Delta{{< /m >}} colors. The odd cycle is exceptional because any {{< m >}}\Delta = 2{{< /m >}} coloring attempt on {{< m >}}C_{2k+1}{{< /m >}} fails at the last step. {{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< proposition label="Prop 6.1" name="Helly Property for Intervals" >}}
Let {{< m >}}\{[a_i, b_i]\}_{i=1}^n{{< /m >}} be a collection of intervals on the real line. If every two intervals intersect (pairwise intersection), then all intervals share a common point: {{< m >}}\bigcap_{i=1}^n [a_i, b_i] \ne \emptyset{{< /m >}}.
{{< /proposition >}}

{{< proof >}}
Let {{< m >}}p = \max_i a_i{{< /m >}} (rightmost left endpoint) and {{< m >}}q = \min_i b_i{{< /m >}} (leftmost right endpoint). For the interval achieving {{< m >}}p{{< /m >}}, say {{< m >}}[a_k, b_k]{{< /m >}}, and the interval achieving {{< m >}}q{{< /m >}}, say {{< m >}}[a_l, b_l]{{< /m >}}: since these two intersect, {{< m >}}a_k \le b_l{{< /m >}}, i.e., {{< m >}}p \le q{{< /m >}}. Then the point {{< m >}}p{{< /m >}} (or any point in {{< m >}}[p,q]{{< /m >}}) belongs to every interval. {{< m >}}\square{{< /m >}}

This property underlies the perfection of interval graphs: it prevents the formation of odd holes (chordless odd cycles of length {{< m >}}\ge 5{{< /m >}}), since three pairwise-overlapping intervals always share a common time point, forming a triangle rather than a triangle-free cycle.
{{< /proof >}}

## Musical Connection

{{< musical-connection >}}
**Voice allocation as graph coloring**

Every polyphonic score implicitly defines an interval graph: notes are vertices, simultaneous notes are adjacent. The chromatic number is the minimum voice count. For Bach's C-major Fugue BWV 846:

- Maximum simultaneous voices: {{< m >}}\omega = 4{{< /m >}}
- Chromatic number (by perfection): {{< m >}}\chi = 4{{< /m >}}
- Bach's actual voices: 4 — exactly matching the theoretical minimum

No voice is redundant; no voice can be removed without a collision. The theorem *proves* that Bach's four-voice writing is tight.

For Beethoven's Fifth Symphony, fourth movement:
- After collapsing octave doublings, {{< m >}}\omega > 10{{< /m >}} at the climax
- Two hands give at most 10 simultaneous notes
- The theorem guarantees the reduction is *lossy by necessity*, not by artistic choice

**Liszt's strategy (1865) as high-degree-first deletion**

When {{< m >}}\omega > 10{{< /m >}}, Liszt retained the outer voices (melody and bass) and deleted middle-register doublings. In graph-theoretic terms: middle-register notes have the highest degree (most overlaps with other notes), so deleting them disrupts the fewest colorings. This is equivalent to a **maximum independent set** heuristic on the conflict subgraph — preserve as many non-conflicting notes as possible.

**Register allocation in compilers (Chaitin, 1982)**

IBM's Gregory Chaitin recognized that assigning variables to CPU registers is exactly graph coloring: variables are vertices, two variables are adjacent if they are *live* simultaneously (overlap in program execution time), and registers are colors. The variable liveness graph is an interval graph (live ranges are intervals of program time), so {{< m >}}\chi = \omega{{< /m >}} and greedy allocation is optimal when registers suffice. When registers are insufficient ({{< m >}}\omega > k{{< /m >}} registers available), some variables must "spill" to memory. Chaitin's heuristic: spill the variable with the highest degree (most conflicts) — the same principle as Liszt deleting the most-overlapping middle voices.

Music and compiler design, separated by 117 years, converge on the same graph-coloring trade-off.
{{< /musical-connection >}}

## Limits and Open Questions

1. **The Four Color Theorem.** For *planar* graphs (graphs drawable without edge crossings), {{< m >}}\chi \le 4{{< /m >}}. Proved by Appel and Haken (1976) using computer-assisted case analysis — the first major theorem proved by computer. Musical planar graphs arise when voice crossings are forbidden (a common constraint in choral writing).

2. **Kempe chains and the failed 1879 proof.** Alfred Kempe published a purported proof of the four color theorem in 1879. His key idea was "Kempe chains" — maximal connected subgraphs alternating between two colors. In 1890, Percy Heawood found Kempe's proof was flawed. Kempe chains are still used in graph coloring algorithms; the flaw only appears in a subtle case with five-colored maps.

3. **Chromatic polynomial complexity.** Computing {{< m >}}P(G, k){{< /m >}} for general {{< m >}}G{{< /m >}} is {{< m >}}\#\mathbf{P}{{< /m >}}-hard (harder than NP), but for interval graphs it can be computed in polynomial time due to the perfect structure.

4. **Tonal pitch space vs. pitch height.** The interval graph model treats pitch height as a continuous real variable. But Western tonal harmony groups notes into equivalence classes (e.g., C4 and C5 are "the same harmony"). A richer model uses the pitch helix (introduced in EP08) and asks about coloring in that quotient space.

5. **Weighted coloring for dynamics.** If different notes carry different dynamic markings, a *weighted* chromatic number would give the minimum number of weighted voices. This is open in general for weighted interval graphs.
