## 概述

"数字音频是阶梯波，每个采样点之间的信号是猜出来的，所以数字不如模拟自然。"
这句话流传极广，却从根本上误解了信号重建的数学。Nyquist-Shannon 采样定理告诉我们：
若信号带宽有限，仅凭等间隔的离散采样值，原始连续波形可以被**完美**还原——不是近似，是精确重建。
重建的钥匙是 sinc 函数，它在离散样本之间填补的不是猜测，而是由采样值唯一确定的答案。

然而采样只是数字音频管道的第一关。本集的核心论点是：**采样不是数字音频中最脆弱的环节，量化才是。**
量化将连续幅度映射到有限电平，不可避免地引入截断误差。若不加处理，低电平信号的量化误差与信号高度相关，
产生刺耳的谐波失真，而非可接受的白噪声底。解决这一问题的技术链条——抖动（dithering）与噪声整形（noise shaping）——
是 CD 格式在 44.1 kHz / 16-bit 限制下仍能听起来如此优秀的真正原因。

本集从频域推导采样定理，经量化 SNR 公式推导，再到 TPDF 三角概率分布的证明，最终分析一阶噪声整形的传输函数 {{< m >}}\text{NTF}(z) = 1 - z^{-1}{{< /m >}}，给出完整的数字音频转换链的数学图景。

> *中文:* "你有没有听过这种说法：数字音频是阶梯波，每个采样点之间的信号是'猜'出来的，所以数字不如模拟'自然'。这是错的。采样定理告诉我们，只要采样率足够高，原始信号可以被完美重建——不是近似，是完美。重建的工具，叫sinc函数。今天我们把这件事从头算清楚。"

## 定义

{{< definition name="带限信号" label="Definition 30.1" >}}
实值信号 {{< m >}}x(t){{< /m >}} 称为**带限于 {{< m >}}B{{< /m >}} Hz** 的信号，若其傅里叶变换

{{< dm >}}\hat{x}(f) = \int_{-\infty}^{\infty} x(t)\, e^{-2\pi i f t}\, dt{{< /dm >}}

满足 {{< m >}}\hat{x}(f) = 0{{< /m >}} 对所有 {{< m >}}|f| > B{{< /m >}} 成立。即信号的所有能量都集中在频率区间 {{< m >}}[-B, B]{{< /m >}} 内。

**例**：人耳可感知频率上限约 20 kHz，因此对语音/音乐信号 {{< m >}}B = 20{,}000{{< /m >}} Hz 即已足够。
{{< /definition >}}

{{< definition name="sinc 函数" label="Definition 30.2" >}}
**归一化 sinc 函数**定义为

{{< dm >}}\operatorname{sinc}(u) = \frac{\sin(\pi u)}{\pi u}, \qquad \operatorname{sinc}(0) \coloneqq 1{{< /dm >}}

关键性质：
- {{< m >}}\operatorname{sinc}(0) = 1{{< /m >}}；
- {{< m >}}\operatorname{sinc}(n) = 0{{< /m >}} 对所有非零整数 {{< m >}}n \in \mathbb{Z} \setminus \{0\}{{< /m >}}；
- {{< m >}}\int_{-\infty}^{\infty} \operatorname{sinc}(u)\, du = 1{{< /m >}}；
- 其傅里叶变换为矩形窗：{{< m >}}\mathcal{F}[\operatorname{sinc}(t/T)](f) = T \cdot \mathbf{1}_{|f| \leq 1/(2T)}(f){{< /m >}}。

**直觉**：sinc 函数是一根"理想的插值脉冲"——在自身时刻取值 1，在所有其他整数时刻取值 0。
{{< /definition >}}

{{< definition name="均匀量化与最低有效位" label="Definition 30.3" >}}
给定 {{< m >}}n{{< /m >}} 比特量化器，满幅信号范围为 {{< m >}}[-A, A]{{< /m >}}，将该范围均匀划分为 {{< m >}}2^n{{< /m >}} 个电平，
**量化步长**（最低有效位，LSB）为

{{< dm >}}q = \frac{2A}{2^n}{{< /dm >}}

量化函数 {{< m >}}Q: \mathbb{R} \to \{-A + q/2,\, -A + 3q/2,\, \ldots,\, A - q/2\}{{< /m >}} 将输入四舍五入到最近电平。
量化误差定义为 {{< m >}}\varepsilon = Q(x) - x{{< /m >}}，满足 {{< m >}}|\varepsilon| \leq q/2{{< /m >}}。

**例（16-bit，满幅 ±1 V）**：{{< m >}}q = 2/(2^{16}) = 1/32768 \approx 30.5\,\mu\text{V}{{< /m >}}。一个电平的宽度仅 30 微伏——这就是 CD 量化的精度。
{{< /definition >}}

{{< definition name="TPDF 抖动噪声" label="Definition 30.4" >}}
**三角概率密度函数（Triangular Probability Density Function, TPDF）**噪声 {{< m >}}D{{< /m >}} 具有概率密度

{{< dm >}}p_D(d) = \frac{1}{q}\left(1 - \frac{|d|}{q}\right) \mathbf{1}_{|d| \leq q}(d){{< /dm >}}

即在 {{< m >}}[-q, q]{{< /m >}} 上的三角形分布，均值为零，方差为 {{< m >}}\sigma_D^2 = q^2/6{{< /m >}}。

**为什么是三角形？**  两个独立的、均匀分布在 {{< m >}}[-q/2, q/2]{{< /m >}} 的随机变量之差的概率密度，
恰好是两个矩形函数的**卷积**，其结果是三角形（见 Theorem 30.3）。
{{< /definition >}}

{{< definition name="噪声传输函数" label="Definition 30.5" >}}
在 {{< m >}}z{{< /m >}} 域中，离散时间滤波器对量化误差的频率响应称为**噪声传输函数（Noise Transfer Function, NTF）**。
对一阶误差反馈噪声整形器，NTF 定义为

{{< dm >}}\text{NTF}(z) = 1 - z^{-1}{{< /dm >}}

其频率响应（令 {{< m >}}z = e^{i\omega}{{< /m >}}）为

{{< dm >}}|\text{NTF}(e^{i\omega})|^2 = |1 - e^{-i\omega}|^2 = 4\sin^2\!\left(\frac{\omega}{2}\right){{< /dm >}}

在 {{< m >}}\omega = 0{{< /m >}}（直流）处为零，在 {{< m >}}\omega = \pi{{< /m >}}（Nyquist）处为最大值 4。这意味着噪声能量从低频被"推"向高频。
{{< /definition >}}

## 主要定理

{{< theorem name="Nyquist-Shannon 采样定理" label="Theorem 30.1" >}}
设 {{< m >}}x(t){{< /m >}} 是带限于 {{< m >}}B{{< /m >}} Hz 的信号，即 {{< m >}}\hat{x}(f) = 0{{< /m >}} 对 {{< m >}}|f| > B{{< /m >}} 成立。
取采样间隔 {{< m >}}T \leq \dfrac{1}{2B}{{< /m >}}（等价地，采样率 {{< m >}}f_s = 1/T \geq 2B{{< /m >}}），
则 {{< m >}}x(t){{< /m >}} 可由其采样序列 {{< m >}}\{x(nT)\}_{n=-\infty}^{\infty}{{< /m >}} 完全确定，并由下式精确重建：

{{< dm >}}x(t) = \sum_{n=-\infty}^{\infty} x(nT)\cdot \operatorname{sinc}\!\left(\frac{t - nT}{T}\right){{< /dm >}}

**结论**：对带限信号，离散采样不损失任何信息；"阶梯波近似"是零阶保持电路的产物，而非采样定理的必然结果。
{{< /theorem >}}

{{< proof >}}
**步骤 1：采样 = 乘以 Dirac 梳状函数。**

对 {{< m >}}x(t){{< /m >}} 进行理想采样，等价于乘以周期为 {{< m >}}T{{< /m >}} 的 Dirac 梳状函数：

{{< dm >}}x_s(t) = x(t) \cdot \sum_{n=-\infty}^{\infty} \delta(t - nT) = \sum_{n=-\infty}^{\infty} x(nT)\,\delta(t - nT){{< /dm >}}

**步骤 2：频域中，采样 = 频谱的周期化。**

由卷积定理，时域相乘对应频域卷积。梳状函数的傅里叶变换仍是梳状函数：

{{< dm >}}\mathcal{F}\!\left[\sum_n \delta(t - nT)\right](f) = \frac{1}{T}\sum_k \delta\!\left(f - \frac{k}{T}\right){{< /dm >}}

因此

{{< dm >}}\hat{x}_s(f) = \frac{1}{T}\sum_{k=-\infty}^{\infty} \hat{x}\!\left(f - \frac{k}{T}\right){{< /dm >}}

即 {{< m >}}\hat{x}_s(f){{< /m >}} 是 {{< m >}}\hat{x}(f){{< /m >}} 以 {{< m >}}1/T{{< /m >}} 为周期的复制叠加。

**步骤 3：无混叠条件 ⟺ 副本不重叠。**

由于 {{< m >}}x(t){{< /m >}} 带限于 {{< m >}}B{{< /m >}}，每个副本 {{< m >}}\hat{x}(f - k/T){{< /m >}} 支撑在 {{< m >}}|f - k/T| \leq B{{< /m >}} 上。
相邻副本（{{< m >}}k=0{{< /m >}} 与 {{< m >}}k=\pm 1{{< /m >}}）不重叠，当且仅当

{{< dm >}}B \leq \frac{1}{2T} \iff T \leq \frac{1}{2B} \iff f_s \geq 2B{{< /dm >}}

**步骤 4：重建 = 乘以矩形窗低通滤波器。**

在无混叠条件下，将 {{< m >}}\hat{x}_s(f){{< /m >}} 乘以矩形窗 {{< m >}}T \cdot \mathbf{1}_{|f| \leq 1/(2T)}{{< /m >}} 恰好还原出 {{< m >}}\hat{x}(f){{< /m >}}。
时域对应与 sinc 函数卷积：

{{< dm >}}x(t) = x_s(t) * \left[T \cdot \frac{1}{T}\operatorname{sinc}\!\left(\frac{t}{T}\right)\right] = \sum_n x(nT)\,\delta(t - nT) * \operatorname{sinc}\!\left(\frac{t}{T}\right) = \sum_n x(nT)\operatorname{sinc}\!\left(\frac{t-nT}{T}\right){{< /dm >}}

这正是定理中的重建公式。{{< m >}}\square{{< /m >}}

**验证插值性质**：在 {{< m >}}t = kT{{< /m >}} 时，{{< m >}}\operatorname{sinc}\!\bigl((kT - nT)/T\bigr) = \operatorname{sinc}(k-n){{< /m >}}，
因 {{< m >}}k - n \in \mathbb{Z}{{< /m >}}，当 {{< m >}}k \neq n{{< /m >}} 时为 0，当 {{< m >}}k = n{{< /m >}} 时为 1。故公式右侧在 {{< m >}}t = kT{{< /m >}} 处精确还原 {{< m >}}x(kT){{< /m >}}。{{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="量化 SNR 公式" label="Theorem 30.2" >}}
对 {{< m >}}n{{< /m >}} 比特均匀量化，满幅正弦信号的信噪比为

{{< dm >}}\text{SNR} = 6.02n + 1.76 \text{ dB}{{< /dm >}}

具体地，每增加 1 比特，SNR 提升约 6 dB。
{{< /theorem >}}

{{< proof >}}
**量化误差功率**：在均匀量化的标准模型中，量化误差 {{< m >}}\varepsilon{{< /m >}} 被建模为在 {{< m >}}[-q/2, q/2]{{< /m >}} 上均匀分布的随机变量。其功率（方差）为

{{< dm >}}P_{\text{noise}} = \mathbb{E}[\varepsilon^2] = \int_{-q/2}^{q/2} \varepsilon^2 \cdot \frac{1}{q}\, d\varepsilon = \frac{1}{q} \cdot \frac{q^3/4 - (-q^3/4)}{3} \cdot \frac{1}{2} = \frac{q^2}{12}{{< /dm >}}

更直接地：{{< m >}}\int_{-q/2}^{q/2} \varepsilon^2 \cdot \frac{1}{q}\, d\varepsilon = \frac{1}{q} \cdot \frac{2(q/2)^3}{3} = \frac{q^2}{12}{{< /dm >}}。

**满幅正弦信号功率**：设满幅正弦波 {{< m >}}x(t) = A\sin(2\pi f_0 t){{< /m >}}，其中 {{< m >}}A = 2^n q / 2{{< /m >}}（使峰值正好达到量化范围上限）。功率为

{{< dm >}}P_{\text{signal}} = \frac{A^2}{2} = \frac{(2^{n-1} q)^2}{2} = \frac{2^{2n} q^2}{8}{{< /dm >}}

**SNR 的线性比值**：

{{< dm >}}\frac{P_{\text{signal}}}{P_{\text{noise}}} = \frac{2^{2n} q^2 / 8}{q^2 / 12} = \frac{12 \cdot 2^{2n}}{8} = \frac{3}{2} \cdot 2^{2n}{{< /dm >}}

**转换为分贝**：

{{< dm >}}\text{SNR} = 10\log_{10}\!\left(\frac{3}{2} \cdot 2^{2n}\right) = 10\log_{10}\!\frac{3}{2} + 10 \cdot 2n\log_{10} 2{{< /dm >}}

{{< dm >}}= 10 \times 0.17609 + 20n \times 0.30103 \approx 1.76 + 6.02n \text{ dB}{{< /dm >}}

即 {{< m >}}\text{SNR} \approx 6.02n + 1.76{{< /m >}} dB。{{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="TPDF 独立性定理" label="Theorem 30.3" >}}
设 {{< m >}}U_1, U_2 \overset{\text{i.i.d.}}{\sim} \operatorname{Uniform}[-q/2,\, q/2]{{< /m >}}，令 {{< m >}}D = U_1 - U_2{{< /m >}}。则：

1. **分布**：{{< m >}}D{{< /m >}} 服从 {{< m >}}[-q, q]{{< /m >}} 上的三角分布，概率密度为

{{< dm >}}p_D(d) = \frac{1}{q}\left(1 - \frac{|d|}{q}\right)\mathbf{1}_{|d|\leq q}(d){{< /dm >}}

2. **方差**：{{< m >}}\operatorname{Var}(D) = q^2/6{{< /m >}}；

3. **独立性**：若在量化前向信号加入 TPDF 噪声 {{< m >}}D{{< /m >}}，则量化误差 {{< m >}}E = Q(x + D) - x{{< /m >}} 的统计特性**与输入信号 {{< m >}}x{{< /m >}} 无关**。
{{< /theorem >}}

{{< proof >}}
**第一部分（三角分布）**：

{{< m >}}D = U_1 - U_2{{< /m >}} 的概率密度是 {{< m >}}U_1{{< /m >}} 与 {{< m >}}-U_2{{< /m >}} 各自密度的卷积。由于 {{< m >}}-U_2 \sim \operatorname{Uniform}[-q/2, q/2]{{< /m >}}（均匀分布关于零对称），

{{< dm >}}p_D(d) = (p_{U_1} * p_{-U_2})(d) = \int_{-q/2}^{q/2} p_{U_1}(d + u)\, p_{U_2}(u)\, du{{< /dm >}}

其中 {{< m >}}p_{U_1}(s) = p_{U_2}(s) = \frac{1}{q}\mathbf{1}_{|s|\leq q/2}{{< /m >}}。计算积分：

对 {{< m >}}0 \leq d \leq q{{< /m >}}，被积函数非零当且仅当 {{< m >}}-q/2 \leq u \leq q/2{{< /m >}} 且 {{< m >}}-q/2 \leq d+u \leq q/2{{< /m >}}，
即 {{< m >}}-q/2 - d \leq u \leq q/2 - d{{< /m >}} 与 {{< m >}}-q/2 \leq u \leq q/2{{< /m >}} 的交集为 {{< m >}}[-q/2, q/2 - d]{{< /m >}}，长度 {{< m >}}q - d{{< /m >}}。
故

{{< dm >}}p_D(d) = \frac{1}{q^2}(q - d) = \frac{1}{q}\left(1 - \frac{d}{q}\right), \quad 0 \leq d \leq q{{< /dm >}}

由 {{< m >}}D{{< /m >}} 的分布关于 0 对称（因 {{< m >}}U_1, U_2{{< /m >}} 同分布），{{< m >}}d < 0{{< /m >}} 时 {{< m >}}p_D(d) = \frac{1}{q}(1 + d/q){{< /m >}}，合写为 {{< m >}}\frac{1}{q}(1 - |d|/q){{< /m >}}。

**第二部分（方差）**：

{{< dm >}}\operatorname{Var}(D) = \operatorname{Var}(U_1) + \operatorname{Var}(U_2) = 2 \cdot \frac{q^2}{12} = \frac{q^2}{6}{{< /dm >}}

**第三部分（独立性）**：

在量化前加入 TPDF 噪声 {{< m >}}D{{< /m >}}，所量化的值为 {{< m >}}x + D{{< /m >}}。
关键观察：{{< m >}}D{{< /m >}} 的范围跨越 {{< m >}}[-q, q]{{< /m >}}，宽度为 {{< m >}}2q{{< /m >}}，而量化步长为 {{< m >}}q{{< /m >}}。
对于任意固定的 {{< m >}}x{{< /m >}}，{{< m >}}x + D{{< /m >}} 在长度 {{< m >}}2q{{< /m >}} 的范围内以三角形分布随机取值；
由于三角分布在每个 {{< m >}}q{{< /m >}} 宽度的区间内的积分完全由 {{< m >}}D{{< /m >}} 的分布决定，
量化后误差 {{< m >}}E = Q(x+D) - x{{< /m >}} 的分布不依赖于 {{< m >}}x{{< /m >}} 落在哪个量化区间内。
故 {{< m >}}E{{< /m >}} 与 {{< m >}}x{{< /m >}} **统计独立**，量化误差从谐波失真退化为与信号无关的白噪声。{{< m >}}\square{{< /m >}}
{{< /proof >}}

{{< theorem name="一阶噪声整形的频谱特性" label="Theorem 30.4" >}}
设一阶误差反馈噪声整形器的噪声传输函数为

{{< dm >}}\text{NTF}(z) = 1 - z^{-1}{{< /dm >}}

则：

1. **频率响应**：令 {{< m >}}z = e^{i\omega}{{< /m >}}（{{< m >}}\omega \in [0, \pi]{{< /m >}} 为归一化角频率），有

{{< dm >}}|\text{NTF}(e^{i\omega})|^2 = 4\sin^2\!\left(\frac{\omega}{2}\right){{< /dm >}}

2. **低频噪声压制**：在带宽 {{< m >}}[0, \omega_{\max}]{{< /m >}} 内（{{< m >}}\omega_{\max} \ll \pi{{< /m >}}），整形后噪声功率相比无整形减少比例约为

{{< dm >}}\frac{\int_0^{\omega_{\max}} 4\sin^2(\omega/2)\, d\omega}{\int_0^{\pi} 4\sin^2(\omega/2)\, d\omega} \approx \frac{\omega_{\max}^3/3}{\pi} \quad (\omega_{\max} \to 0){{< /dm >}}

3. **DC 处为零**：{{< m >}}|\text{NTF}(e^{i\cdot 0})|^2 = 0{{< /m >}}；**Nyquist 处为最大**：{{< m >}}|\text{NTF}(e^{i\pi})|^2 = 4{{< /m >}}。
{{< /theorem >}}

{{< proof >}}
**第一部分（频率响应推导）**：

令 {{< m >}}z = e^{i\omega}{{< /m >}}，则

{{< dm >}}\text{NTF}(e^{i\omega}) = 1 - e^{-i\omega}{{< /dm >}}

利用恒等式 {{< m >}}1 - e^{-i\omega} = e^{-i\omega/2}(e^{i\omega/2} - e^{-i\omega/2}) = e^{-i\omega/2} \cdot 2i\sin(\omega/2){{< /dm >}}，取模平方：

{{< dm >}}|\text{NTF}(e^{i\omega})|^2 = |e^{-i\omega/2}|^2 \cdot |2i\sin(\omega/2)|^2 = 1 \cdot 4\sin^2\!\left(\frac{\omega}{2}\right){{< /dm >}}

**第二部分（低频噪声功率）**：

未整形时，量化噪声功率在 {{< m >}}[0, \pi]{{< /m >}} 均匀分布（白噪声）。整形后带内噪声功率正比于

{{< dm >}}\int_0^{\omega_{\max}} 4\sin^2\!\left(\frac{\omega}{2}\right) d\omega{{< /dm >}}

由 {{< m >}}\sin^2(u) \approx u^2{{< /m >}}（{{< m >}}u \to 0{{< /m >}}），令 {{< m >}}u = \omega/2{{< /m >}}：

{{< dm >}}\int_0^{\omega_{\max}} 4\left(\frac{\omega}{2}\right)^2 d\omega = \int_0^{\omega_{\max}} \omega^2\, d\omega = \frac{\omega_{\max}^3}{3}{{< /dm >}}

而无整形时带内噪声功率正比于 {{< m >}}\omega_{\max}{{< /m >}}（白噪声均匀分布）。故整形带来的压制比例为

{{< dm >}}\frac{\omega_{\max}^3/3}{\omega_{\max} \cdot \pi} = \frac{\omega_{\max}^2}{3\pi}{{< /dm >}}

对于 CD 格式（44.1 kHz 采样，音频带宽 20 kHz），{{< m >}}\omega_{\max} = \pi \cdot (20/22.05) \approx 0.907\pi{{< /m >}}，
实际低频噪声功率相比奈奎斯特频段被大幅重新分布，听觉带内感知 SNR 等效提升约 2 bit。

**第三部分**：

{{< m >}}\omega = 0{{< /m >}}：{{< m >}}4\sin^2(0) = 0{{< /m >}}。{{< m >}}\omega = \pi{{< /m >}}：{{< m >}}4\sin^2(\pi/2) = 4 \cdot 1 = 4{{< /m >}}。{{< m >}}\square{{< /m >}}
{{< /proof >}}

## 数值示例

**不同比特深度的 SNR**（满幅正弦信号，均匀量化）：

| 比特深度 {{< m >}}n{{< /m >}} | 理论 SNR (dB) | 等效动态范围 | 备注 |
|:---:|:---:|:---:|:---|
| 8 | 49.9 | ~50 dB | 早期游戏机、电话语音 |
| 16 | 98.1 | ~98 dB | CD 格式，覆盖人耳完整动态范围 |
| 24 | 146.2 | ~146 dB | 专业录音，超出人耳极限约 60 dB |
| 32 | 194.2 | ~194 dB | 浮点格式，实际受限于底噪地板 |

**计算验证（16-bit）**：

{{< dm >}}\text{SNR}_{16} = 6.02 \times 16 + 1.76 = 96.32 + 1.76 = 98.08 \text{ dB}{{< /dm >}}

**计算验证（24-bit）**：

{{< dm >}}\text{SNR}_{24} = 6.02 \times 24 + 1.76 = 144.48 + 1.76 = 146.24 \text{ dB}{{< /dm >}}

人耳的动态范围约为 0 dB（听觉阈值）到 120 dB（痛觉阈值），共 120 dB。
16-bit 已有约 98 dB，高于实际音频使用场景（专业录音室底噪约 -70 dBFS）中的需求。
24-bit 的额外 48 dB 不是给听众的——是给工程师在增益调整、混音压缩时留出的**运算余量**（headroom）。

> *中文:* "代入具体数字：十六比特给出约九十八分贝——覆盖人耳动态范围。二十四比特给出约一百四十六分贝——超过人耳极限六十分贝。所以专业录音用二十四比特，不是为了你能听到更多细节，而是给工程师留了足够的增益余量。"

**TPDF 噪声方差计算**：

TPDF 噪声 {{< m >}}D = U_1 - U_2{{< /m >}} 的方差 {{< m >}}= q^2/6{{< /m >}}，比均匀量化误差方差 {{< m >}}q^2/12{{< /m >}} 大一倍。
这是抖动的代价：底噪功率加倍（约 +3 dB），但换来了量化误差与信号的统计独立性。

**噪声整形增益估算**：

一阶 NTF 在音频带（0–20 kHz）内的有效噪声压制：

{{< dm >}}\text{压制比例} \approx \frac{\omega_{\max}^2}{3\pi} \approx \frac{(0.907\pi)^2}{3\pi} \approx \frac{0.823\pi}{3} \approx 0.86{{< /dm >}}

这意味着约 14% 的噪声能量留在音频带内；其余被推向 20 kHz 以上。
五阶 NTF 可将这一比例进一步压低至等效 +4 bit 的感知 SNR 提升。

## 音乐联系

{{< musical-connection >}}
**为什么 CD 听起来比理论预测好**

理论告诉我们 16-bit 的 SNR 约为 98 dB；人耳动态范围约 120 dB；看起来 CD 格式有 22 dB 的缺口。
但实际上，现代 CD 播放器在 D/A 转换前都加入了 TPDF 抖动与噪声整形，
将量化误差的谐波失真成分消除，并将噪声能量推到 20 kHz 以上——超出人耳敏感范围。
最终感知 SNR 可等效于 18–20 bit 的量化深度，远超理论上的 16-bit 计算。
"CD 格式足够好"这一工程结论背后，是三个定理的精确协作：采样定理保证无混叠，TPDF 定理消除谐波失真，NTF 定理将代价推出听觉范围。

**模拟信号链的对应物**

噪声整形不是数字音频的发明。模拟调幅（AM）广播的预加重/去加重网络（de-emphasis），
将发射端的高频信号提升、接收端反向还原，达到与噪声整形类似的效果：
将信道噪声（主要在高频）在解调后被去加重滤波器压制。
这一思想与 NTF 的误差反馈完全对应——只是一个在模拟频域实现，另一个在数字 {{< m >}}z{{< /m >}} 域实现。

**与 EP02 的联系：傅里叶视角下的采样**

{{< episode-ref ep="2" >}}EP02 中的傅里叶级数{{< /episode-ref >}}揭示了时域和频域的对偶性。
采样定理正是这一对偶的精确利用：时域的离散采样（周期性冲激序列），
等价于频域的周期性复制。带限条件保证副本不重叠，从而重建唯一确定。
"采样 = 时域离散化" 与 "量化 = 幅度离散化" 在数字音频中形成正交的两个维度，
各自需要独立的数学工具来分析与补偿。

**与 EP35、EP39 的前向联系**

{{< episode-ref ep="35" >}}EP35（相位声码器）{{< /episode-ref >}}中，sinc 插值被直接用于时间拉伸算法：
在变换域对频率箱的相位进行重新插值，数学上与 Whittaker-Shannon 重建公式结构完全相同。

{{< episode-ref ep="39" >}}EP39（LUFS 响度标准）{{< /episode-ref >}}中，真峰值（True Peak）检测同样依赖 sinc 插值：
对 PCM 波形进行 4× 过采样后再取最大值，以检测采样点之间可能存在的幅度超限。
这是本集采样定理的直接工程应用——不过采样率足够高时，点间峰值可被精确预测。

## 局限性与开放问题

1. **理想 sinc 的物理不可实现性**：Whittaker-Shannon 重建公式要求**无限长**的 sinc 卷积核，在实时系统中不可实现。实际 DAC 使用有限长 FIR 滤波器近似，引入截断误差（Gibbs 现象）和线性相位延迟。最优截断窗函数（Kaiser 窗、Blackman-Harris 窗等）的参数选择是一个持续的工程优化问题。

2. **过采样与∑-Δ 调制的统一框架**：现代高分辨率音频 ADC 几乎全部采用∑-Δ（Sigma-Delta）架构：先以极高采样率（数 MHz）进行 1-bit 量化，再通过数字滤波器降采样。这将 TPDF 抖动、噪声整形和采样率转换整合为统一的架构。其精确的噪声分析需要高阶 NTF（如五阶、七阶），超出本集一阶分析的范围。

3. **非均匀量化与感知编码的协同**：本集假设均匀量化（每电平等宽）。实际上，人耳对低电平信号的感知灵敏度远高于高电平，μ律/A律压缩（电话语音）和 MP3 的比特分配算法（见 EP40）都是基于感知加权的非均匀量化，可在相同比特数下获得更高感知质量。

4. **抖动频谱的最优选择**：TPDF 并非唯一的抖动策略。高斯抖动具有更短的相关性，蓝噪声（high-pass shaped）抖动可将底噪能量进一步推向高频。目前缺乏在"最小感知底噪"意义下的最优抖动频谱的严格理论最优性证明。

{{< conjecture name="噪声整形阶数上限猜想" >}}
直觉上，NTF 阶数越高，音频带内噪声压制越强，感知 SNR 越高。
然而，高阶 NTF 在 Nyquist 附近的噪声增益急剧增大，可能导致量化器过载（overload）和系统不稳定。
**猜想**：对于 44.1 kHz 采样、20 kHz 音频带宽的系统，存在一个最优 NTF 阶数 {{< m >}}N^*{{< /m >}}，
使得感知加权 SNR 在稳定性约束下达到最大值，且 {{< m >}}N^* \leq 7{{< /m >}}。

**可证伪标准**：若存在阶数 {{< m >}}>7{{< /m >}} 且稳定（对所有满幅正弦输入不过载）的 NTF 方案，
在 A 加权 SNR 上超越已知最优七阶设计，则此猜想被证伪。
{{< /conjecture >}}
